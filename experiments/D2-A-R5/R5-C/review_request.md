## 总体研究目标与本阶段问题

RadarDistill 的总体目标是通过物理仿真真值和传统算法知识蒸馏，训练能够直接完成 GMTI 动目标检测与参数估计的学生，争取在精度或完整处理效率上形成优势；本阶段不是独立开发 CFAR 项目。

本阶段对应研究总纲 v1.3 的任务级学生目标，并关联 Q1/Q2/Q4/Q6/Q9/Q10。核心问题是：冻结 B3 DPCA 形成的完整 RD 软响应、固定 4× 连续频率响应、以及教师自选距离门内的局部频率响应，是否在可辨识场景含有可用的目标位置/Doppler 信息；K3 的峰值定位收益是否达到预注册有意义幅度；可观测响应尖锐度是否能识别不可靠输出。它没有检验学生是否吸收这些知识。

## 冻结实验方案与实现

- 保持三通道、PRF=1300 Hz、N=130、32距离单元、静止杂波及 D2-A-E001 单目标复 AWGN 信号模型。
- 新生成4,352个独立配对 base scenes，覆盖 C0–C3 共12个条件格；H0/H1共享背景噪声，scene ID 配对。使用按条件隔离的 seed blocks 726,000,000–727,199,999；预检与仓库已知清单的 seed/ID 冲突数为0。
- 以16 CPI为批次流式仿真和处理；不缓存全量 IQ 或 teacher maps。教师输入限于可观测 IQ 与冻结物理配置；真值仅用于离线评价。
- K1：冻结 B3 DPCA 原生130×32全RD支持图；K3：同一前端、固定4×零填充的520×32全RD支持图；K2-local：由IQ-only K3全局峰选距离门，再对该门的520点频谱局部归一化。
- 使用 complex128/FP64 在 RTX 3050 Laptop GPU `cuda:0` 执行教师计算，不允许CPU教师回退。PyTorch 2.8.0+cu128 / CUDA 12.8，Python 3.13.7。
- 配对 bootstrap 以 base_scene_id 为单位、2,000次重抽样。按协议预注册目标窗口 lift、top-cell localization、回绕 Doppler RMSE 和固定可观测 confidence；K3有意义收益门为定位提升至少0.02且配对95% CI下界大于0，或 Doppler RMSE至少改善2.5 Hz且其区间下界仍达到2.5 Hz。
- **模型参数量、学生训练 updates、样本暴露量、学习率计划、训练曲线：不适用。** R5-C没有学生模型或训练；本阶段不据此作容量/收敛判断。R5-A Medium（82,887参数）仅作为下一 pilot 的现有学生参考，其C3 H0 Pfa=`0.18896`，未满足0.10保护。

## 运行结果摘要

本次共完成13,056条候选逐场景记录。以下汇总为可辨识 C2+C3；结果已用于教师候选判断，属于开发审计，不是 blind。

| 候选 | 目标窗口 lift（95% CI） | top-cell localization（95% CI） | all-H1 Doppler RMSE | C3 localization | G4 |
|---|---:|---:|---:|---:|---|
| K1 原生全RD | 0.05162 `[0.04943, 0.05383]` | 0.7810 `[0.7680, 0.7938]` | 76.02 Hz | 0.7272 | 通过 |
| K3 4×全RD | 0.05130 `[0.04910, 0.05350]` | 0.8122 `[0.8003, 0.8247]` | 69.62 Hz | 0.7656 | 通过 |
| K2-local | 0.40122 `[0.39182, 0.41082]`* | 0.8122 `[0.8000, 0.8242]` | 69.62 Hz | 0.7656 | 通过 |

`*` K2-local 的 lift 是教师自选距离门中的局部归一化质量，不能与 K1/K3 的全图归一化 lift 直接比较；其峰位置继承 K3 的全局最大值，因此不是独立峰值估计器。

K3−K1 配对定位差：C2+C3 `+0.03125`（95% CI `[+0.02474,+0.03776]`），C3 `+0.03841`（`[+0.03027,+0.04655]`），达到定位有意义收益门。全图目标窗质量反而略降：C2+C3 差`−0.000320`（`[−0.000421,−0.000219]`）；C3差`−0.000250`（`[−0.000333,−0.000167]`）。Doppler RMSE差`−6.404 Hz`（`[−10.893,−2.169]`），区间下界未达到2.5 Hz，不能单独据此判定RMSE收益门通过。

最弱的 C3 partial-overlap / 0 dB 子组：K1/K3/K2-local 定位率分别为0.021/0.041/0.041；对应置信 AUC 为0.404/0.326/0.783。K2-local 的AUC尚未校准。按冻结的 severe-subgroup 联合规则（lift区间上界≤0 且定位率≤0.05），没有候选触发否决条件；但这不表示该子组可可靠定位。完整六个 C3 子组见 `metrics.json` 与阶段自审。

按协议三种软响应均通过 G4。这个门只支持提出受限学生教学内容 pilot，**不代表固定阈值检测器资格、学生蒸馏收益、可靠性加权收益或全域教师可靠性**。本阶段没有用教师硬标签，没有训练学生，也没有把教师输出当作物理真值。没有进行学生侧 Pd/Pfa 比较、教师/学生错误交叉分析、正式多 seed、KD或 final blind。

资源记录：CPU场景仿真41.83秒；K1/K3 CUDA计算阶段1.38/1.58秒；峰值CUDA allocated/reserved 23.43/44.04 MB；进程峰值RSS 859 MB；阶段后工作区约15.1 GB（约14.1 GiB），低于20 GiB限制。这些不是完整链路时延或实时性结论。
