## 研究问题回答

1. **哪个模型能够最好学习频率？** 三种主架构中只有 M1 通过筛选并进入盲测。把 M1-power 输入消融也计入时，它的 0–20 dB 平均 E1 RMSE 最低（主架构 M1 为 0.1529 Hz，功率消融为 0.1516 Hz）。M1 在 20 dB 为 0.0390 Hz，约为 CRLB 标准差的 1.14 倍；连续 ML 为 0.0349 Hz（1.02× CRLB）。
2. **物理归纳偏置是否优于普通序列学习？** M1 使用固定、不可学习的 16N 复 FFT，后接可学习循环 Conv1d 频谱读出；它不是学习式 FFT。M3 是两层、宽度 32、4 头的直接 IQ Transformer。M3 训练损失从 7.045 降至 5.579，但验证损失在首轮已最优（6.997）后升至 7.635，20 dB 开发 RMSE 为 371.3 Hz，接近常值预测 376.1 Hz，远差于 FFT 峰值 2.964 Hz。它按预注册规则停止，因此没有三种子正式盲测；这一单种子失败显示明显泛化问题，不能单独断言 Transformer 类方法普遍不可行。M1 E1 对 M1-power E1 的 20 dB 成对差为：
   - M1 − M1-power：+0.002 Hz [-0.001, +0.007]。两者 RMSE 非常接近，功率消融点估计略好（0.0368 Hz，对比 M1 0.0390 Hz），没有证据表明相邻谱相干通道提高了单音频率精度。
3. **FFT 辅助网络的收益来自哪里？** M1 比固定 16N FFT 峰值低约 0.148 Hz（20 dB，95% CI [-0.153, -0.142]），但比 16N 插值、同局部 4N 抛物线和连续 ML 差；可归因于固定频谱前端后的学习式精细读出，不能称为超过 ML。M2 在筛选开发集 20 dB RMSE 为 0.0958 Hz；它比 N 点 FFT 插值低 1.1370 Hz，但比相同 4N 局部频谱输入的抛物线估计高 0.0618 Hz、比连续局部 profile-ML 高 0.0627 Hz。M2 验证损失只下降 4.2%，随后回升，且没有胜过匹配的非学习局部估计，因此未进入正式三种子盲测；以下仅报告开发集点差，不报 CI。
4. **学生能否超过部分传统方法？** M1 E1 在 0–20 dB 的五个主 SNR 点都显著优于 N 点 FFT 峰、N 点三点插值、相位差估计及 16N FFT 峰值（各 paired 95% CI 上界低于 0）。它未超过 4N/16N 抛物线插值或连续 profile-ML。
5. **蒸馏是否带来增益？** E2-H 对 E1 在 20 dB RMSE 差为 -0.002 Hz [-0.006, +0.001]，区间跨 0；E2-S 明显更差（+0.079 Hz [+0.071, +0.091]），E3-S 在 20 dB 也更差（+0.009 Hz [+0.002, +0.015]）。G3 未通过，没有可复现的联合蒸馏收益。
6. **对 P1 三通道相位估计有什么启示？** M1 对公共相位旋转的预测变化最大仅 0.0122 Hz，0.625 Hz 精确频移的最大等变误差约 0.0125 Hz；G1、G2 均通过，支持按阶段门进入 P1-A。P1 需直接构造并验证跨通道复互相关/相位差特征，保留通道间相对相位；本单通道实验不能证明角度或三通道相位能力。

20 dB 下分组 RMSE 范围（每个训练种子分别统计）为：频率八分箱 0.0329–0.0512 Hz；初相八扇区 0.0326–0.0469 Hz；幅度四分位 0.0335–0.0455 Hz。Nyquist 边界带每 SNR 仅约 13 个带噪样本，需谨慎解释；独立 noiseless 边界集每个 E1 种子 MAE 均小于 0.026 Hz、P95 小于 0.034 Hz。
