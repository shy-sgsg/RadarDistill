# D0-E001 预注册协议

**状态：** 已冻结；在本协议提交后才实现 D0 仿真器和教师适配器。
**目标：** 验证 3 通道距离压缩慢时间简化模型、APX15 慢时间 FFT 子链及其输出字段，为 D1 训练提供可信的数据接口。D0 不训练学生，不证明算法性能优势。
**配置：** [`config.yaml`](config.yaml)。

协议设计阶段运行过非持久化工程核对：191 点 LFM 数值核对最大误差为 `1.2663e-4`；对 130 脉冲、4 倍补零频谱进行 10001 个分数栅格偏移计算，三点功率抛物插值的 RMSE/最大误差为 `0.02906/0.04053 Hz`；理想 sinc 邻点幅度比的无噪偏差为浮点精度量级。另以 seed `101`、每类每 SNR 256 个样本做过分数尺度 sanity check，`-10 dB` AUC 为 `0.9933`；该小检查采用简化随机通道相位，未验证 C++ FFT 适配器或冻结的 APX15 几何。以上均为协议设计核对，不属于 D0 正式数据或指标；正式 D0 使用配置中独立 seeds 和更大样本数，不能据此宣称研究结论。

## 1. 信号模型与适用范围

输入为固定监视窗 `X ∈ C[B,3,130,32]`，轴顺序是样本、通道、慢时间脉冲、距离门。慢时间目标相位为

\[
x_{m,n,r}=A e^{j\phi_0}a_m(\theta,\epsilon)
\operatorname{sinc}(r-r_0)e^{j2\pi f_D n/1300}+w_{m,n,r}.
\]

`f_D ∈ [-650,650) Hz`，`r0 ∈ [4,28)` 为连续的理论带宽分辨单元。窗口固定为 32 个门，所有样本使用同一窗口，不根据目标真值平移、裁剪或归一化。H0/H1 具有相同的幅度参考、SNR、角度、初相和噪声先验；目标仅在 H1 中叠加。H0 的目标距离/Doppler 标签记为无效值，不用零值伪装真值。

每个样本的目标幅度为 `A=10^(A_dB/20)`，`A_dB ~ Uniform[-6,6]`。SNR 定义为连续目标峰值功率与每个复数 IQ 单元噪声总功率之比：`SNR=A²/E|w|²`。`Re(w)` 和 `Im(w)` 独立，方差各为 `E|w|²/2`。H0 也先采样同分布的参考幅度和 SNR，再据此生成噪声；不得让类别决定噪声方差、数组布局、归一化或随机数消耗路径。

通道相位使用 APX15 四接收通道仿真场景前三个相位中心：`(-0.085,0,0.085) m`、`(0.085,0,0.085) m`、`(-0.085,0,-0.085) m`。目标方位在 `[-60,60]°`、仰角在 `[-4.5,-3.5]°` 均匀抽样，按载频 16 GHz 的远场相对路径相位形成单位幅度导向响应，再乘共同随机初相。该场景是 APX15 仿真几何的三通道子集，不代表已经核实的实机三通道标定。

距离门使用 `ΔR=c/(2B)=2.99792458 m` 的理论带宽分辨率单元，点扩散幅度为 `sinc(r-r0)`。APX15 参数文件另有 `range_resolution_m=5.0 m`，其 DDC 采样间距为 `c/(2Fs)=2.498270483 m`；本 D0 缩减模型不把这两个配置字段等同于 `c/(2B)`，输出距离仅首先按相对分辨单元报告。D0 不模拟完整快时间回波、脉压窗口加权、杂波、通道失配或平台运动，不能据此声称复制完整 APX15 生产链。

## 2. LFM—匹配滤波核对

使用 APX15 对应的 `B=50 MHz`、`Fs=60 MHz`、`T=130 μs`、`fc=16 GHz`，离散脉冲长度为 7800 点。基带脉冲为中心化矩形包络线性调频 `s(t)=exp(jπ(B/T)(t-T/2)^2)`，采样时刻为 `(n+0.5)/Fs`。对 191 个 `δB` 均匀覆盖 `[-0.95,0.95]` 的分数距离单元，直接生成延迟脉冲并与零延迟离散参考脉冲作复相关；将相关幅度除以参考脉冲能量后，与 `|sinc(δB)|` 比较。

通过条件是全偏移区间最大绝对幅度误差不超过 `2e-4`。该核对只支持当前矩形 LFM、带内延迟范围及简化 PSF；不能外推至 APX15 的完整距离压缩窗口/硬件量化链。

## 3. APX15 教师适配定义

只复用 `GMTI_APX15_CoreX_Int16_20261014/include/transposeFFT.hpp` 的 `ColFFTTranspose` 慢时间 FFT 布局和 `(-1)^n` 频轴居中约定。整包 CMake 面向 CoreX，本机未安装 CoreX SDK；D0 不编译、运行或修改 CoreX 正式处理链。适配器仅用 FFTW3 在 CPU 运行这一独立子链。

教师对每个通道分别做矩形慢时间 FFT，非相干功率求和。蒸馏软响应使用原生 `NFFT=130`、130 个中心化 Doppler 栅格和 32 个固定距离门；将整张非负响应图归一化为单位和。硬 Doppler 估计另用 4 倍零填充 `NFFT=520`，在功率峰值附近作带环绕的三点抛物插值。硬距离估计从细 Doppler 功率对频率求和得到距离边缘谱，在粗峰两侧使用 sinc 邻点幅度比估算连续偏移，偏移截断到 `[-0.5,0.5]`。

输出字段为 `teacher_response`、`teacher_detection_score`、`teacher_range_cell`、`teacher_doppler_hz`、`teacher_confidence`。检测分数为细网格最大功率除以全图中位数；置信分数为细网格最大功率占全图功率和的比例，仅表示谱集中度，不解释为校准概率。教师只接收 IQ，不接收 `truth_*`、目标真值 SNR 或仿真噪声功率；不作真值裁剪。H0 假警与 H1 错估均保留。D0 不设置工作检测阈值，阈值只可在 D1 的独立 H0 校准集上确定。

## 4. 冻结的正确性数据与检查

所有样本分批生成/处理，CPU 教师批大小 64；不持久化可由种子重建的完整 IQ 或教师响应数组。冻结样本和种子见配置：

1. 191 点 LFM 分数延迟核对，最大归一化幅度误差 `≤2e-4`。
2. 256 组 H0/H1 反事实配对：相同种子下类别只控制是否叠加目标；噪声、幅度/SNR 参考量、随机数消耗和背景数组必须相同，`H1−H0` 必须等于独立计算的无噪目标项（浮点误差容限 `1e-6` 相对量级）。
3. 1,000,000 个复噪声样本的经验 `E|w|²` 与请求方差相对误差 `≤0.5%`。
4. 4096 个无噪 H1 随机样本，覆盖连续距离、连续 Doppler、初相及通道方向；距离 RMSE `≤1e-6` cell、最大误差 `≤1e-5` cell；周期 Doppler RMSE `≤0.035 Hz`、最大误差 `≤0.06 Hz`。
5. 频率边界样本 `-650`、`-649.99`、`0`、`649.99 Hz` 按周期误差评价；连续范围边界样本 `r0=4` 和 `27.999` 不得读出窗外或发生真值裁剪。
6. 原生 FFT 的 130 个栅格音调必须落在与 APX15 居中约定一致的频率索引；复正频率不得被误标为负频率。对 4 倍零填充路径额外检查正负 Nyquist 邻域的周期估计。
7. 对 8 个 SNR `[-20,-15,-10,-5,0,5,10,20] dB`，每个 H0/H1 类各生成 1024 个独立样本，报告检测分数 AUC 及区间、H0 分数分位数、H1 距离/Doppler 误差。仅设一个教师可用性门：`-10 dB` 的 AUC 点估计至少 `0.98`；该门检查实现/信号链，不是学生或教师相对传统方法的研究优势声明。不得按 D0 结果更改门槛。
8. 32 个固定种子样本必须逐元素复现，形状/轴必须为 `[B,3,130,32]`；256 个通道方向的 steering 幅度为 1，且相对相位与独立远场路径差公式一致。

若物理、频轴或教师门未通过，先定位实现问题，不能进入 D1 训练；失败数据与原因仍写入 D0 产物。D0 样本、旧 P0/P1 测试集均只作开发/诊断，不作 D1 最终盲测。D0 各子检查使用 `config.yaml` 中列明的独立 seeds；D1 必须另设不重叠的训练、验证、开发 pilot、阈值校准和最终盲测 seeds。

## 5. 运行与报告

计划实现后使用 `conda run --no-capture-output -n AISAR python scripts/run_d0_e001.py --config experiments/D0-E001/config.yaml`。脚本记录 Git SHA、Python/NumPy、g++/FFTW、CPU、种子和实际配置。D0 产物含 `metrics.json`、`result.csv`、`analysis.md`，但不提交可重建的完整训练数组或 APX15 原始 BIN。当前文件是预注册协议，命令尚未运行；D0 正确性须以实现和实际输出为准。
