## 研究问题与数据

R6-J4检验固定几何DPCA和520点频率网格上的学习读出，能否在相同新场景和预算下优于raw-IQ联合学生J1-J。训练使用seed909、51,200个配对训练场景、5,000个配对验证场景，每臂25,600次FP32 optimizer updates、有效batch64、microbatch16；每种H0/H1存在状态暴露819,200次。J1-J有70,277个参数，best update为16,000，训练用时16,852.9秒；J4有10,494个参数，best update为24,000，训练用时22,557.6秒。两臂均在AISAR环境RTX 3050 Laptop `cuda:0`顺序训练。J4峰值allocated/reserved显存为0.90/0.97 GiB。固定预算内验证目标到末段仍有小幅改善，不能据此声称达到收敛极限。

独立评价使用120,000个H0校准CPI、120,000个H0验证CPI和6,144个H1 development CPI，覆盖12个冻结条件。B3、DPCA+130峰值、DPCA+520峰值、J1-J及J4都用各自H0校准的全局5%阈值评价。所有H1数据均为development，不是blind。

## 核心配对结果

预注册主端点J4−J1-J的C2+C3 joint-success差为`+0.03255`，配对95% bootstrap CI为`[+0.02408,+0.04080]`，超过+0.02点增益门。总体Pd差的95% CI为`[-0.01660,-0.00635]`，仍通过−0.02非劣门；全H1 range-RMSE比的CI为`[0.768,0.896]`，通过1.05保护门。

Doppler保护门失败：J4/J1-J的全H1 Doppler-RMSE比CI为`[1.723,2.085]`，明显高于1.05。点估计分别为39.56 Hz和20.84 Hz。也就是说，J4用显著更小的模型取得更多C2+C3场景的联合成功，但频率估计精度明显损失。

## 物理前端与困难条件

固定DPCA+520相对+130使C2+C3 joint success增加`+0.03299`（95% CI `[+0.02648,+0.03950]`），range和Doppler保护都通过。这支持在本仿真条件下，更密的频率采样改善峰值精估；零填充没有增加独立观测信息。

J4相对固定520峰值的C2+C3 joint差为`+0.56098`（95% CI `[+0.54709,+0.57465]`），说明学习读出显著优于同一物理频谱上的固定峰值读出。J4相对J1-J则是完整系统比较，不能把差异单独归因于DPCA或零填充。

困难condition 10暴露了总体汇总掩盖的问题：J4相对J1-J的H0 Pfa为18.31%对9.77%，Pd为23.05%对27.73%，joint success为2.15%对10.35%。J4的range RMSE较低（7.70对9.54 cells），但Doppler RMSE更差（130.10对62.99 Hz）。因此，主端点的C2+C3平均收益没有转化为困难C3格的可靠优势。

所有方法均未通过C3六格familywise exact Pfa门。J4 pooled C3 Pfa为9.65%，但condition 6/8/10的Pfa分别为19.24%/18.68%/18.31%，另三格约0.50%–0.58%；最坏格familywise单侧上界为19.90%。J1-J六格上界也未通过，最坏上界10.81%。全局或pooled C3 Pfa不能替代逐格保护。

## 阶段门与结论

| 冻结门 | 结果 |
|---|---|
| C2+C3 joint提升至少2个百分点，且95% CI下界大于0 | PASS |
| 总体Pd非劣（差值CI下界不低于−0.02） | PASS |
| Range RMSE ratio CI上界不超过1.05 | PASS |
| Doppler RMSE ratio CI上界不超过1.05 | FAIL |
| J4 C3六格familywise单侧Pfa上界均不超过0.10 | FAIL |

结论：**当前J4参数化不晋级新的确认实验。** 它是约10.5K参数的紧凑物理前端模型，在平均C2+C3 joint上超过70.3K参数的J1-J，并显著优于固定频谱峰值；但以Doppler精度退化、最难格检测退化和C3条件虚警失稳为代价。结果支持“物理前端+学习读出可以学到有用候选信息”，不支持“它已成为更可靠的GMTI检测与参数估计学生”。这是一种seed和仿真条件下的筛选结果，不外推否定所有物理驱动架构。
