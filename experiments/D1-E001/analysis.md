# D1-E001 正式盲测分析

## 结论

**阶段决策：GO → D2（按阶段门逐项增加一项复杂度）。** 预注册 G1 真值监督学习门通过，G2 蒸馏价值门通过；G3 传统算法竞争触发门未通过。该 GO 表示 D1 学生已学到基本任务映射且至少一种蒸馏方案有独立指标收益，**不表示学生可替代 APX15/profile-ML，也不表示达到 `Pfa=1e-6`**。

实验范围为 D0 冻结的单目标、三通道距离压缩复 IQ 与复 AWGN 仿真，`PRF=1300 Hz`、130 脉冲、32 个固定距离门；不含杂波、多目标、通道失配、真实 GMTI 数据或完整 CoreX/APX15 生产链。每 SNR 4096 个 H0 与 1024 个 H1，共 40,960 个盲测样本；检测阈值来自独立 50,000 个 H0 校准样本。盲测样本在模型冻结后新生成。

## 阶段门

| 阶段门 | 结果 | 证据 |
|---|---|---|
| G1：真值监督的基本任务学习 | **PASS，3/3 seed** | A 组在 20 dB 的 AUC 与 `Pfa=1e-2` 下 Pd 均为 1.0；全 H1 range RMSE 为 0.0592–0.0682 cell，Doppler RMSE 为 25.95–35.13 Hz，且两项均显著优于常值预测。 |
| G2：教师蒸馏价值 | **PASS** | C、D 的预注册最终联合指标 J 均改善，层级配对 bootstrap 95% CI 完全低于 0，且各 3/3 seed 方向改善；B 未通过。B/C/D 均未达到单独的收敛加速规则。 |
| G3：传统算法竞争触发 | **FAIL** | A/B/C/D 均没有一个预注册相邻高 SNR 区间同时满足检测差距、range 和 Doppler RMSE 门槛。 |

## 主要发现

### 检测

A 组跨种子的平均 AUC 在 -20/-15/-10/-5 dB 分别约为 0.486/0.514/0.621/0.941，跨种子 Pd（校准 `Pfa=1e-2`）约为 0.015/0.014/0.047/0.607；0 dB 及以上三种子 AUC 与 Pd 均为 1.0。-20 至 -15 dB 接近随机判别。APX15 教师在 -10 dB AUC 为 0.988、Pd 为 0.911，在低 SNR 检测上明显强于学生；在高 SNR 学生与教师都能检测，但这不代表学生参数估计同样准确。

正式盲测每方法有 32,768 个 H0，因此这里只报告协议规定的 `Pfa=1e-2/1e-3`，不能外推至 `1e-6`。工作点经验 Pfa 与区间见 `blind/metrics.json`。

### 参数估计与传统基线

按每 seed 全部 1024 条 20 dB H1 计算，D 组平均 range/Doppler RMSE 为 0.0676 cell/25.54 Hz；APX15 教师为 0.04064 cell/0.03624 Hz，四倍 FFT 抛物线插值 Doppler RMSE 为 0.02080 Hz。profile-ML 仅在预先指定的 128 条子集运行，该子集上 D 为 0.0689 cell/25.42 Hz，APX15 为 0.0415 cell/0.0360 Hz，profile-ML 为 0.01994 cell/0.01906 Hz。学生 range 误差低于原生 FFT 栅格误差 0.12867 cell，但 Doppler 估计远差于教师、FFT 插值和 profile-ML。检测门通过不能被表述为整项参数估计优于传统方法。

低 SNR 对全部方法都困难：学生在 -20 dB 的 AUC 约为 0.48–0.50；-10 dB 的 range/Doppler 无条件 RMSE 仍约为数个 range cell/数百 Hz。传统 APX15 教师在低 SNR 具有较好的检测表现，但其距离和 Doppler 数值估计同样受低 SNR 影响。逐 SNR、分组、教师/学生/传统基线、条件 CRLB 与区间均保存在 `blind/metrics.json` 和 `result.csv`；图见 `rmse_snr.png`、`detection_roc.png`。

### 蒸馏消融

主指标 J 为 0/5/10/20 dB 等权平均的归一化 range 与 Doppler RMSE。

| 组 | 相对 A 的平均 ΔJ（负值为改善） | 配对层级 bootstrap 95% CI | 改善 seed | 收敛门 | G2 |
|---|---:|---:|---:|---|---|
| B 教师预训练后真值微调 | -0.00000047 | [-0.00019825, 0.00022190] | 2/3 | 未通过 | FAIL |
| C 真值与教师联合训练 | -0.00013472 | [-0.00025944, -0.00000810] | 3/3 | 未通过 | PASS（最终指标） |
| D 渐进式蒸馏 | -0.00086207 | [-0.00214046, -0.00004611] | 3/3 | 未通过 | PASS（最终指标） |

D 的 J 平均约改善 7.6%，但区间较宽，收益大小受 seed 1 影响明显；三个 seed 的方向一致。C 约改善 1.2%。三种蒸馏策略都没有证据表明更快达到 A 的验证损失目标，因此不可声称提升了收敛速度。G2 的通过来自预注册的盲测最终指标规则，而非收敛规则。

## 物理一致性、资源与审计

物理一致性只在每 seed 256 条验证样本上诊断（各 SNR 分层数量有限），不用于盲测调参或阶段门。公共相位旋转/频率平移诊断可见 `formal/seed_*/metrics.json`；这些扰动下输出并非严格不变/等变，后续设计仍需显式检查相干信息的稳健性。

正式训练在 RTX 3050 Laptop GPU `cuda:0`、FP32、有效 batch 64 顺序运行。独立阈值校准在同一 GPU、batch 128 完成，耗时 532.2 s，峰值已分配显存约 359 MB。盲测学生预测使用 `cuda:0`，传统基线和结果复算使用 CPU；不报告未测量的端到端实时性能。

学生 CUDA 与 APX15 CPU 的结果跨设备，不能作速度优劣比较。APX15 只覆盖 FFT 子链和 D0 硬估计；学生输入已经过距离压缩，因此这不是全链部署时延或实时性结论。

评估器曾在全部盲测预测写盘后因读取 G2 AUC margin 的配置路径错误而中止。修正后通过保存预测重算全部指标：未生成新盲测样本、未改变冻结阈值、模型、门槛或指标定义。重算使用提交 `64210fc`；预测生成代码为 `209c48e`。详细审计在 `blind/metrics.json.analysis_replay` 与 `blind/metrics_partial.json`。保存的压缩逐样本预测约 6 MB，用于复核该重算。

## 限制与下一步

本结果只支持在理想 D0 仿真上进行一个最低复杂度的 D2 验证。学生在低 SNR 的检测明显弱于 APX15，在高 SNR Doppler 估计远逊于传统精细估计；G3 失败，不能把 D1 解释为传统方法替代证据。下一阶段应一次只增加一个可辨识且可证伪的因素，并继续保留教师、物理真值、同预算真值学生和独立盲测对照；不能把多目标、杂波和失配一次性叠加。`Pfa=1e-6` 需单独设计足够背景样本或尾部模型验证。
