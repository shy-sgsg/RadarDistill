# D1-E001 预注册协议

**实验名称：** 传统距离—多普勒知识引导的直接目标检测与参数估计
**英文：** *Teacher-Guided Direct Target Detection and Doppler Estimation from Multichannel Complex Slow-Time Signals*
**状态：** 已冻结；本协议先于 D1 学生/训练器实现和 pilot 运行。
**范围：** D0 已通过的理想三通道距离压缩复数慢时间信号；H0/H1 单目标，无杂波、多目标、角度输出或通道失配。
**唯一配置：** [`config.yaml`](config.yaml)。数值和种子以配置为准。

## 1. 问题、假设与适用范围

**问题：** 轻量学生能否从未经 Doppler FFT 的三通道复慢时间数据直接输出目标存在、连续距离单元与连续 Doppler？在最终推理结构和训练更新数相同的条件下，APX15 教师的全图距离—Doppler软响应预训练、联合监督或渐进退火是否改善收敛或独立测试任务指标？

**假设：** 三通道相干数据含有可辨识的单目标检测、距离和 Doppler 信息。真值监督 A 应能在较高 SNR 学到该任务；教师响应只提供辅助信息，是否改善 A/B/C/D 的公平对照不预设。教师的硬估计、检测分数和软响应均不是物理真值。

输入服从 D0 冻结信号模型，`PRF=1300 Hz`、`N=130`、三通道、32 个固定距离门，数据形状 `[B,3,130,32]`。输入窗口不按真值平移或裁剪。H0/H1 的幅度、SNR、初相、方向 nuisance 参数和噪声遵守 D0 同一先验；训练 SNR 在 `[-20,20] dB` 均匀抽样，类别严格等量。训练和验证的 H0/H1 用相同随机流构造反事实配对背景，避免类别相关的噪声、幅度和随机数路径。最终盲测 H0/H1 使用互不相同的随机种子。

范围只含单个点目标；不回归方位/速度，不加入杂波、多目标、真实通道校准或运动误差。该仿真不等于实测 GMTI。D0 通过仅确认已冻结的简化仿真和 APX15 FFT 子链正确性，不能替代本实验的学生验收。

## 2. 学生结构与物理输出

输入为 IQ 的实部/虚部平面 `[B,6,130,32]`，不把真值 SNR、目标 presence、噪声功率、教师输出或教师元数据交给学生，也不做依赖标签的归一化。学生使用宽度 32 的二维深度可分离 TCN：范围轴 `1×3` stem，七个时间 dilation `[1,2,4,8,16,32,64]`、时间核宽 3 的残差块，GroupNorm(8) 与 SiLU。理论时间感受野为 `1+2×(1+2+4+8+16+32+64)=255`，覆盖全部 130 个脉冲；时间聚合后保留 32 个距离单元。

输出为一个 presence logit、32 个 range-cell logits、每个 cell 一个 `[0,1]` 距离内偏移、每个 cell 一个归一化 `(cos,sin)` Doppler 向量，以及只在训练中使用的 `[130,32]` 频谱辅助 logits。推理时选最大 range logit 解码 cell+offset，并以 `atan2` 解码周期 Doppler；最终导出的同一学生删除频谱辅助头。前向图不得调用 FFT、CFAR、APX15 教师或参数搜索。

检测损失为全样本 BCE。距离分类、距离 offset Smooth-L1(`β=0.1`) 和 Doppler cosine 周期损失只在 H1 目标所在真值 cell 计算；H0 参数回归损失屏蔽。教师软响应 KL 对 H0/H1 全图计算，不能按真值裁剪教师图。D1 蒸馏只使用教师单位和频谱响应：硬距离/Doppler、教师检测分数和 confidence 只用于基线与教师错误分析，不作蒸馏标签。

## 3. A/B/C/D 匹配训练

每个 seed 有 1600 个 AdamW optimizer updates、有效 batch size 64；A/B/C/D 使用相同训练/验证数据、初始状态、minibatch 顺序、骨干/任务头、优化器、学习率计划及总样本呈现数。初始学习率 `1e-3`，cosine 衰减至 `1e-4`，weight decay `1e-4`，梯度范数裁剪 `1.0`。presence、range CE、range offset、Doppler cosine 损失权重均为 1；教师 KL 权重为 `0.05`。全程 FP32。

| 组 | 1600 次更新的固定阶段 | 监督信号 |
|---|---|---|
| A | 1600 真值任务更新 | 仿真真值；无教师损失 |
| B | 400 教师响应预训练 + 1200 真值微调 | 预训练使用完整软响应；微调冻结辅助谱头，继续训练共享 backbone 和任务头 |
| C | 1600 联合更新 | 真值任务损失 + `0.05×` 全图教师响应 KL |
| D | 320 教师预训练 + 480 联合 + 480 教师权重线性 `0.05→0` 退火 + 320 真值微调 | 真值任务损失与全图软响应，按固定阶段切换 |

所有方法采用相同均衡 H0/H1 采样和 `[-20,20] dB` SNR 分布；不使用课程学习，不为任一蒸馏组增加数据、更新步数或调参预算。每 100 更新评估公共验证任务损失；按最低验证任务损失保存 checkpoint，不早停，不使用验证教师损失选取模型。正式最终测试开始前冻结所有 checkpoint、代码、阈值计算规则与配置。pilot 是独立开发 seed，四组均完整运行相同 1600 步，只用于排查错误、收敛和 CUDA 资源；pilot 不进入正式种子统计。

## 4. 数据划分与随机种子

配置中显式列出一个 pilot seed 和三个互相独立的正式训练/验证/初始化 seed。每种子训练样本为 4096 H0 + 4096 H1，按 64 对分块；块 seed 由训练 base 加 `1009×块索引`生成。验证集在 8 个冻结 SNR 上每类各 128 条；验证 seed 由配置 base 加 `1009×SNR 索引`生成。同一块/同一 SNR 的 H0/H1 使用配对随机流。每个 seed 内 A/B/C/D 共享同一组样本。

独立 H0 检测校准集共 50,000 条，8 个 SNR 各 6250 条，种子由配置的 calibration base 和固定 stride 生成。最终盲测在所有模型冻结后生成：每 SNR 4096 条 H0、1024 条 H1，共 40,960 条。最终盲测 H0/H1、校准、验证、训练和 D0 correctness 的种子互不重合。相同最终盲测样本 ID 按顺序喂给所有方法；IQ 按批确定性生成，不缓存到 GPU。profile-ML 只处理预先指定的每 SNR 前 128 条 H1，其他方法使用全盲测样本。

`experiments/D1-E001/data/cache/` 仅在本机保留可由配置重建的训练/验证 IQ 及教师响应，文件由窄范围 `.gitignore` 排除。校准和盲测 IQ 流式生成，不持久化。保存配置、seed、实际微批次、权重、环境和汇总指标。教师响应与物理真值字段分别命名、保存，绝不互相覆盖。

## 5. 教师与传统基线

教师是 D0 的 `APX15DopplerTeacher`：只复用 APX15 `ColFFTTranspose` 慢时间 FFT 子链，并不等于完整 CoreX/APX15 生产 GMTI 链。APX15 FFTW 教师在 CPU 计算；学生训练必须使用 RTX 3050 Laptop GPU `cuda:0`。比较原生 130-bin FFT 峰值、原生三点插值、4× 零填充插值教师、跨三通道/距离单元的聚合相位差，以及单目标连续 profile-likelihood 参考。

profile-ML 假设白复高斯噪声、D0 的单目标 sinc 距离响应和 Doppler 单音，在每通道 profile 掉未知复增益；范围候选步长 `0.25 cell`，Doppler 用 `16N` FFT 网格后对二维峰值作局部抛物细化。它只用于每 SNR 128 条盲测 H1 的估计参考，不用于训练、学生选择或检测阈值。该有限网格/细化结果称为 profile-likelihood 数值参考，不声称解析连续全局最优。检测对照使用 APX15 教师和学生 score；阈值各自独立校准。

## 6. 检测阈值、指标与不确定性

每个模型/教师分别在独立 50,000 条 H0 校准流上，以预注册有限样本次序统计量确定 `Pfa=1e-2` 与 `1e-3` 两个阈值；盲测期间不重估或调整阈值。报告 ROC/AUC、各 SNR Pd、盲测 Pfa、混淆计数及 95% Wilson 二项区间，并同时报告各工作点的校准 H0 数、独立盲测 H0 数。由于每个方法共有 32,768 个盲测 H0，不声称达到 `Pfa=1e-6`。

估计报告所有 H1 上的 range/Doppler MAE、RMSE、Doppler bias 和 `|error|>50 Hz` 比例；另对检测正确的 H1 单独报告条件参数误差，并分开给出漏检率。按 SNR、范围四分位、Doppler 正负/Nyquist 邻域和目标幅度四分位分组。每条 H1 的理想 Doppler 条件 CRLB 参考为

`std(f_hat) >= PRF / sqrt(8*pi^2 * SNR_linear * 3 * sum_r(sinc(r-r0)^2) * sum_n((n-mean(n))^2))`，

假设三通道单位模响应、各通道未知复增益及 D0 白噪声模型。报告该界但不把它作为学生通过门槛。

置信区间使用配置固定 seed 的 2000 次 stratified paired bootstrap。组间主比较以三种子为层、相同盲测样本为配对单位。蒸馏主指标为 0/5/10/20 dB 各 SNR 等权平均的

`J = mean_snr(0.5 × (range_RMSE/24 + Doppler_RMSE/1300))`，越低越好。

同时给出每种子训练/验证任务损失、验证检测与估计曲线、达到 A 组最佳验证任务损失所需步骤、训练时长、吞吐、CUDA 峰值显存和实际微批次。共同相位旋转与 `0.625/5 Hz` 频率平移敏感性只在 validation 样本做物理一致性诊断，不用 blind 数据调参。

## 7. 冻结的阶段门

### G1：真值监督的基本任务学习

G1 仅由 A 组判定，要求三个正式 seed **全部**满足 20 dB：AUC `≥0.95`；独立校准 `Pfa=1e-2` 下 Pd `≥0.90`；所有 H1 的 range RMSE `≤2.0 cells`、Doppler RMSE `≤50 Hz`；且 range 与 Doppler 误差相对各自常值预测的配对 95% CI 均完全低于零。G1 未通过时保留全部 A/B/C/D 结果并停止增加 D2 复杂度；不能用蒸馏指标掩盖 A 组未学会基础真值映射。

### G2：教师蒸馏价值

B/C/D 分别与配对 A 比较。最终指标收益须在 0/5/10/20 dB 的主指标 `J` 上配对 95% CI 支持改善、至少 2/3 种子方向改善，并且高 SNR 平均 AUC 下降不超过 `0.02`。独立的收敛收益标准为至少 2/3 种子以少 `≥20%` 更新达到该 seed A 组最佳验证任务损失，且该策略最终 blind 主指标相对 A 的退化不超过 `10%`。未满足任何标准时记录为没有可重复蒸馏增益。

### G3：与传统算法的关系及下一阶段

不要求 D1 首轮在全部条件超过 profile-ML 或完整生产链。只有固定的某一学生策略在 0/5、5/10 或 10/20 dB 至少一对相邻 SNR 同时满足：Pfa=`1e-2` 时 Pd 与 APX15 教师差距 `≤0.05`，且 range RMSE 不超过 APX15 教师与 profile-ML 的较小 RMSE 的 `2×`、Doppler RMSE 同样不超过两者中较小 RMSE 的 `2×`，才记作达到 D1 冻结的传统竞争触发条件。

- **STOP：** G1 未通过。先诊断数据、模型、优化和信息条件，不加杂波或更复杂网络。
- **CONDITIONAL GO：** G1 通过，但 G2、G3 均未通过。只允许提出一个有界 D1 后续验证，不直接进入 D2。
- **GO：** G1 通过，且 G2 或 G3 至少一个通过，才可进入 D2 逐项增加场景难度。

## 8. CUDA 执行及产物

启动训练前检查 PyTorch CUDA、驱动及 `cuda:0`；不可见时立即终止且不得 CPU 回退。四种策略与种子顺序运行，任一时刻最多一个模型驻留 GPU；FP32、有效 batch 64、训练数据留在 CPU/memmap，按 batch 搬运。显存不足先把 microbatch 从 64 降至 32、再降至 16，并以梯度累积保持有效 batch 和 optimizer updates 不变；仍 OOM 则停止并记录。全程保存初始/最佳 checkpoint、seed、训练历史、配置、GPU 型号/显存、CUDA/驱动、峰值分配/保留显存和耗时。

正式结果应至少包含 `config_used.yaml`、`environment.json`、`metrics.json`、`result.csv`、`training_history.csv`、`analysis.md`、RMSE-SNR 图、检测 ROC 图、checkpoint 和独立 D0/D1 阶段审查。禁止提交 APX15 原始 BIN 或可重建的训练/验证 IQ 和教师数组。没有完成的指标不得写作结果；当前没有 D1 训练或测试结果。
