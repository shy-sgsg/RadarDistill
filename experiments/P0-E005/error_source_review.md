# P0-E005 误差来源复核

## 范围

仅复核预注册主门未通过后的现有产物，不新增训练或调整判据。所有分析使用 E005 保存的测试真值和三个 E1 种子预测；20 dB 结果来自每个种子的 1024 个固定测试样本。训练、验证、测试 NPZ 已逐数组核对与 E001 相同。

## 观察

- 20 dB 的三个 E1 种子 RMSE 为 13.05、15.26、17.95 Hz，平均 15.42 Hz。对应有符号平均误差为 1.65、2.12、0.42 Hz；种子间 RMSE 差异不可忽略。
- 合并种子预测后，预测频率对真值的线性斜率为 0.930、相关系数为 0.935。预测标准差 373.76 Hz，真值标准差 376.01 Hz。模型覆盖频率动态范围，但仍留有约 15 Hz 的误差。
- 20 dB 下按初相扇区分组的 RMSE 为 15.33–16.16 Hz；按幅度四分位为 15.15–15.92 Hz；按 FFT 栅格偏移四分位为 15.22–15.86 Hz。这些分组没有显示其中某一因素单独主导总误差。
- 按真值频率五分组的 RMSE 为 10.77–18.02 Hz，各组平均有符号误差从 -5.65 到 +7.82 Hz。频率位置相关的残差是后续诊断更值得关注的线索。
- E1 三个种子的训练损失为 0.14056、0.14344、0.13447；验证真值 MSE 为 0.14405、0.14412、0.13636。没有明显训练损失远低于验证损失的迹象。E1 RMSE 在测试 SNR 10 dB 为 11.57 Hz，而 15/20 dB 分别为 14.22/15.42 Hz，也没有呈现随 SNR 单调下降。

## 解释边界

结果与模型近似/频率相关校准残差、训练种子波动相符；它们不能证明是哪一项架构或优化细节导致误差。训练/验证损失接近也不能排除优化器、模型容量或损失设计造成的误差。当前小型 CNN 未达到 FFT 峰值门槛，明显落后于插值 FFT、相位差和连续 ML；E005 因而不支持启动 P1。

## 后续决策

先重新评估纯 CNN 路线是否值得继续。若继续，应先提出针对频率相关残差或种子差异的有界 P0 诊断及预先固定的判据；本复核没有据此授权或启动额外训练。
