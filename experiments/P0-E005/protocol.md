# P0-E005 预注册实验协议

**状态：** 运行前预注册，2026-10-22  
**问题：** 显式相位增量输入能否改善现有小型 CNN 的单音 Doppler 估计，使 E1 在正常 SNR 范围的部分测试点稳定优于 FFT 峰值？

## 唯一诊断改动

对每条原始复慢时间序列 `x`，构造单位相位增量

`u[n] = x[n+1] * conj(x[n]) / abs(x[n+1] * conj(x[n]))`, `n=0..N-2`。

幅度为零的增量定义为 `0+0j`。学生以这 129 个复值作为两通道 Conv1D 输入；FFT、插值、相位差和连续 ML 基线仍直接使用原始 130 点 IQ。数据集文件继续保存原始 IQ，以便复现该变换和传统基线。

## 固定条件

- 保持 E001 的物理数据与独立测试划分：PRF 1300 Hz，N=130，训练 SNR 为 -15、-5、0、10、20 dB；测试 SNR 为 -15、-10、-5、0、5、10、15、20 dB；训练/验证/测试种子方案不变。
- 训练种子为 101、202、303；每种子 6000 个训练和 1200 个验证样本；测试每个 SNR 1024 个样本。
- 使用 E002 的优化轮数上限：160 epochs、patience 40、batch size 128、learning rate 0.001。
- 学生保持 6 个卷积通道、kernel size 9、全局均值池化和圆周 sin/cos 输出。
- 保留 E1 真值监督、E2 教师软目标、E3 真值加权教师软目标（权重 0.5）及全部四个传统基线。
- 使用与 E001/E002 相同的确定性测试种子；训练种子 101 可与 E002 配对核对。

## 指标与阶段门

- 主比较：E1 相对 FFT 峰值的 RMSE 差 `E1 - B0_fft_peak`；负值有利于 E1。
- 在每个测试 SNR 上以共享测试样本和训练重复为单位做 500 次两层配对 bootstrap。
- 通过条件：在 0、5、10、15、20 dB 中，至少两个相邻 SNR 点的 `E1 - B0_fft_peak` 95% bootstrap 区间上界均小于 0。
- 其余 SNR、插值/相位差/ML 差距、分组误差及 E2/E3 蒸馏比较为次要结果；不得据此声称实测 GMTI、杂波抑制或部署收益。
- 若未通过，按阶段计划先分析误差来源并重新评估纯 CNN 路线；本实验本身不启动 P1。
