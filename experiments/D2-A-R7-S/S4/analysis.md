# S4：历史虚警证据资格审查

## 审查范围

本审查只对照已冻结的协议、指标和统一矩阵，检查每个虚警数字代表的事件单位、分母、校准/验证分组和方法输出接口；没有重新校准阈值或生成检测结果。可机器筛选的阶段审计见 [`false_alarm_evidence_audit.csv`](./false_alarm_evidence_audit.csv)。

## 核心结果

1. **历史证据以 CPI 级为主。** 统一矩阵共28,058条指标记录，其中6,106条显式标记`Pfa_CPI`；它们来自不同实验、split、条件、方法和统计粒度，不能把6,106当作独立样本或统一排行榜。矩阵中没有一条数值型`pfa_cell`记录；R7-D的检测分数是每CPI一个标量，逐CUT虚警状态为不适用/未验证。
2. **R7-D是清楚的CPI级共同工作点。** 每个方法、每个SNR有2,048个H0校准和2,048个独立H0验证场景，阈值目标为每SNR `Pfa_CPI=0.01`。这能比较无杂波复AWGN下的CPI存在性检测，不能外推到一个未知SNR全局门限、有杂波场景或物理距离–Doppler cell。
3. **独立H0数量增加未自动解决条件迁移。** R6-B/G/H/J4等阶段使用约120,000个校准与120,000个验证H0后，总体Pfa可接近目标，但C3逐格familywise门仍失败。R6-I的尺度校正让C3 pooled Pfa下降0.00905，却未达预设改善门，且整体Pd非劣保护失败、C3高SNR分层失稳。
4. **不能把历史稀疏候选事件换算成cell级概率。** CPI存在事件、CPI最大候选、稀疏候选输出、CUT阈上事件具有不同分母及相关结构。D2-A-E001/T001等历史出现的CUT相关统计只按其原协议表述，不满足统一dense CUT map、独立阈值与验证的 cell 资格。
5. **R7-A数字是资源规划，不是测量结果。** 在零事件的独立Bernoulli近似下，平均单CUT 95%单侧上界达到`1e-6`需2,995,731个样本；4,160个固定CUT同时保证的保守估计需11,328,997个。它们不包含校准集额外预算、CUT间相关、条件分层或模型输出缺陷。

## 资格判定

| 资格项 | 判定 | 理由 |
|---|---|---|
| 历史CPI级评价是否有用 | 有，但协议限定 | 可用于原有任务/条件下的存在性检测比较，必须带上split、阈值规则、H0分母和CI |
| R7-D共同数据能否比较学生和传统CPI检测 | 可以，限L1无杂波AWGN、每SNR独立工作点 | 54种方法使用同一批IQ和同一分层规模；profile-ML/lag-one没有检测输出，不进入该比较 |
| 当前是否有模型达到`Pfa_cell≈1e-6` | 未验证 | R7-D无dense CUT分数图；矩阵没有数值`pfa_cell`；R7-A仅作样本量分析 |
| 当前总体Pfa合格是否保证C3条件虚警合格 | 否 | R5/R6/R7多轮总体值接近门槛，困难条件仍违反逐格保护门 |
| 可否对R7-D标量`Pfa_CPI`作换算 | 不可以 | 事件单位、候选策略和有效统计分母不同，且无dense map与相关性模型 |

## 对后续路径的约束

下一次检测资格实验必须先明确“物理CUT”与边界/无效单元定义，记录逐CPI的dense score map，独立划分H0拟合/阈值校准/验证，并按模型、场景条件和真实有效分母报告点值及区间。L0–L1可以先验证接口与中等虚警工作点；若样本量不能支持目标尾概率，应标注未验证，不得由CPI级结果外推。该建议是本阶段路线审查，不代表已启动新实验。
