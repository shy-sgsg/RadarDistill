# D2-A-R3 第一阶段：原始 T0 H0 统计量

本阶段只运行冻结的 B0–B3 原始分数，没有运行 T1/T2，也没有训练学生。运行器使用新的校准/验证 seed，按 batch=16 流式生成 H0；量化结果与逐场景诊断分别保存在 `metrics.json`、`raw_score_quantiles.csv` 和 `h0_scene_diagnostics.csv`。

- H0 总计 53,376 条记录：20,480 个校准场景、32,768 个验证场景和 128 个受控缩放场景。
- 主条件下，E001 的 B3 固定阈值 961.3979 应用于 16,384 个独立 H0，得到 `Pfa_CPI=0.064636`，95% Wilson CI `[0.060972,0.068504]`；四个 A/B/C/D 验证组各自为 0.0632、0.0647、0.0659、0.0647。
- 三个独立 primary B3 校准阈值为 1006.866、1042.350、997.105，校准 Pfa(`>=`) 均为 0.050049；不同阈值应用到新验证组后的合并 Pfa 分别为 0.049866、0.041809、0.053467。
- 在新分布点估计 `p=0.064636` 下，单独验证抽样得到 `K≥23/256` 的精确二项尾概率为 0.07019；联合 `n_cal=512,n_val=256` 层级 bootstrap 的对应比例为 0.0216。
- 潜在目标参考幅度与 H0 总功率的 Pearson `r=0.999989`，与 B3 原始分数 dB 的 `r=0.9780`、线性斜率 `1.0018 dB/dB`。B3 在最低幅度箱的 Pfa 为 0，最高幅度箱为 0.168–0.216。
- 所有 T0 方法的受控 `X,aX` 测试均满足 `score(aX)=|a|² score(X)`；最大相对误差为 `3.32×10⁻⁷`，低于冻结容限 `10⁻⁵`。

完整代码核对、重复校准矩阵、阈值边界、幅度 nuisance 解释和候选阶段依据见 [`raw_phase_review.md`](raw_phase_review.md)。其中记录了“**T0 原始分数复核完成**”，所以现在允许依预注册协议运行固定 T1/T2 比较。
