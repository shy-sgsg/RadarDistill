# D2-A-R3 阶段结果分析

**状态：** 数据生成、统计量比较与冻结门审查完成；未启动 E1 学生 pilot、蒸馏或 final blind。
**研究总纲：** [`docs/RESEARCH_CHARTER.md`](../../docs/RESEARCH_CHARTER.md)，v1.1；核心目标仍是以物理真值和传统教师支持任务级 GMTI 学生检测与参数估计。R3 是为后续学生与教师可靠性提供基础，不是独立 CFAR 研究。
**结果性质：** 合成开发诊断，不代表真实回波或生产系统性能。
**实现基准：** 候选数据生成基于 `5391adc31f9f42a827c03982568870db6a5cdc7b`；受控尺度计算和 G3 复核修正见 `f81093e5f027962fc3252c81d45b91bcd49e14a1`。本文件随阶段结果提交，提交 SHA 由阶段汇报提供。

## 1. 执行与证据范围

实验按 `protocol.md` 预注册的顺序运行：先冻结 B0–B3 原分数 T0，再在相同预生成场景上评价 T1/T2。主条件每个 H0 校准组、H0 验证组及配对 H1 组均为 4096 场景；3 个主校准组与 4 个主验证场景组互不重叠，另有 CNR=0/20 dB 有界检查和 128 个受控 `X,aX` 场景。数据按 batch=16 流式产生，没有缓存完整 IQ。

复现命令：

```bash
conda run --no-capture-output -n AISAR python scripts/run_d2a_r3.py --config experiments/D2-A-R3/config.yaml --phase raw
conda run --no-capture-output -n AISAR python scripts/run_d2a_r3.py --config experiments/D2-A-R3/config.yaml --phase candidates
```

T0 用时 615.25 秒，T1/T2 候选阶段用时 1895.29 秒。两阶段在 CPU 上运行；实验不需要神经网络训练或 GPU。候选阶段复放并核对了冻结 T0 分数。最终保存逐场景 H0 诊断、配对 H1 检测结果、阈值/指标、运行环境和图表。代码修正后，专项及相关仿真、基线和评估测试共 **45 项通过**；另通过 Python 编译检查和 `git diff --check`。

T1 是 B3 DPCA RD 功率图峰值除以固定 guard 外的全图中位背景功率；T2 是每个 RD cell 除以局部 9×7 参考窗（排除 3×3 guard）的中位数，CPI 分数取最大值。两者仍以 B3 为物理前端，并非纯学习方法或已获准的教师。

## 3. 十项研究问题

### 1. E001 的 Pfa 迁移偏差能否由有限样本解释？

有可能，但不能归因于有限样本这一项。将 E001 冻结的 B3 阈值 `961.3979` 用于 R3 新的 16,384 个主条件 H0，得到 1059 次误警，`Pfa=0.064636`，Wilson 95% CI `[0.060972, 0.068504]`；A/B/C/D 四组各为 0.06323、0.06470、0.06592、0.06470。若真实率固定为 R3 点估计 0.064636，单独验证抽样出现 E001 的 `23/256=0.089844` 或更高值的精确二项尾概率为 0.07019。按预注册的分层 10,000 次 bootstrap 同时重采样 512 个校准分数与 256 个验证分数，阈值 2.5/50/97.5 百分位为 `[939.86,1014.46,1092.72]`，Pfa 百分位为 `[0.01953,0.05078,0.08594]`，达到或超过 `23/256` 的比例为 0.0216。

因此 E001 的高点估计并非统计上不可能，校准和验证有限样本都可能有贡献；但联合抽样尾部较少，不能只以有限样本消解问题。更直接的证据是下述幅度 nuisance：它系统性改变 H0 的绝对尺度。bootstrap 是按共同分布假设的抽样诊断，不证明 R3 与 E001 完全同分布。

### 2. H0 场景整体幅度 nuisance 是否影响固定阈值？

是，且影响显著。生成器以潜在目标参考幅度 `A` 设定 `noise_power=A²×10^(-SNR/10)`，再把杂波功率按 CNR 缩放到噪声功率。于是即使 H0 中没有目标，潜在的反事实目标幅度仍共同缩放噪声和杂波。这是当前仿真尺度模型中的 nuisance，不是 H0/H1 标签分支泄漏；检测器也没有读取 `A` 或组件功率。

四个预定幅度箱的 H0 总功率中位数依次为 0.391、0.779、1.559、3.116；噪声功率中位数为 0.0356、0.0708、0.1417、0.2834；杂波功率中位数为 0.355、0.709、1.417、2.834。潜在幅度与 H0 总功率 dB 的 Pearson `r=0.999989`；与 B3 分数 dB 的 `r=0.9780`，回归斜率 `1.0018 dB/dB`。B3 在一个主校准阈值下四个幅度箱的 Pfa 为 `0, 0, 0.00042, 0.20319`，三个校准阈值下最高箱 Pfa 为 `0.168–0.216`。固定绝对功率阈值无法抵抗此尺度变化。

### 3. 可观测归一化/CFAR 是否改善虚警稳定性？

幅度与尺度稳定性得到支持，但总体固定阈值迁移尚未解决。T1 三次校准均通过 G3：最高减最低幅度箱 Pfa 的 95% 区间全部落在 `[-0.02,0.02]`，四箱点估计极差为 0.0040–0.0045；其受控尺度不变误差也通过。T2 三次均通过 G3，幅度箱极差为 0.0044–0.0069，受控尺度检查同样通过。

两者都未通过 G2。T1 三次主条件合并验证 Pfa 为 0.04620、0.04443、0.04596，95% CI 分别为 `[0.04309,0.04953]`、`[0.04138,0.04770]`、`[0.04286,0.04927]`，均没有覆盖 0.05；CNR=0 合并 Pfa 为 0.05591，CI `[0.05114,0.06109]` 也不覆盖 0.05。T2 主条件三次为 0.05243、0.04846、0.05438；第三次 CI `[0.05101,0.05796]` 不覆盖 0.05，因此 G2 失败。CNR=0/20 的 T2 合并点估计为 0.04980/0.04749，区间覆盖 0.05。

这两个归一化统计量有效移除了被测的整体尺度 nuisance，但不能据此宣称已实现稳定的跨样本阈值迁移或理论 CFAR。T2 仅是经验校准的 CFAR-like 统计量，没有局部参考单元独立同分布假设。

### 4. 数据生成或检测分数是否存在错误？

未发现会解释本次异常的实现错误。A/B/C/D 只改变目标构造；同 seed 下 H0、噪声和杂波逐元素相同；H1 与 H0 的差正好是目标 IQ。随机流由 `SeedSequence.spawn(3)` 分开，数据按 `[B,C,N,R]` 布局，阈值采用冻结的 `higher` 经验分位数，比较符为 `>=`。所有 T0 检测结果由现存冻结基线逐场景复放。

发现的是仿真尺度假设带来的目标参考幅度与 H0 尺度耦合，而非标签泄漏或检测器输入泄漏。原始统计量的 `|a|²` 规律经受控测试成立。E001 的异常可以有有限样本贡献；本轮证据支持幅度 nuisance 是其结构性风险，但没有证明它是 E001 这一次偏差的唯一成因。仿真模型未被修改，E001 冻结结果未被覆盖。

### 5. 归一化是否损害 Pd 或参数估计？

按冻结 G4，T1/T2 在所有可辨识 A/B/C 条件的 Pd 和 joint success 相对 B3 均未出现超过 0.05 的退化，故均通过性能保护门。CNR=10 dB 部分重叠 C 中，B3 的 Pd/joint 为 0.530/0.530，T1 为 0.982/0.982，T2 为 0.926/0.921。T1 对 B3 的配对 Pd/joint 差为 `+0.452`（95% CI 下界约 `+0.437`）；T2 对应约 `+0.396/+0.392`（下界均为正）。T1 的该条件 range RMSE 为 0.432 cell、Doppler RMSE 为 4.28 Hz；T2 为 1.18 cell 和 23.0 Hz；B3 为 0.383 cell 和 4.35 Hz。T1 在检测上改善很大，参数误差与 B3 相近；T2 的局部背景参考被目标污染，导致该困难条件参数精度明显变差。

CNR=20 dB 的部分重叠 C 仍然困难：B3 Pd/joint 为 0.168/0.141，T1 为 0.369/0.329，T2 为 0.248/0.208。A/B 条件三方法均接近满检出。D 是同流形不可辨识边界：三方法 AUC 均约 0.50、joint success 近零，不用于来源恢复门。

T1 的 scene-wide robust 背景估计较少被目标污染：配对 H0/H1 估计变化中位数 A/B/C/D 分别为 1.28%、0.69%、0.47%、0.43%。T2 在真值附近 CUT 的局部参考估计变化中位数为 66.7%、29.0%、8.2%、4.1%；真值只用于此后处理诊断，没有输入检测器。结果倾向 T1，但二者都未通过 G2，因此尚不能成为已批准方法。

### 6. 哪个统计量最稳健、适合作为教师/基线？

在已测统计量中，T1 是最有前景的后续候选：通过 G3/G4，目标污染较小，并在部分重叠 C 的 Pd、AUC、joint success 和参数误差上总体优于 T2。B3 保留为历史物理基线。T2 的局部参考在目标邻近区域受到污染，参数估计损失明显。

目前**没有**方法通过全部 G1–G4，`selected_b3_based_statistic=null`。因此不能把 T1 选定为固定阈值传统教师，也不能声称教师已具备足够稳定的虚警控制。后续比较中可把 T1 视为研究候选，但它必须先经单独冻结、独立校准验证；不可用同一开发数据回调阈值。

### 7. 是否满足冻结 R2 的 E1 truth-only pilot 前置条件？

不满足。G1 正确性审查通过，T1/T2 的 G3 与 G4 通过，但没有任何 B3-based 统计量同时通过 G2、G3、G4。因此按当前冻结 R2/R3 规则，**未授权、未运行**单 seed E1 truth-only pilot。没有运行 E2/E3、正式多 seed 训练或 final blind。

### 8. 是否仍值得研究 K1/K2 渐进蒸馏？

保留为后续假设，但当前不启动。R3 没有测试蒸馏。D1 蒸馏证据只在对应 AWGN 协议范围内成立，不能直接外推到静止杂波；在学生尚未通过 truth-only 基础学习、教师的 H0 阈值稳定性也未解决时，K1/K2 复杂度会掩盖基本映射或教师可靠性问题。若另立并通过独立批准的 truth-only 学生协议，先验证基础任务，再决定是否冻结单一 K1/K2 对照。

### 9. 哪些研究假设获支持或否定？

- **H-CLUTTER-002（固定 5% 阈值可迁移）：NOT_SUPPORTED。** 新固定阈值 B3 Pfa 为 0.06464，95% CI 不含 0.05；R3 三个独立 B3 校准阈值也不是全部满足 G2。
- **H-CLUTTER-003（归一化稳定尺度且保持可辨识 H1）：INCONCLUSIVE。** T1/T2 的 G3/G4 支持幅度稳定与性能保护，但两者 G2 未通过，完整假设条件未成立。
- **幅度 nuisance 是 T0 绝对分数不稳定原因之一：SUPPORTED（当前生成模型内）。** `A` 与 H0 噪声、杂波和分数尺度强相关；不外推为真实设备幅度变化。
- **同一 CNR 下 A/B/C/D 的 H0 分布因场景标签而不同：NOT SUPPORTED。** 同 seed H0 完全相同，独立组的少量差异仅作描述。
- **T1 对部分重叠目标比 T2 更有研究价值：有条件支持。** H1 表现与参考污染结果有利于 T1，但它还不是可部署/批准的阈值或教师。

### 10. 下一步唯一优先任务

优先准备并送审一份**独立、truth-only 学生 pilot 协议提案**，评估是否可以在不依赖传统教师阈值通过的前提下，检验核心任务级学生能否从物理真值学习三通道检测与参数估计。提案应保持学生与预算冻结项，预先定义学生自己的独立 H0 校准/验证、Pfa、Pd、参数误差与物理一致性门；不得加入教师损失、K1/K2 或 final blind。该提案属于新路线，未获独立审查/批准前不得训练。

这样下一阶段回到核心学生目标，同时保留当前对传统教师可靠性的负结果；不再为引入 CFAR 反复增加统计量和窗口搜索。若审查不接受这条路线，则仅另行定义一个有限的 H0 分布一致性分析，不在本阶段默认继续重校准。

## 4. 总体阶段决定

**REFINE。** R3 的证据足以确认原始绝对分数对仿真中的潜在整体尺度敏感；T1/T2 改善了尺度不变性并保护已辨识目标表现，但独立 Pfa 门仍未通过。因而当前冻结 E1 前置条件不成立，停止在本阶段，不进行蒸馏或盲测。总体研究目标仍有可检验价值：下一步的优先事项应重新围绕 truth-only 任务级学生可行性设计独立协议，而非扩大传统统计量搜索。所有结论限于当前三通道、PRF=1300 Hz、N=130、32 range cells、合成静止杂波与圆对称复 AWGN 条件。
