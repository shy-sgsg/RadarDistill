## 当前主要问题

1. 学生连续 Doppler 误差远高于 FFT 插值、APX15 和 profile-ML。
2. 低 SNR 检测弱，教师在其自身低 SNR 失效区不能作为可靠真值。
3. 还未分离距离门选择错误、时间特征池化、任务损失冲突和数据/优化等竞争性解释。
4. 推理成本证据不足以判断完整处理链速度。

## 当前唯一优先任务

**D1-R1：在 D1 的训练/验证缓存和已保存训练产物上分解 Doppler 误差来源。** 使用真值距离索引只做 oracle 诊断；绝不将真值提供给模型推理。比较池化前/后可读频率信息、各任务梯度及不同 SNR/种子/频率区间。不要读取 D1-E001 最终盲测预测用于结构选择。

用户已批准 D1-R1 后接 D1-E002 的整体路线；E002 的精确模型、预算、统计门和新数据种子必须由 R1 结果与正式协议冻结。

## 后续候选与依赖

1. **D1-E002：** 依赖 D1-R1 确认的最小结构变化。匹配 S0 原 TCN、S1 保留时间的轻量读出、S2 低成本相干特征、S3 固定 FFT 混合参考；S3 必须与相同 FFT 前端非学习方法比较。
2. **D2 单因素场景扩展：** 仅在 R1/E002 阶段审查仍支持任务学生方向后，选择一个可辨识的复杂度，例如静止杂波或低速弱目标，不叠加多项困难。
3. **D3 原始回波迁移：** 依赖可靠的下游任务和明确的输入边界。
4. **D4 计算优化及 D5 系统评估：** 依赖任务质量已可靠且有明确系统目标；完整链速度必须同硬件测量。

## 阶段决策规则

- **GO：** 预注册主要指标达到门槛，关键保护指标和物理一致性通过，独立数据/种子支持结论。
- **CONDITIONAL GO：** 学习有可复现价值但传统性能或适用范围有限；只开展明确受限的最低复杂度后续实验，不能扩大主张。
- **REFINE / REDIRECT：** 机制或架构证据指向更合理且可证伪的路线；在新协议中冻结变更并保留旧结果。
- **STOP：** 当前假设在适用范围内被否定，或预设保护门失败；停止该路线的无目标扩展。
- 任何新最终盲测都要在模型、阈值、统计门、预算和候选集冻结后才生成。旧开发测试只作诊断。
