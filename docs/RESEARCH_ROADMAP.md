## 当前阶段

**D1：任务级检测与参数估计的有界后续诊断。** D1-E001 已按冻结门完成，阶段 GO → D2 不变；D1-R1 已完成。D1-E002 的候选、数据种子、预算、统计门和停止条件已预注册；尚未训练，下一步仅按冻结协议做单 seed pilot。

## 已完成实验与证据

- **D0-E001：** 12/12 仿真和教师子链正确性检查通过；结果仅支持简化仿真/FFT 子链有效。
- **D1-E001：** 三种子正式训练、独立校准和盲测完成；G1、G2 通过，G3 未通过。受测真值监督学生可学习最终任务；部分联合/渐进蒸馏最终指标改善，但没有收敛加速证据。
- **D1-R1：** 只用 D1 训练/验证材料完成三种子预测门/oracle 门、池化前后线性 probe、A/D 任务梯度和教师分组质量诊断。高 SNR oracle 几乎不改变 Doppler 误差；pooling 因果仍未决；低 SNR 教师检测和 Doppler 质量区间不同。见 experiments/D1-R1/。
- **D1-E002 protocol：** S2 lag-one 相干统计为唯一优先纯 IQ 候选；S1 仅单 seed 反证，S3 明确为 FFT 混合并匹配非学习估计。配置测试确认所有派生数据种子与登记的 D0/D1 种子不重合。协议冻结但尚无 pilot 结果，见 experiments/D1-E002/。
- **P0/P1 历史先导：** P0-E006 STOP/REDIRECT；P0-E007 G1/G2 PASS、G3 FAIL；P1-A-E001 STOP/REDIRECT。它们保留独立结论，不作为 D1 的数据或可重复新盲测。

详见 docs/stage_reviews/D0-D1_overall_report.md、D1-E001_review.md、P0_final_review.md、P0-E007_review.md 和 P1-A-E001_review.md。

## 当前主要问题

1. 学生连续 Doppler 误差远高于 FFT 插值、APX15 和 profile-ML。
2. 低 SNR 检测弱，教师在其自身低 SNR 失效区不能作为可靠真值。
3. R1 已排查距离门、时间池化读出和最终 checkpoint 梯度；训练早期优化、模型选择和数据分布仍未完全分离。
4. 推理成本证据不足以判断完整处理链速度。

## 当前唯一优先任务

**D1-E002 单 seed pilot：** 依照 [`experiments/D1-E002/protocol.md`](../experiments/D1-E002/protocol.md) 顺序训练 S1、S2、S3；只使用其指定的 pilot train/validation 种子和预注册筛选门。协议测试通过前不得启动训练；pilot 前不得生成 calibration 或 blind 数据。未通过筛选的候选不进入三 seed formal。

## 后续候选与依赖

1. **D1-E002：** 协议与门槛已冻结。匹配 S0 原 TCN、S1 四段时间读出、S2 低成本相干特征、S3 固定 FFT 混合残差；S3 必须与相同 FFT 前端非学习方法比较。
2. **D2 单因素场景扩展：** 仅在 R1/E002 阶段审查仍支持任务学生方向后，选择一个可辨识的复杂度，例如静止杂波或低速弱目标，不叠加多项困难。
3. **D3 原始回波迁移：** 依赖可靠的下游任务和明确的输入边界。
4. **D4 计算优化及 D5 系统评估：** 依赖任务质量已可靠且有明确系统目标；完整链速度必须同硬件测量。

## 阶段决策规则

- **GO：** 预注册主要指标达到门槛，关键保护指标和物理一致性通过，独立数据/种子支持结论。
- **CONDITIONAL GO：** 学习有可复现价值但传统性能或适用范围有限；只开展明确受限的最低复杂度后续实验，不能扩大主张。
- **REFINE / REDIRECT：** 机制或架构证据指向更合理且可证伪的路线；在新协议中冻结变更并保留旧结果。
- **STOP：** 当前假设在适用范围内被否定，或预设保护门失败；停止该路线的无目标扩展。
- 任何新最终盲测都要在模型、阈值、统计门、预算和候选集冻结后才生成。旧开发测试只作诊断。
