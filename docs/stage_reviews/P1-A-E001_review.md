# P1-A-E001 阶段审查：理想三通道相对相位估计

**日期：** 2026-10-24  
**决定：STOP / REDIRECT（当前跨通道相关特征 MLP 路线未通过 G1）**  
**适用范围：** 三通道共享单音、固定通道增益、独立同方差复 AWGN 的仿真条件。

## 研究问题与预注册

在 `PRF=1300 Hz, N=130` 下，观测为

\[
x_m[n]=a_m e^{j\phi_m}s[n]+w_m[n],\quad m=1,2,3,
\]

其中三路共享同一连续频率复正弦，通道幅度独立取自 `[0.5,1.5]`，参考通道相位及两组相对相位独立均匀分布在 `[-π,π)`。每条记录按平均通道信号功率设置同一噪声方差；三路噪声相互独立、圆对称复高斯。目标只包括 `Δφ21` 与 `Δφ31`，不包括角度、速度、目标检测或通道误差。

预注册协议见 `experiments/P1-A-E001/protocol.md`。模型对输入 `C21/C31` 的归一化复互相关实虚部进行 `4→64→64→4` MLP 读出，以真实相位 sin/cos 标签进行 E1 监督。该模型具有显式相干物理前端，不能解释为原始 IQ 端到端。训练前设定的 G1 要求至少 2/3 个训练种子同时达到无噪声两相位 MAE `<0.01 rad`、P95 `<0.05 rad`、20 dB RMSE 比零相位基线至少低 50%、三类物理不变性误差 `<0.02 rad`；模型种子还需独立。

## 实验与复核

- 训练数据：每个模型种子 6000 条；验证集每份 1200 条；train、validation、noiseless 和 final blind 数据使用不同随机种子。训练 SNR 为 `{-15,-5,0,10,20}` dB。
- 独立无噪声集：2048 条。最终盲测集仅在三个模型 checkpoint 冻结后生成，8 个 SNR、各 1024 条，共 8192 条；盲测种子为 `401999,402999,…,408999`。
- 训练种子 `[121001,121002,121003]`，验证种子 `[221001,221002,221003]`，Torch 种子 `[82101,82202,82303]`。
- 运行环境：AISAR、PyTorch `2.8.0+cu128`、CUDA build `12.8`、NVIDIA GeForce RTX 3050 Laptop GPU（4 GiB）。三份模型顺序训练，FP32、batch 64、Adam `1e-3`、最多 160 轮、patience 40。每份训练 14.52–14.90 秒；峰值已分配显存均为 17.6 MiB。训练数据保存在 CPU，按 batch 传入 GPU。
- 实现核对：共轭方向/参考通道、周期边界、解析估计器无噪声恢复、公共相位/复尺度/频移不变性以及有限差分 Fisher 信息均有测试。当前完整测试集为 67 项通过。

## 主要结果

### G1：FAIL

总体 0/3 种子通过。所有种子在 20 dB 的相对 B0 改善和三种不变性检查均通过，但三种子、两组相位的无噪声 MAE 均在 `0.0177–0.0206 rad`，高于预注册 `<0.01 rad` 门槛。无噪声 P95 为 `0.0414–0.0524 rad`，部分相位也没有通过 `<0.05 rad` 门槛。因此按冻结规则不能通过；不使用 blind 结果修改模型或验收值。

| 20 dB RMSE (rad) | Δφ21 | Δφ31 |
|---|---:|---:|
| 学生，三个种子范围 | 0.02315–0.02603 | 0.02329–0.02584 |
| B1 相干互相关 | 0.009992 | 0.009754 |
| B2 单样本圆均值 | 0.009951 | 0.009740 |
| B3 秩一 profile-ML | 0.009936 | 0.009738 |
| 条件 CRLB RMS 标准差 | 0.009989 | 0.009952 |

三个学生都把 20 dB RMSE 相对零相位基线降低约 98.6%，且相位旋转、全局复尺度及公共频率调制后的最大输出差仅 `4.77×10⁻⁷ rad`。这些结果表明模型确实利用了相对相位信息，并符合所测物理不变性；但精度未达 G1。学生高 SNR 误差约为 CRLB 的 `2.3–2.6` 倍，B1–B3 则接近 CRLB。三个种子的 student−B1 与 student−B3 配对 RMSE 差在 20 dB 均为正，95% bootstrap 区间均不含零；详细数值见实验 `analysis.md` 与 `paired_comparisons.json`。

在 0–20 dB，学生总体没有超过 B3 profile-ML；20 dB 也明显落后 B1/B2/B3。低 SNR 时学生与 B1/B3 相近，但没有持续、显著的优势。整个 SNR 范围上，解析 profile-ML 是最强参考，低/中 SNR 时两组相位 RMSE 也通常低于学生。

学生在低 SNR 个别点能优于较弱的 B2 无权重圆均值：例如 -10 dB 两相位学生跨种子平均 RMSE 约为 `0.946/0.915 rad`，B2 为 `1.072/1.076 rad`。但这些点仍未优于 B3（约 `0.868/0.831 rad`），也没有抵消高 SNR 的明显误差差距。

### 训练与泛化

三种子的最佳验证向量 MSE 为 `0.1035–0.1090`，最佳轮次为 `140–151`；最佳轮的训练向量 MSE 为 `0.1060–0.1111`。训练与验证损失均已平台化，没有明显训练/验证鸿沟，和当前模型读出欠拟合或优化受限相符。现有证据不能区分模型逼近能力、不同 SNR 混合下的目标冲突和优化因素的因果贡献。不同相位扇区、公共初相扇区及通道幅度差四分位的误差见 `grouped_metrics.csv`；三种子在高 SNR 的整体误差方向一致。

完整各 SNR RMSE、CRLB、误差分组、训练记录、资源占用和图表见 `experiments/P1-A-E001/analysis.md`、`result.csv`、`grouped_metrics.csv`、`training/`、`metrics.json` 与 `rmse_snr.png`。

## 决定与边界

**当前 P1-A 最小学习路线 STOP / REDIRECT。** 因为解析相干估计器/profile-ML 已接近此模型的条件 CRLB，且学生未达到无噪声精度门、在高 SNR 明显落后，所以当前不进入 P1-B、不追加蒸馏，也不在盲测后更换损失/结构或延长训练。若以后重新提出相位学习实验，应先针对“共享相位角函数在混合 SNR 条件下的近似/优化差距”给出新的可证伪问题、独立协议及阶段门；当前结果本身不授权扩展搜索。

本决定不否定所有神经相位估计器，不改变 P0-E006/ E007 历史审查，也不对有通道失配、杂波、目标混合或真实回波的数据作推断。E001 没有教师或蒸馏，因此没有蒸馏收益结论。
