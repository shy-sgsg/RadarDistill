# P0 阶段最终审查

日期：2026-10-23  
阶段决策：**STOP / REDIRECT（停止当前单音学习路线的继续扩模）**  
P1-A 状态：**未启动训练；仅保留理论方案**。本决定遵守 E006 预注册 G1：G1 未通过时不开展 P1-A 实验。

## 1. 研究目的与理论边界

P0 检查有限学习模型是否能从长度为 130 的单通道复慢时间序列中估计连续多普勒频率，并区分基本学习能力、传统算法竞争力和蒸馏收益。信号为

\[
x[n]=A e^{j(2\pi f_dn/\mathrm{PRF}+\phi_0)}+w[n],
\]

其中 PRF=1300 Hz，频率在半开无模糊区间均匀连续分布，初相均匀随机，幅度在 [0.5, 1.5] 内随机，噪声为圆对称复高斯白噪声。频率误差按 PRF 周期回绕。未知复幅度/相位下的 periodogram profile likelihood 是经典频率估计参考；CRLB 是所列模型与无偏假设下的理论尺度，不是低 SNR 有限样本的保证。

P0 只验证仿真单目标频率估计，不验证 GMTI 检测、杂波、多目标、三通道相位、角度/速度估计、实测泛化或部署效率。

## 3. 算法和计算条件

- **S0：** 冻结的 E005 CNN；只作原模型参考。
- **S1：** lag=1/2/4/8 的归一化复自相关特征，经小型 MLP 输出圆周频率。匹配的非学习基线 B7 对同一组复相关做全频率相干评分和局部精化。
- **S2：** 固定 520 点 FFT 的归一化对数功率，经小型 MLP 输出圆周频率。匹配物理参考 B6 为 4N FFT 峰值。
- **教师：** T1 局部 profile-ML 点估计；T2 教师峰周围 ±2 个原生 FFT bin 的 65 点局部 profile likelihood 圆周均值；T3 保留该 65 点响应并用 KL 目标训练响应头。
- **策略：** E1 真值监督；E2-A 教师训练并按教师验证早停；E2-B 教师训练但按真值验证早停；E3 真值+教师联合训练并按真值验证早停。所有 S1/S2 对照共享每个训练种子的初始化和样本顺序。
- **传统参考：** N 点 FFT 峰、对数三点插值、相位差、FFT 初始化局部 profile-ML、全局网格 profile-ML、4N FFT 峰、B7 多延迟相干评分。
- **运行环境：** Python 3.13.7、NumPy 2.3.4、PyTorch 2.8.0+cu128、CUDA build 12.8、NVIDIA RTX 3050 Laptop GPU、driver 580.178.04、`cuda:0`。33 个模型均在 CUDA 上训练，无 CPU 回退。基准提交为 `81b85e1700918ddb5ecde10a0083495e5a84e0ee`，运行时工作区包含本轮未提交改动。GPU 运行不构成部署性能测量。

### G1：学习可行性 — 未通过

预注册数值门要求：某一学生至少 2/3 个训练种子在 2048 个连续无噪声频率样本上 MAE<1 Hz 且 P95<5 Hz，并且该学生 20 dB E1 RMSE 小于零频预测的一半。

- S1 三种子的 noiseless MAE/P95 分别为 3.010/6.401、2.438/5.829、2.667/5.749 Hz；满足无噪声门的种子数为 0/3。它在 20 dB 的 RMSE 2.947 Hz，远低于零频预测 372.125 Hz，满足高 SNR 常数对照，但不能弥补无噪声门失败。
- S2 三种子的 noiseless MAE 为 26.54–30.98 Hz、P95 为 62.04–76.98 Hz；20 dB RMSE 为 27.238 Hz，也低于零频预测一半，但无噪声门为 0/3。

因此，S1 有频率信息学习证据，但没有达到预注册的可靠学习精度门。不能把“明显优于常值”写成 G1 通过。

### G3：蒸馏价值 — 未通过

S1 E3/T2 相对匹配 E1 的配对差：0 dB 为 -0.369 Hz，95% CI [-0.734, -0.064]；5 dB 为 -0.062 Hz，区间跨零；10、15 dB 区间也跨零；20 dB 为 -0.229 Hz，95% CI [-0.417, -0.028]。0 和 20 dB 是两个彼此不相邻的孤立点，因此不满足相邻 SNR 门。其 seed-level 方向在 0、5、20 dB 均为 3/3 改善，但不能替代配对区间的相邻点条件。

S1 E3/T3 在五个主 SNR 点都比 E1 差，95% 区间均高于零；本实验下完整局部响应头没有显示收益。S1 E2-A/T1 和 T2 在部分点比 E1 低，但对应差异不构成预注册的 E3 蒸馏门，且 T2 圆周均值几乎与 T1 点目标相同。当前证据不支持“联合蒸馏已带来稳定收益”。

## 5. 分组与物理变换

在 20 dB，S1 E1 的 RMSE 随五个频率区间为 2.57–3.37 Hz；初相扇区 2.79–3.10 Hz；幅度四分位 2.91–3.02 Hz；FFT 栅格偏移四分位 2.90–3.01 Hz。S1 对初相/幅度/栅格偏移变化较稳定，但对高精度门仍不够。S0 20 dB 的频率分组范围为 10.52–18.00 Hz；S2 为 23.37–31.10 Hz。

在固定开发批次的实测诊断中，S1 对公共相位旋转、完整观测复缩放的平均绝对预测偏差约 2.3×10⁻⁵、2.6×10⁻⁵ Hz；S2 约 1.1×10⁻⁴、1.2×10⁻⁴ Hz。归一化相关/功率特征实现了预期不变性。但频率平移与复共轭的预测偏差分别约为：S1 26.3/28.4 Hz，S2 146.4/146.2 Hz，S0 46.6/103.7 Hz；这些学生没有形成可靠的频率等变结构。仅改变信号幅度 1.7 倍会使 SNR 增加约 4.61 dB，这项诊断单独报告，不当作幅度不变性；开发批次 128 例上平均频率 RMSE：S1 292.0→181.7 Hz，S2 334.4→305.0 Hz，S0 315.6→231.2 Hz。

## 6. 科学问题回答

1. **网络是否学到频率？** S1 的误差随 SNR 降低，在 20 dB 明显优于零频预测，并且在 15 dB 单点超过 FFT 峰，说明它用到了频率信息；严格 G1 仍未通过，不能称为可靠高精度学习。
2. **普通 CNN 为什么落后？** S1 相对 S0 的提升与相干复相关特征提供更合适归纳偏置相一致；这是有支持的解释线索，不是隔离各因素后的因果结论。S1 仍远落后相同输入的解析多延迟评分，说明优化、输出结构或训练目标尚未把物理特征转化为高精度估计。
3. **物理归纳偏置是否有效？** S1 优于 E005 的冻结 CNN，支持复相关特征有用；S2 失败，且两个 MLP 均不胜过同物理前端的经典方法。故结论是有限、架构相关的收益，不是物理前端+网络普遍优于传统处理。
4. **蒸馏是否有效？** E3/T2 只有非相邻点的孤立收益；E3/T3 明显变差。G3 未通过。
5. **继续哪类模型？** 若仅作离线研究基准，S1 是本轮最好学生；它没有达到同特征解析基线性能，不应部署或替代解析估计器。S2 不建议继续沿当前 MLP 方案扩展。
6. **局限是什么？** 单音 AWGN、指定长度和频率分布；独立噪声/幅度变化以有限模拟覆盖；只有 3 个训练种子；局部教师响应不是全局后验；未验证实测、杂波、多目标或跨系统误差。
7. **哪些结论可迁移到三通道？** 复数相关特征、圆周误差和公共相位不变性的数学处理值得保留。频率网络的精度、角度/速度估计能力、三通道相位闭合、目标检测和部署结论都不能迁移。

## 7. 阶段决策与 P1-A 边界

最终决策为 **STOP / REDIRECT**：G1 未通过，按冻结规则不启动 P1-A 训练，不增加 E007 单音网络或更大架构搜索。可供后续审议的 P1-A 理论问题和最小可执行协议草案见 `docs/stage_reviews/P1_A_plan.md`；该计划不是实验结果或获准开跑的阶段。若未来研究方向重新获批，先用独立方案论证三通道相对相位的可辨识性及解析基线，再决定是否恢复学习实验。
