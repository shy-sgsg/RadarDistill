- D0-E001 的 12/12 冻结检查支持简化复数 AWGN 仿真、频轴和 APX15 慢时间 FFT 子链适配正确；不覆盖完整生产链。
- D1 学生输入距离压缩 IQ 的六个实/虚平面，使用普通实值卷积、GroupNorm、SiLU 和时间均值池化。它没有显式复数卷积或相位群等变算子。推理导出移除训练期频谱头；教师硬估计不是任务真值。损失代码按 H1 mask 计算参数项，Doppler 使用圆周向量损失。
- D1-E002 的 S1/S2 未调用完整 FFT；S3 是 520 点固定 FFT 加学习残差的混合模型，协议和指标将其与纯 IQ 学生区分。S3 未通过 pilot，未有正式盲测结论。
- D1-E001 与 E002 均有一次评估器配置读取错误，分别在保存的预测或同一 blind cache 上修复并重放。数据、ID、模型、阈值和冻结门未改变，失败产物被保留。这是可审计的分析重放，不是新盲测。
- CUDA、checkpoint、训练历史和统计结果有记录。D1-E001 时延测量以距离压缩 IQ 为输入且学生 GPU / APX15 子链 CPU 不同；没有完整链同硬件速度证据。

## 2. 实验科学性与统计复核

### D0 与 D1-E001 冻结结论

- **D0：** 12/12 仿真/教师子链正确性门通过；教师在 -20/-15 dB 并不可靠，不能取代物理真值。
- **D1-E001 G1：PASS。** A 真值监督组 3/3 seed 在 20 dB 满足冻结检测、距离、Doppler 与常值预测对照门。全盲测条件下低 SNR 检测仍弱。
- **G2：保留原冻结 PASS，但证据范围有限。** C 联合真值+软频谱响应的 ΔJ 为 `-1.3472e-4`，95% bootstrap CI `[-2.5944e-4,-8.0956e-6]`，3/3 seed 改善。D 渐进蒸馏 ΔJ 为 `-8.6207e-4`，CI `[-2.1405e-3,-4.6108e-5]`，方向也是 3/3。B 未通过。任何策略都未通过收敛加速门。
- **跨 seed 影响：** C 的每 seed ΔJ 为 `-7.52e-5/-2.22e-4/-1.07e-4`，方向稳定。D 的三值为 `-2.189e-3/-1.425e-4/-2.552e-4`；seed 1 占三 seed 绝对改善量约 84.6%。去掉 seed 1 的描述性两 seed 均值改善约 `1.99e-4`，比完整均值 `8.62e-4` 小约 77%。方向并非只由 seed 1 决定，但效果量明显受其影响。
- **多策略比较：** G2 同时考察 B/C/D，并以“至少有预注册策略通过”形成阶段结论；报告的是各策略名义 95% 区间，没有跨 B/C/D 的家族错误率调整。原冻结 G2 PASS 不改写；它支持本协议下 C/D 的有限信号，不支持未校正的普遍“蒸馏有效”主张。后续确认应事先指定一个主要蒸馏策略或预注册多重比较校正，并用新独立数据/种子。
- **低 SNR 保护：** 以盲测 `Pfa=1e-2` 下 -20/-15/-10/-5 dB 的等权 Pd 描述均值，A 为 0.1705，C 为 0.1721，D 为 0.1149。E001 的 G2 高 SNR AUC 保护条件没有覆盖低 SNR Pd；因此不能把 C/D 的 J 收益解释成低 SNR 检测改善。D 的低 SNR 检测相对 A 明显更弱。
- **G3：FAIL。** D1-E001 学生没有达到冻结传统竞争触发。原阶段决定 GO → D2 由 G1 和 G2 支持，结论仍保持；它不代表传统替代性能。

### D1-R1 与 D1-E002

R1 只用开发材料：高 SNR 的预测门与 oracle Doppler RMSE 接近；固定 ridge 池化后 probe 优于池化前 probe，但维数相差 130 倍、样本仅 1024；最终 checkpoint 梯度 cosine 均值近零；teacher-KL 梯度因缺训练期 spectrum-head checkpoint 不可用。R1 没有证明池化、任务冲突或教师蒸馏是高 SNR 频率瓶颈的因果原因。

E002 使用新独立盲测，每个学生候选 3 seed，S1/S2 每 seed 1600 次更新，FP32、有效 batch 64、RTX 3050 Laptop GPU。S2 的 0/5/10/20 dB 等权 Doppler RMSE 为 23.352 Hz，相对 S0 改善 10.86%，配对 95% CI `[-6.338,-0.173]` Hz、3/3 seed 同向；range 非劣门通过，但低 SNR Pd 的 CI 下界 `-0.0939` 未达预注册 `-0.05`，总门失败。S1 RMSE 比 S0 差 8.02%。

传统估计差距仍很大：非学习 lag-one 3.743 Hz、原生 FFT peak 2.860 Hz、原生三点插值 1.494 Hz、四倍 FFT peak 0.738 Hz、四倍 FFT 抛物插值 0.104 Hz、APX15 0.122 Hz、有限网格 profile-ML 0.100 Hz。profile-ML 每 SNR 只使用协议固定的 128 个 H1，解释为有限网格参考；0/5/10/20 dB 条件 CRLB 均值约 0.098 Hz。S2 约为该参考的 238 倍。

S2 受测的公共相位旋转会造成约 11–15 Hz Doppler 输出变化；小频移也有明显等变残差。接入 lag-one 特征证明了该读出在本协议里可提供部分增益，但没有让 TCN 自动获得相位不变性或频移等变性。

## 3. 研究主线与贡献边界

1. **哪个模型最会学习频率？** E002 受测纯 IQ 学生中为 S2；它相对 S0 有可重复的中等改善，但精度仍远不够与传统精估计竞争，且检测保护门失败。
2. **物理归纳偏置是否胜过普通序列学习？** S2 的 lag-one 相干输入在此高 SNR 汇总指标上优于 S0；这只支持该物理特征在该任务/预算下有用，不能推广到一般架构，更不能称为完整物理等变模型。
3. **FFT 辅助网络收益中传统前端贡献多少？** 没有正式盲测可量化。S3 pilot 的高 SNR Doppler RMSE 为 68.110 Hz，匹配三点 FFT 为 67.963 Hz，未显示学习残差增益；S3 也未通过 pilot screen，未进入 formal。传统 FFT 基线在盲测达到 0.104–2.860 Hz 范围，不能把任何混合估计表现归为纯学习成功。
4. **学生是否超过部分传统方法？** E002 S2 的 RMSE 未超过表列任何精细传统频率基线。E001 证明的是相对常值预测和自身任务可学习性，不是传统估计竞争力。
5. **蒸馏是否有收益？** E001 的 C/D 在冻结 J 上满足原规则，C 的种子方向较稳定、D 的效应量受 seed 1 影响；无收敛加速证据，且 D 的低 SNR Pd 下降。E002 只有 E1 真值监督，未开展 E2/E3，不能据此声称新架构的蒸馏收益。
6. **速度潜力如何？** 尚无可靠证据。旧结果不是同硬件、同输入边界、完整链比较；不声称实时性或加速。

当前可陈述的贡献限于：简化仿真正确性、受测 TCN 的任务可学习性、D1-E001 C/D 的协议内联合指标变化，以及 E002 S2 对 S0 的高 SNR 相对改进。标准 CNN/TCN、IQ 输入、FFT 和蒸馏本身不构成本项目已证明的创新。

## 4. 战略决定

**总判断：REDIRECT。** 停止 D1-E002 的 AWGN S1/S2 结构扩展，保留其负结果与 S2 的有限正向统计结果。D1-E001 原阶段 GO → D2 不被 E002 覆盖；这两项决定适用范围不同。

**唯一下一项优先任务：** 编制并审查 D2-A“静止杂波下单目标检测与参数估计”单因素预注册协议及传统基线/可辨识性验证。固定 D1-E001 直接 IQ TCN 作为一个参考，不继续增加 Doppler readout 架构。只加入一种静止杂波模型，不同时加入多目标、加速度、通道误差或运动补偿误差。协议应先冻结 H0/H1 生成、目标与杂波幅相/功率定义、可辨识区间、DPCA/杂波抑制与频谱检测基线、校准 Pfa、训练预算、种子、独立测试及 Pd/range/Doppler 保护门；新 blind 数据只在方案冻结后生成。训练从 E1 真值监督开始；只有基础任务学习合理后才比较 E2/E3。

D1-E001 的 GO → D2 允许进入 D2 设计，但 D2-A 的具体协议尚未冻结。当前任务不生成新盲测、不训练新模型，也不把建议记作实验结果。若 D2-A 在正确基线/可辨识条件下不能显示可学习空间，停止该学生路线并评估混合物理前端边界。
