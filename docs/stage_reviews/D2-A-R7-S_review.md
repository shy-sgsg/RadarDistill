# D2-A-R7-S：学生、教师与传统方法证据综合审查

**阶段结论：REFINE**
**研究总纲：** `docs/RESEARCH_CHARTER.md` v1.4；本阶段未修改总纲。
**输入基线：** 开始本轮时 `main` 与 `origin/main` 均为 `759799a34b0aea9c0955427db9b398bf8ec94275`。
**范围：** 统一历史结果表独立审计，比较既有模型与教师证据，评估参数/虚警/知识资格及研究路线；没有训练、蒸馏、阈值搜索、新性能实验或 final blind。

## 1. 总体判断

R7-S回答的不是“谁在所有场景绝对最好”，而是“现有模型、传统方法和教师分别在哪些数据、任务与虚警口径上有证据”。审计发现统一性能矩阵的来源指针映射、R7-D逐方法覆盖、模型checkpoint哈希、指标格式和历史参数量规范化均已核实；修复的是表格构建和来源追溯问题，没有改写原始metrics或冻结实验结论。

当前证据可以确认：有些学生在无杂波L0/L1上学会基本检测/参数映射；受测学生和传统方法的最佳指标随SNR与任务变化；传统FFT/profile-ML的中高SNR连续估计显著更强；部分软教师知识在最困难的静止杂波重叠格常常错误，且R5-C/R6-G均没有证明现有K3/K2-local教学能在truth-only之外提高学生最终任务。现有任何一项结果都不能证明 `Pfa_cell≈10^-6`。

因此不应把R5/R6/R7的开发结果拼成总排行榜，也不应因joint点值提高就忽略Doppler或困难条件虚警保护。RadarDistill总体研究目标仍有价值，但在增加学生训练前应先补上检测输出和误差分解的评价能力。阶段判定为 **REFINE**，下一项唯一优先任务是预注册、实现并独立核验一个L1 dense CUT分数接口与H0校准/验证路径。

## 5. S3：参数估计能力与训练充分性

R7-D主估计口径是**全部H1**；检测命中子集仅作条件诊断。命中子集会由不同检测器筛出不同场景，不能独立说明完整系统能力。参数专用的lag-one和profile-ML没有Pd/Pfa/Joint输出。profile-ML每SNR n=256，而其余大部分方法n=2,048。

在−5至20 dB，受测学生的逐SNR最佳Doppler RMSE仍约195至39–54 Hz；传统FFT细化约0.08–3 Hz，profile-ML在256样本子集约0.432至0.022 Hz。学生高SNR Range RMSE最佳约0.18–0.21 cell，profile-ML约0.14–0.15 cell。低SNR参数误差会变大；学生检测与精估计的最优候选并不相同。详见[参数证据审查](../research/D2-A-R7-S_PARAMETER_EVIDENCE_REVIEW.md)、[表4–7](../../experiments/D2-A-R7-S/S2/model_capabilities.md)和图3–5。

训练预算证据有限且跨阶段不可混排：R5-A同长计划内S0验证Range/Doppler误差从1,600至12,800更新持续下降，说明该设置下单遍训练不足以代表长预算；Small→Medium（13,383→82,887参数）同seed/预算下改善C2+C3任务，但两者C3 Pfa都未过绝对门。R6-C Large/XLarge在12,800步改善部分joint指标但C3六格门失败；R6-G用51,200步训练，最佳checkpoint早于末步；R6-H 25,600步部分验证指标仍末段改善。没有共同证据证明固定步数就是上限，也没有跨协议参数量散点可以因果确定“最合适大小”。

R6-J4只有10,494参数并在C2+C3 joint上胜过J1-J点值，但其Doppler RMSE比95% CI为1.723–2.085，且最难C3格Joint只有2.15%（J1-J为10.35%）。该模型是固定DPCA/FFT前端加学习读出，不能称为纯端到端模型或普遍更优架构。

## 6. S4：虚警统计资格

统一矩阵中显式Pfa_CPI标记6,106条记录，其中数值型Pfa_CPI 4,440条；矩阵没有数值型Pfa_cell记录。大多数R7-D方法每CPI只输出一个分数，按照协议报告CPI级虚警；任何Pfa_CPI都不能换算为Pfa_cell。历史阶段统计定义、校准/验证split和门槛不同，须按[虚警审计表](../../experiments/D2-A-R7-S/S4/false_alarm_evidence_audit.csv)读取。

E001中主条件经验Pfa从校准的0.0508到独立开发0.0898，R3新主条件下冻结B3阈值Pfa_CPI=0.06464（95% Wilson CI `[0.06097,0.06850]`），层级bootstrap能解释部分波动但不能把偏差完全归为有限样本。R3识别到噪声与杂波功率随潜在目标参考幅度变量缩放，绝对分数因此带有尺度nuisance；该变量不是H0/H1标签分支泄漏。

R3归一化T1/T2在受测幅度/尺度检查与可辨识H1任务保护上表现较稳，但均未通过固定阈值G2。R4的T1总体幅度四分位Pfa约0.046–0.052，C3仍0.178–0.217。R6-I单斜率尺度校正在C3 pooled Pfa只下降0.00905，且总体Pd保护失败并在部分C3高SNR条件失稳。故没有证据支持一个能跨主要条件同时稳定虚警并保护任务的已合格统计量。

R7-A中`1e-6`零事件样本量仅为规划计算：平均单CUT至少约2,995,731个独立H0样本；若4,160个固定CUT同时满足则约11,328,997。它不是实测或资格结果。没有任何方法通过单元级`1e-2`至`1e-6`资格，`1e-6`仍`NOT_VERIFIED`。

## 7. 数据生成、评分实现与归一化

未发现足以推翻R7-D主数值的输入、评分或生成器错误。R7-S审计定位并修复了统一矩阵构建器的来源指针和历史参数字段问题；R7-D原始metrics、checkpoint和协议未变。R7-B DPCA数值与声明公式及CPU/CUDA分量实现相符，但结论只覆盖共址Tx的合成几何、周期分数移位和纯静止杂波组件。

绝对B3统计分数的跨尺度脆弱性有R3证据；归一化对受测T1/T2的幅度敏感性有改善证据，但固定阈值迁移仍失败。不能说“归一化本身有害”：R3候选在所测H1保护未见超门退化；也不能说“归一化已解决检测”，因为G2没过。R6-I还表明单一后验分数校正可降低pooled C3误警同时损害总体Pd并加剧特定分层，因此归一化/校正必须连同分层任务保护一起评价。

## 8. S5：教师与传统方法资格

教师五类资格分开记录在[教师资格矩阵](../../experiments/D2-A-R7-S/S5/teacher_qualification_matrix.csv)：(1)公式/接口正确；(2)物理组件作用；(3)任务能力；(4)知识内容正确性；(5)学生教学收益；另列虚警资格。

- B0/B1和profile-ML是有价值的**无杂波参考**；lag-one/profile-ML为参数专用。它们不构成复杂杂波环境下的合格教师。
- B3 DPCA在当前合成几何下具备有限的静止杂波抵消组件资格：1,280场景杂波抑制中位15.478 dB（95% CI `[15.420,15.540]`），补偿前后相干0.8486→0.9858。未证明端到端检测/参数或学生教学收益。
- R5-C K3对K1的可辨识C2+C3定位提高0.03125（95% CI `[0.02474,0.03776]`）；最难格K1/K3/K2-local定位率约2.15%/4.10%/4.10%。软知识有部分信息，但不宜无条件全域监督。
- R5-C T1/T2与R6-G T1均未证明相对truth-only有增益。R6-G T1−T0 C2+C3 joint差−0.00130（95% CI `[-0.00781,+0.00521]`）；T3 truth-assisted差+0.01172低于+0.02门且不是教师蒸馏。
- T001 ACE×AMF在前置门停止，未完成软图审查；7kg来源未获得版本/许可证/接口/正确性及公平比较证据，未构成数值基线。

所以“最好的教师”目前不存在已证明的全域答案：B1/profile-ML是L1基线，B3是合成组件候选，K3软响应有局部知识质量证据，但没有一个兼具困难场景任务/虚警资格和已证实学生收益的教师。

## 9. S6：假设复核与研究方向

Q1/Q2：当前K3/K2-local的受测教学收益不支持，不扩展权重/时机搜索；并非否定所有教师知识。Q3/Q4：学生可学习L0/L1映射、DPCA组件物理实现成立，但没有识别普遍更优的网络表示或前端。Q5/Q7：原始回波迁移和同硬件完整链成本未评价。Q6/Q8：传统精估计强，学生部分低SNR检测有价值，但没有完成有杂波、低虚警的统一比较。Q9：困难格教师错误需先质控；教师物理正确、知识质量与教学收益必须独立。Q10：延长训练和width-only的有限收益有支持，但收敛、容量最优点、架构因果及知识吸收机制均未确定。逐题状态和路线影响见[Q1–Q10矩阵](../../experiments/D2-A-R7-S/S6/charter_question_evidence_matrix.csv)。

## 10. 阶段门与明确问答

| 问题 | 结论 |
|---|---|
| 原始Pfa迁移异常是否可由有限样本解释？ | 只能部分解释。R3层级bootstrap显示E001的0.0898并非完全不可能，但主验证0.06464仍偏高，且幅度/条件尺度nuisance有直接证据。 |
| H0幅度nuisance是否影响固定阈值？ | 是，绝对功率分数受场景噪声/杂波尺度影响；尺度归一化改善受测幅度鲁棒性但未通过G2。 |
| 检测分数或数据生成有已证实错误吗？ | 本轮未发现推翻原始指标的score/generator错误。发现并修复了历史统一矩阵的来源映射/参数元数据问题；生成器尺度依赖是已声明的nuisance模型，不自动等于仿真错误。 |
| 哪种检测统计量最稳健？ | 当前没有跨条件合格项。T1/T2有幅度稳健证据但固定迁移门失败；R7-D的FFT在L1 AWGN是强参考，不测复杂杂波。 |
| 归一化损害Pd或估计吗？ | R3 T1/T2在冻结H1保护范围未显示超门退化；证据不足以推到所有条件。R6-I单斜率修正保护失败，说明其他校正并不安全。 |
| 哪种方法适合作教师？ | B1/FFT、profile-ML适合作无杂波参照；B3仅为合成物理组件；无已证明的全域任务+知识+教学合格教师。 |
| 是否满足E1 truth-only pilot前置条件？ | 按当前R7 G5不满足：dense CUT评价能力、cell级虚警证据和可靠教师资格不足。此阶段未启动pilot。 |
| 是否仍值得当前K1/K2/K3渐进蒸馏？ | 当前K3/K2-local内容分支不值得继续搜索，因R5-C/R6-G未过收益门且困难格教师错误严重。不同教师/表示需新证据和独立预注册，不能一概判死。 |
| 哪些假设获支持/否定？ | 有限支持：合成DPCA组件正确、部分学生学会L0/L1、预算/容量在若干特定pilot中影响任务。受测K3/K2教学、部分架构合取门和低虚警稳健化假设未通过；完整回波、端到端效率、普遍架构优越性仍未决。 |
| 下一项唯一优先任务？ | 建立L1 dense CUT分数输出及物理CUT边界定义，预注册独立H0校准/验证和统计预算，以FFT/局部检测参考做有界对比；完成后重审G5。 |

## 11. 阶段决策与边界

**主裁决：REFINE。** 总体GMTI学生和教师教学研究目标仍值得研究；当前应从反复学生架构/K3蒸馏搜索转为完善能验证长期`Pfa_cell`目标的基础输出与统计路径，并保留强传统参数估计对照。下一任务必须预注册并另行授权；本报告没有启动该任务。

未修改研究总纲、历史实验协议、原始metrics/checkpoints或冻结门；没有新训练、知识蒸馏、final blind、真实回波或低虚警实测。结论适用范围限于本项目已存仿真、协议和开发结果，不能据此宣称真实GMTI资格或1e-6系统性能。
