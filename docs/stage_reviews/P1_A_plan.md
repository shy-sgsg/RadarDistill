# P1-A 理想三通道相对相位研究设计

**状态：P1-A-E001 已完成；按冻结 G1 为 0/3 种子通过，当前决定 STOP / REDIRECT。** P0-E006 的 G1 失败仍作为历史结论保留，P0-E007 的 GO 只作为启动本轮最小实验的阶段准入。本文件记录研究背景与约束；实验结果和审查见 `experiments/P1-A-E001/analysis.md`、`docs/stage_reviews/P1-A-E001_review.md`。

## 研究问题与可辨识假设

估计三路相干观测中两组相对相位：

\[
x_m[n]=a_m e^{j\phi_m}s[n]+w_m[n],\qquad m\in\{1,2,3\},
\]

其中 `s[n]` 为三通道共享的非零复数波形，`a_m>0` 与 `φ_m` 在一段 CPI 内固定；首轮假设各通道噪声独立圆对称复高斯。以通道 1 为相位参考，估计

\[
\Delta\phi_{21}=\operatorname{wrap}(\phi_2-\phi_1),\qquad
\Delta\phi_{31}=\operatorname{wrap}(\phi_3-\phi_1).
\]

公共相位不可辨识，也不需要估计。若各通道没有共同的 `s[n]` 或增益在 CPI 内变化，以上相位差未必可辨识；这类情况不属于首轮理想 P1-A。

对无噪声共享波形，互相关

\[
C_{m1}=\sum_n x_m[n]x_1^*[n]
=a_ma_1e^{j(\phi_m-\phi_1)}\sum_n|s[n]|^2
\]

的相位等于目标相对相位。首个传统估计器因此为 `angle(C21)` 和 `angle(C31)`。噪声存在时再比较逐样本互相关圆均值、按幅度/噪声加权的圆周估计及带未知波形 nuisance 参数的 profile-ML。正式运行前需推导并核对相位 CRLB/Fisher 信息；不预先把简单互相关称为所有噪声条件下的精确 ML。

## 逐步实验条件

沿用 N=130 的慢时间长度，固定三通道共享波形和 CPI，逐项增加难度：

1. 无噪声、固定相位差，检查解析互相关和周期回绕。
2. 无噪声、均匀随机相位差和公共相位，检查参考通道定义。
3. 三通道独立 AWGN，按通道记录 `a_m² E|s|² / E|w_m|²`。
4. 固定相位差下加入通道幅度差异；最后才增加独立通道 SNR。

首轮不加杂波、多目标、硬件通道相位漂移、时延、阵列几何映射或角度/速度标签。训练、验证、盲测数据采用不同固定随机种子；E001–E006 的数据不能复用作 P1 最终盲测。

## 学习对照

若未来重新获准训练，先用单一小模型，不做架构搜索：输入 `C21`、`C31` 的归一化实虚部，MLP 分别输出两个单位圆向量。损失对两组 `(cos Δφ, sin Δφ)` 做平方误差或等价的圆周损失。E1 真值监督先于任何教师策略；仅当它在独立数据上稳定、且与解析基线比较得到明确问题后，才考虑一个有界教师消融。

不使用三通道的绝对相位作为输出，不把相位差解释成角度或径向速度。若想检验闭合误差，应同时输出三组 pairwise 相位并评估 `wrap(Δφ21 + Δφ32 + Δφ13)`；若模型只输出两组独立相位，第三组由差值派生，闭合恒等式并非独立验证。

## 指标和预注册门

- 周期相位误差 `wrap[-π,π)(estimate − truth)`，逐通道对报告 MAE、RMSE、偏差、异常率、每个训练种子和 95% 区间。
- 按 SNR、相位区间、通道幅度差和公共初相分组；公共初相整体旋转不应改变相对相位。
- 先验证无噪声正确性、边界回绕、通道索引/共轭约定，再评估噪声泛化。
- 学生必须明显优于相位先验/常值参考，并在预先指定 SNR 区间通过与复互相关/适用 ML 的配对比较；具体 SNR、数值容差、样本数和 CRLB 在拟启动前写入新 `P1-A-E001/protocol.md`。
- 三通道公共初相变化要稳定；若模型输出三个 pairwise 相位，闭合残差须在预设容差内。任何模型不得以拟合教师代替真值相位验收。

## 风险与备选

1. 共享波形/恒定复增益假设不符时，相位偏差可能混合通道误差、时延和目标参数；先标明可辨识条件，不让网络猜不可辨识量。
2. 互相关可能已接近理论界；若学生不优于它，应把结论定位为“可学习”而非“更准确”，停止增加模型复杂度。
3. 若噪声不等或有离群回波，再另立 P1-B；不得在 P1-A 中一次加入多个误差源。

P0-E007 的阶段审查允许 P1-A 启动一个有界实验。上述细节冻结于 `experiments/P1-A-E001/protocol.md`。E001 的学生优于常值预测并保持公共相位、复尺度和公共频移不变性，但未通过无噪声 MAE 门，且 20 dB 明显落后解析相位基线；因此本路线停止，不扩展至 P1-B 或蒸馏。详细证据以 E001 结果和阶段审查为准。
