# D2-A-R3 阶段审查

**请首先读取本次Git提交对应版本的 `docs/RESEARCH_CHARTER.md`，理解RadarDistill的整体研究主题、研究目标、研究内容、科学问题和技术路线，然后结合这些内容审查本阶段的代码、实验、数据和研究结论。**

## 审查范围与研究总纲对齐

- **研究总纲：** [`docs/RESEARCH_CHARTER.md`](../RESEARCH_CHARTER.md)，v1.1。本阶段未修改总纲。
- **阶段任务：** 诊断 D2-A-E001 固定阈值迁移；只比较预注册的 T0/B0–B3、T1 和 T2；评估是否满足冻结 R2 的一个 truth-only E1 pilot 前置门。
- **实现/数据基准：** 候选数据由 `5391adc31f9f42a827c03982568870db6a5cdc7b` 生成；G3 受控尺度计算与门控修正在 `f81093e5f027962fc3252c81d45b91bcd49e14a1`。阶段审查报告和动态状态文件随本次阶段结果提交，最终提交 SHA 由 Codex 阶段汇报提供。
- **对应总体研究目标：** 用物理仿真真值与可信传统教师支持任务级 GMTI 学生，最终评估检测/参数精度与完整处理效率；当前优先判断学生是否能学习可辨识物理量。
- **对应科学问题：** Q1（复数观测中可学习检测与参数），Q2（教师知识可靠性与蒸馏收益），Q3（物理真值与传统教师如何结合）。R3 只提供这些问题的传统 H0/H1 基础证据，不验证神经网络，也不验证蒸馏。

## 审查结论

**阶段决定：REFINE。** 预注册的 T0 原分数和两个有界候选均完成，实验与数据正确性门 G1 通过。T1/T2 通过幅度/整体尺度 G3 及可辨识 H1 保护 G4，但所有 B3-based 方法均未通过固定阈值迁移 G2。因此冻结的 R2 前置条件不满足；本阶段没有运行 E1 truth-only pilot、E2/E3 蒸馏、正式多 seed 训练或 final blind。

建议把下一步唯一优先事项定为：**提交一份独立的 truth-only 学生 pilot 协议提案，评估无需传统教师阈值门即可测试任务级学生基础学习的可行性，并为学生本身预注册独立 H0 校准/验证及任务门。** 该提案仍须独立审查/批准后才可运行，且不得加入教师损失、K1/K2 或 final blind。这样可将研究带回总纲中的学生任务主线，同时不抹掉教师阈值未通过的结果。

## 与总体研究目标的关系

R3 是支持学生/教师路线的基础工作，不是 CFAR 方向扩展。实验显示，T1/T2 在当前合成静止杂波下都能检测可辨识目标，特别是部分重叠 C 条件；但 Pfa 的独立固定阈值迁移没有达到冻结要求。T1 的检测和参数表现总体优于 T2，因此可作为后续教师前端候选保留；在 G2 通过前不能将其称为已选定教师。T2 的局部参考背景受目标峰污染，C 条件下 Doppler RMSE 升至约 23 Hz，限制明显。

重要新证据是 H0 整体尺度受潜在目标参考幅度 `A` 驱动：噪声功率按 `A²×10^(-SNR/10)` 生成，杂波随噪声按 CNR 缩放。该机制存在于 H0/H1 共用的场景生成模型中，不是标签分支泄漏；它使 T0 绝对功率阈值跨幅度明显失稳。T1/T2 在受控 `X,aX` 上满足整体尺度不变性，并通过预注册的幅度 Pfa 子门。

R3 不能证明整体尺度 nuisance 是 E001 `Pfa=0.0898` 的唯一原因。冻结 B3 阈值在 R3 新的 16,384 个 H0 上 `Pfa=0.064636`（Wilson 95% CI `[0.060972,0.068504]`）。以该点估计计算，E001 的 `23/256` 验证尾概率为 0.07019；同时校准/验证层级 bootstrap 达到该值的比例为 0.0216。有限样本可能解释一部分，但不应消解幅度机制证据或阈值门失败。

## 科学假设审查

1. **固定 5% 阈值在当前主条件迁移：不支持。** 新独立 H0 仍给出偏离 0.05 的点估计/区间，三个新重复校准也未全部通过。
2. **绝对 T0 分数受整体幅度 nuisance 影响：支持（当前仿真限定）。** 按预注册幅度箱分层，T0 的最高/最低箱 Pfa 极差约 0.169–0.216。
3. **可观测归一化改善尺度不变性：支持。** T1/T2 的 G3 均通过，但总体阈值迁移的联合假设尚未成立。
4. **归一化候选可保持可辨识 H1 检测任务：支持（当前合成条件）。** 两候选均通过 G4；T1 的 H1 结果最好。
5. **归一化统计量已可用作稳定传统教师：尚未证实。** G2 是明确失败门，不能由 G3/G4 替代。
6. **蒸馏在静止杂波任务带来收益：未检验。** 不能把 D1 的有限证据外推为 R3 或 D2-A 的蒸馏结论。

## 对原研究方向与路线的判断

Q1 仍值得检验；R3 没有证明任务级学生无法从三通道 IQ 学习。反而，A/B/C 的物理真值与参数指标仍显示可辨识任务空间，T1 的强 Pd 表现说明静止杂波下存在可利用的检测结构。Q2 的前置基础仍不完整，因为可靠教师阈值未通过。继续增加 CFAR 窗口或统计量搜索的边际科研价值低，也会让路线偏离学生目标。

因此建议对动态技术路线作**有限调整提案**：另行设计 truth-only 学生 pilot，由学生输出自己的 detection/range/Doppler，独立校准其 H0 决策分数；先测基础学习与物理一致性，不训练教师损失。该提案不能自动豁免旧 R2/R3 阶段门，须独立审查批准并预注册，之后才可运行。若该路线被否决，则维持学生训练暂停，并仅在独立分析能定位 G2 失败原因时再开展有限 H0 统计分布检查。研究总纲保持不变。
