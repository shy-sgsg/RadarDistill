## 阶段判断

1. **仿真/数值正确性：通过。** 冻结的波形近似、噪声机制、数据复现、通道方向响应和边界门均达到预注册标准。
2. **教师接口可用性：通过但有条件。** 原生软频谱、4 倍补零硬 Doppler、检测分数与连续距离估计的接口行为通过正确性检查；检测 AUC 门只规定在 -10 dB 通过，低 SNR 教师表现较差。
3. **学习与蒸馏：未检验。** D0 未训练任何学生，不提供 G1、G2 或 G3 的证据。

据此 **GO → D1**：允许冻结 D1 协议并开始学生 pilot。D1 需在 RTX 3050 CUDA 上顺序训练，CPU 不得回退；需使用独立的训练、验证、pilot、校准和最终盲测数据。

## 适用边界

本审查仅覆盖矩形 LFM 的简化 sinc 距离响应、固定距离窗、单目标/无杂波复 AWGN、APX15 仿真几何前三通道，以及 CPU FFTW 慢时间 FFT 子链。它没有验证完整快时间距离压缩、APX15 全部生产模块、CoreX 执行、实测通道标定、系统级虚警率或边缘速度，也没有证明学生优于 FFT/ML 或受益于蒸馏。
