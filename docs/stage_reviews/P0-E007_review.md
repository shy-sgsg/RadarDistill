# P0-E007 阶段审查

**审查日期：** 2026-10-24  
**阶段决策：GO（进入 P1-A 方案登记与设计；尚未开始 P1-A 训练）**  
**阶段门：G1 PASS，G2 PASS，G3 FAIL**

E007 是在 P0-E006 历史 STOP/REDIRECT 之后，经单独批准和预注册执行的新诊断。E006 的盲测、结论和审查均保留；本报告仅更新当前 P0 阶段判断。所有 E007 结果均来自单目标复慢时间序列加复 AWGN 仿真。

## 1. 研究问题和范围

E007 比较复数频率估计的三类学习架构，分别考察频谱物理归纳偏置、FFT 加学习修正、直接序列建模。目标是判断它们是否能学习稳定的频率映射、泛化至独立数据及传递教师知识。实验保持 PRF=1300 Hz、N=130、连续无模糊区间、随机初相和幅度；不含杂波、通道失配、多目标、加速度或运动补偿误差。

设计说明、冻结协议和实现分别见 [E007 设计文档](../superpowers/specs/2026-10-23-p0-e007-design.md)、[E007 协议](../../experiments/P0-E007/protocol.md)、[训练入口](../../scripts/run_p0_e007.py)、[模型实现](../../src/radardistill/torch_models.py)。

## 2. 模型设计与前端归属

| 模型 | 结构 | 前端性质 | 进入正式阶段 |
|---|---|---|---|
| M1 | 16N 点复 FFT；log-power 与相邻谱线归一化复互谱特征；三层 circular Conv1d；2080 点循环频率响应 | FFT 固定、不可学习；卷积频谱读出可学习。不是学习式 FFT，也不是直接 IQ 端到端模型 | 是，E1 三种子及三种蒸馏策略 |
| M1-power | 与 M1 同样的固定 FFT 和循环卷积，仅 log-power 输入 | M1 的相干特征消融 | 是，E1 三种子，不做蒸馏 |
| M2 | 固定 4N FFT 找粗峰；9 个局部 bin 的 27 维特征；64/32 隐层 MLP 预测限制在半个粗栅格内的修正 | 固定 FFT 前端 + 学习修正，是混合方法 | 否，未通过预注册 screen 门 |
| M3 | 130 个归一化 I/Q token；2 层、d=32、4 头、FFN=64 Transformer；2080 点循环频率响应 | 直接 IQ 序列输入，不使用 FFT 特征 | 否，单种子 screen 未通过 |

M1 的固定 FFT 将频率调制映射为频谱循环平移，circular padding 卷积使读出保持频率轴平移结构；相邻复互谱用于表达相邻 bin 的相干相位并消除公共初相。M1-power 用于区分相干特征贡献与频谱功率/循环卷积贡献。

M2 必须按混合方法解释。其学习收益要与同一局部频谱窗口的经典估计比较；FFT 粗峰及局部抛物线不是神经网络贡献。M3 的单种子 screen 是对该小型配置的诊断，不等价于对所有 Transformer 结构的否定。

## 3. Screen 结果与停止依据

所有 screen 使用同一训练/验证数据种子、FP32、batch 64、学习率 0.001、最多 160 轮、patience 40。screen 开发指标沿用已多次用于诊断的 E005 development benchmark；它不是最终测试。

| 路线 | 验证损失首轮→最佳 | 20 dB 开发 RMSE (Hz) | 诊断和决定 |
|---|---:|---:|---|
| M1 | 1.6877→1.2728 | 0.03862 | 验证降幅 24.6%，结构频移检查通过，五个主 SNR 点均优于 N 点 FFT 峰；进入三种子 E1 |
| M1-power | 1.6714→1.2748 | 0.03567 | 作为 M1 输入消融保留；不据此增加架构搜索 |
| M2 | 0.032951→0.031577 | 0.09585 | 验证目标仅下降 4.2%，未达冻结的 20% 条件。20 dB 开发 RMSE 比 N 点 FFT 插值好 1.1370 Hz，但比同窗口 4N 局部抛物线差 0.06179 Hz、比连续局部 profile-ML 差 0.06270 Hz；不做正式三种子训练 |
| M3 | 6.9966→6.9966 | 371.30 | 训练 loss 7.0446 降至 5.5794，验证从首轮最优 6.9966 升至 7.6346；20 dB 误差接近常值预测 376.09 Hz，且五个主 SNR 点均未胜 FFT 峰。表现与明显泛化失败相符，按冻结规则停止 |

M2 与其要求的三种参照均在相同 development benchmark 上比较。0–20 dB 下，M2 对 N 点 FFT 插值、同局部 4N 抛物线和连续 profile-ML 的 RMSE 差列于 [analysis.md](../../experiments/P0-E007/analysis.md)；由于 M2 没有通过 screen，不报告最终盲测 CI，也不宣称 M2 的泛化收益。其局部特征与子栅格平移结构测试通过，所以负结果没有显示出已知实现错误；但验证改善弱且与匹配解析估计差距明显，不值得用追加训练掩盖。

M3 的训练损失持续下降而验证损失恶化，提示过拟合/泛化失败；单种子无法唯一归因于架构、优化或样本量。协议的停止决定只针对本次宽度、层数、预算和输入设定。

## 4. 正式 E1、教师目标和蒸馏

正式 E1 使用三个独立训练种子 17101、17202、17303，以及对应验证种子 37101、37202、37303。M1-power 使用相同正式数据种子。M1 入选后才训练蒸馏变体，避免用蒸馏损失补救尚未证明基础能力的架构。

- **E1 真值监督：** 物理仿真频率真值。
- **E2-H 硬教师：** FFT 初始化局部 profile-ML 的连续点估计，以圆周频率目标编码训练。
- **E2-S 软教师：** 16N 网格 profile-likelihood 归一化响应。
- **E3-S 联合监督：** 物理真值损失 + 0.5 倍软响应损失。

真值、硬教师和软响应分别存储；教师估计不覆盖物理真值。E1 完成后才开展 E2/E3。所有训练顺序使用 CUDA 运行，最终 blind 之后没有重训或选模。

### 基线和教师配对结果

在五个主 SNR 点，M1 E1 对 N 点 FFT 峰、N 点插值、相位差和 16N FFT 峰值的 candidate-minus-baseline RMSE 95% bootstrap 区间上界均小于零。20 dB 关键差值为：

| 比较 | RMSE 差 (Hz) | 配对 95% CI | 解释 |
|---|---:|---:|---|
| M1 E1 − N 点 FFT 峰 | -2.89284 | [-2.95283, -2.83217] | M1 显著更好 |
| M1 E1 − N 点 FFT 插值 | -1.19565 | [-1.21416, -1.17678] | M1 显著更好 |
| M1 E1 − 相位差 | -0.16361 | [-0.17177, -0.15570] | M1 显著更好 |
| M1 E1 − 16N FFT 峰 | -0.14751 | [-0.15336, -0.14179] | 固定频谱前端上的学习读出通过匹配门 |
| M1 E1 − 连续局部 profile-ML | +0.00412 | [+0.00120, +0.00816] | ML 显著更好 |
| M1 E1 − 4N 局部抛物线 | +0.00352 | [+0.00061, +0.00766] | 插值显著更好 |
| M1 E1 − M1-power E1 | +0.00222 | [-0.00057, +0.00660] | 未证明相干输入有增益 |
| E2-H − E1 | -0.00205 | [-0.00599, +0.00096] | 区间包含零 |
| E2-S − E1 | +0.07889 | [+0.07084, +0.09075] | 软教师学生明显更差 |
| E3-S − E1 | +0.00884 | [+0.00151, +0.01515] | 联合训练更差 |

M1 在 20 dB RMSE 为 0.03899 Hz，约为 CRLB 标准差的 1.14 倍；M1-power 为 0.03677 Hz（1.08 倍），连续 profile-ML 为 0.03487 Hz（1.02 倍）。学生接近正确模型下的强估计器，但未胜过连续 ML 或高精度局部插值；本项目不要求它超越 ML。N 点基线的主要改进不能解释为“超过所有经典方法”。

M1 对 M1-power 的五个主 SNR 配对区间均包含零，且功率模型点估计略好。因而，E007 支持“固定频谱表示 + 循环读出能学得精确频率”的结论，不支持“相邻谱相干通道提高单通道单音频率精度”。这不否定相对通道相位在 P1 中的作用，因为 E007 没有跨通道相位目标。

E2-H 在 20 dB 略好但区间包含零，五个主 SNR 无满足预设的稳定显著增益；E2-S 和 E3-S 均明显差于 E1。G3 的区间/种子联合要求无一主点通过，不存在两个相邻收益点。故蒸馏未证明额外价值；不应把 E2-H 的小幅点差或训练损失下降称为蒸馏成功。

## 6. 误差分组与物理一致性

- 20 dB 下 M1 的八个频率分箱 RMSE 跨训练种子范围为 0.0329–0.0512 Hz；八个初相扇区为 0.0326–0.0469 Hz；幅度四分位为 0.0335–0.0455 Hz。
- 带噪测试的 Nyquist 边界带每个 SNR 约 13 个样本，20 dB RMSE 与内部频带接近，但样本量不足以单独证明边界误差等同。独立无噪声边界子集上，3 个 M1 E1 种子 MAE 均低于 0.026 Hz，P95 均低于 0.034 Hz。
- 三个 E1 模型的公共相位旋转最大预测变化分别为 0.01221、0.00647、0.00598 Hz；复数尺度变化最大值分别为 0.01782、0.00903、0.00891 Hz。
- 0.625 Hz 频移的最大等变误差分别为 0.01245、0.00671、0.00610 Hz。结构单元测试中，M1 的 16N 整 bin 频移为循环滚动，M2 的局部输入和残差在整 4N bin 平移下不变。M3 不满足小误差频移等变（筛选最大误差约 38.45 Hz），与其频率泛化失败一致。

公共相位旋转不变性是对单通道频率估计的检查，不等于三通道相位信息保留。P1-A 应直接使用/验证跨通道相对相位或复互相关表征，并设置解析相位估计基线。

## 7. CUDA 和训练资源

训练使用 NVIDIA GeForce RTX 3050 Laptop GPU，4 GiB；PyTorch 2.8.0+cu128、CUDA 12.8、Python 3.13.7。所有 M1/M2/M3、正式 E1 和蒸馏训练均用 `cuda:0`、FP32、batch 64，顺序运行；数据按 batch 从 CPU 主存传入。M2 screen 单实例 peak allocated 17.4 MiB，M3 为 59.7 MiB，正式 M1 E1 最高 71.0 MiB，全部正式训练单实例峰值不超过 71.1 MiB。硬件整体 `nvidia-smi` 快照显示测试时可用显存约 2.06–2.47 GiB。

M1 screen 的 checkpoint 和完整 epoch 历史已恢复并用于筛选，但其单次 wall time/peak allocated 未持久化；后续三个正式 M1 E1 运行均有完整时间与显存记录。该遗漏在 `attempts/screen_m1_complete_stage_error.json` 记录，没有影响筛选指标或后续正式对比。

## 8. 阶段门判定

| 阶段门 | 判定 | 依据 |
|---|---|---|
| G1 学习可行性 | **PASS** | 纯相干 M1 的 3/3 种子在连续无噪声全频及 Nyquist 子集达到 MAE<1 Hz、P95<5 Hz；20 dB RMSE 均比零频预测低至少 50%；随机相位/幅度、边界周期和数据种子隔离检查通过 |
| G2 传统算法竞争力 | **PASS** | M1 对 N 点 FFT 峰的配对 CI 在五个主 SNR 点均低于零；M1 对匹配固定前端的 16N FFT 峰同样五点通过 |
| G3 蒸馏价值 | **FAIL** | E3-S 相对 E1 无一个主 SNR 点满足冻结的区间和种子一致性联合条件；20 dB 反而显著更差 |
| 当前阶段决策 | **GO** | 按独立门规则，G1 与 G2 通过允许 P0 进入下一阶段；G3 失败保持为独立的负结果 |

GO 仅代表 P1-A 方案设计和预注册可开始。它不代表蒸馏有效、不代表学生全面优于传统算法，也不意味着单通道结论可外推至三通道 GMTI。P1-A 训练尚未启动。

## 9. 后续研究判断

P0-E007 证明本条件下的小型频谱卷积网络可以从单通道复观测稳定估计连续频率，并以较大幅度超过 N 点离散基线；在 20 dB 仍略落后于接近 CRLB 的 profile-ML 和高精度局部插值。其固定 FFT 前端和循环读出具备频率平移归纳偏置，但 M1-power 消融未显示频谱相干通道对单音频率精度有额外收益。E3-S 没有蒸馏增益，软教师响应反而损害性能。

可进入最低复杂度 P1-A，重点转为跨通道相对相位是否可辨识、相干关系是否在相位噪声/幅度失配下可学习。P1-A 开始前需另行冻结三通道观测模型、复互相关/相位差等强解析基线、相位周期统计、独立系统/噪声种子和验收门；不要沿用本次单音网络结论作为 P1 的成功假设。
