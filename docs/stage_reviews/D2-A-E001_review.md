## 1. 工程正确性结论

**结论：PASS（限定于明示的合成研究模型）。** R0 逐脉冲按 `L=R_tx+R_rx` 合成传播相位和距离响应；静止散射点 Doppler 来自平台运动和观测几何。三通道由同一散射集合、系数与热噪声背景生成，H0/H1 配对且 `H1−H0=target_signal_iq`。T1–T12 全通过；T2 明确比较通道间实测相位差与双程路径解析相位，T7 用实际生成场景核实请求 CNR 与组件功率比。

发现并修复一项影响结果报告的统计单位错误：旧代码对 squared error 做 mean bootstrap 后直接称为 RMSE CI，实际单位为 MSE。现在每次 cluster bootstrap 对平方误差先算 `sqrt(mean(squared_error))` 再取 percentile；新增回归测试，重新运行完整开发实验并重生成 `metrics.json`、CSV、图和分析。RMSE 点估计没有改变；更新报告分别列出 Range 单元和 Doppler Hz 区间，漏检只通过 joint success 计为失败。

实现依赖研究假设：发射相位中心与平台参考原点共址；平地、点散射、理想校准、方位 Gaussian 主瓣、D0 sinc PSF 和独立复 AWGN。实际 Tx 相位中心、通道校准、二维方向图、地物统计和运动补偿误差未验证，因此不能称为生产链物理复现。

## 2. 实验科学性结论

**结论：CONDITIONAL PASS。** 设计把新增因素限定为静止地杂波，按 A/B/C/D 分层；传统基线包括单通道、三通道非相干、几何相干搜索和候选 DPCA；阈值使用独立 H0 calibration，不在开发 H0 上调参；区间按 scene cluster bootstrap。方法和教师含物理前端，报告没有把其归为纯学习证据。

## 3. 研究主线一致性结论

D2-A 从 D1 的复 AWGN 单目标任务转到共享三通道相干静止杂波，直接检验空间—时间结构、传统杂波抑制和可辨识性，服务于总纲的检测与参数估计问题。结果表明：单纯增加通道数不自动带来抑制；适用几何的 DPCA 对分离目标有显著收益；目标进入 clutter support 后 Pd 下降；精确同流形时单 CPI 无法唯一归因源分量。这为学生和教师知识设计提供了可证伪问题，但没有证明学习模型会受益。

本阶段没有读入原始 ADC，没有引入复杂地物/多目标/通道失配，没有测完整链速度，也未证明真实 GMTI、系统级虚警或部署价值。D1-E002 既有 STOP/REDIRECT 负结果继续保留；D2-A 没有把它们改写成学生优于传统方法的证据。

## 4. 创新性与论文价值判断

**尚未建立研究创新结论。** 逐点几何仿真、FFT、波束形成、DPCA 都是验证工具或已有方法。当前的研究价值在于受控刻画可辨识边界、建立三通道配对真值和考察 K1 频谱/K2 杂波残差/K3 任务输出之间的教师可靠性。只有后续同架构、同预算、独立种子的 E1/E2/E3 显示可重复学习或蒸馏增益，并与公平传统基线对比，才能支持论文级方法主张。

## 5. 总判断与阶段门

**总判断：REFINE。阶段状态：CONDITIONAL GO。** R0/R1 给出可辨识场景和通过门的 DPCA 基线，说明后续任务级学习仍有可检验价值；但主工作点固定 H0 阈值的独立迁移尚未通过，所以当前仅允许阈值迁移诊断，不允许 D2-A-E001 学生训练、KD 或 final blind。

R2 已纠正为复用 D1-E001 已验证 `TaskStudent`：原时间卷积骨干和 K3 推理头不变，K1/K2 是导出时删除的 training-only soft-map 辅助头。三组蒸馏与真值监督匹配为每组/seed 1,600 更新、有效 batch 64。该修正不因 R1 结果更改目标或阈值。

## 6. 下一步唯一优先任务

**用全新 base-scene seeds 预注册并执行独立阈值迁移/幅度 nuisance 诊断。** 冻结当前方法分数、阈值计算、允许幅度变化、`Pfa_CPI` 接受标准和区间统计；分离校准场景与诊断 H0，固定阈值应用于未见 H0，不用开发 H0 选择分数或门槛。通过后只启动一 seed、truth-only、D1 结构的 E1 pilot；若固定阈值仍失稳，则先改进并重新冻结检测统计量，不做教师蒸馏。

## 7. 证据缺口与适用范围

- 本模型不含真实地物、旁瓣、地形、相关杂波、发射/接收硬件相位误差或生产运动补偿残差；`Tx` 共址是未验证研究假设。
- 当前开发场景已用于设计解释，不是 final blind；最终盲测 seeds 仍保留未物化。
- 尚无学生训练结果，故不能回答哪种学生最优、K1/K2 是否有增益、学习是否降低完整链成本。
- 当前没有 D2 学生 data loader；T9 测试验证 target truth 改变不影响 H0 背景/噪声，T12 验证 H0/H1 有相同形状和物理组件，但“未来训练文件顺序/标签编码无捷径”仍需在 loader 实现时单独验收。
- 没有拟合真实杂波协方差的 Oracle、全维 STAP 或适用的 `10⁻⁶` 虚警数据；这些限制不能被低样本开发 AUC 替代。

## 面向原任务的十项回答

1. **本轮实际开展：** 实现并测试 D2-A 物理仿真、H0/H1 配对、B0–B3 和独立 H0 校准；运行 48 个开发结果；修复 bootstrap RMSE 区间单位错误并完整重跑；冻结 D1 学生基础结构的 R2 草案。没有训练学生或生成盲测。
2. **静止杂波模型可信度：** 在“平地、独立静态点散射、双程几何、理想通道、Gaussian 主瓣、sinc 距离响应”范围内有解析路径、慢时间/跨通道相位和配对测试支持；对真实 APX15 杂波的统计代表性未知。
3. **三通道相干：** 三通道共享散射点与复系数；T2/T5 对照路径相位，B3 通过静止杂波抵消/目标保留检查，故可以测试相干基线。它没有验证实际通道标定。
4. **可辨识条件：** A 在理想 clutter Doppler support 外，B 处在小于一个 FFT 间隔的谱边缘，C 在谱内但仍有部分几何/范围线索，D 与静止散射点同流形而源分解非唯一。
5. **传统 GMTI 性能：** 表格给出 B3 的 Pd、Pfa、AUC、Range/Doppler RMSE 和 joint success；静止杂波中位抑制 15.406 dB。A/B 强、C 部分可检测、D 近随机。B0–B2 在 A/10/10 dB AUC 约 0.5。
6. **传统方法瓶颈：** B0–B2 未做杂波抵消，受强静止地物支配；B3 的 CNR 20 dB partial-overlap Pd=0.230/AUC=0.628，显示谱/几何重叠困难。D 是观测不可辨识边界。Pfa 偏高原因尚不能区分有限样本、score nuisance 敏感性或仿真假设，不能先验归咎于算法失配或计算成本。
7. **值得蒸馏的知识：** K1 RD soft response 可传频谱结构但丢失跨通道相位且可能让学生拟合杂波；K2 DPCA saliency 更靠近检测目标但可能误抑制低速/重叠目标；K3 hard detection/估计适合诊断，不替代物理 truth。本轮分别保存，不预设 teacher 正确。
8. **下一步学生：** 保留 D1 `TaskStudent` 直接 IQ backbone 与 K3 presence/range/Doppler 推理头；只加训练期 K1/K2 图头并导出时删除。不加 Transformer、不扩大结构、不引入 angle/multitarget 回归。
9. **是否启动 D2-A-E001：** 当前不启动正式训练或 final blind。阶段为 CONDITIONAL GO，仅在独立阈值迁移前门通过后做一个 truth-only E1 pilot；基础学习不通过则停止 KD。
10. **唯一优先任务：** 新 seeds 下固定阈值迁移和幅度 nuisance 诊断；它直接处理当前唯一阻塞证据，并决定是进入 E1 还是先修订冻结的统计量。
