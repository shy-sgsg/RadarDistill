# 研究方案

## 研究背景

机载多通道 GMTI 需要从相干复回波中抑制静止杂波，并估计目标多普勒、速度和空间参数。DPCA、ATI、STAP、谱估计和似然方法建立在物理模型上，可解释且提供可靠基线；其性能会受通道误差、非均匀杂波、有限训练样本和模型失配影响。近年的雷达学习工作涵盖汽车 FMCW 原始 ADC 感知、STAP 展开网络和自监督 MTI，但数据体制、阵列/通道几何、任务输出和验收指标并不相同，不能直接移植结论。

本项目的主目标是最终任务级学习：用传统 GMTI 处理链和物理仿真真值共同指导学生，逐步训练其从三通道复数雷达回波直接完成检测与参数估计。传统频谱、抑杂、CFAR 等知识可以用于训练，但学生不必逐个复刻传统中间模块。研究路线为 D0 可信仿真/教师、D1 最小检测与估计任务、D2 三通道复杂条件、D3 原始回波迁移、D4 计算优化和 D5 系统验证。P0/P1 单模块实验保留为历史先导结果，不作为新主线的串行前置门。实时性只在阶段任务与公平计时边界明确后评价。

## 科学问题

研究 Q1–Q6 见根目录 `AGENTS.md`。本方案聚焦：传统教师知识能否改善最终检测/估计任务；学生是否必须显式复现传统中间变量；逐步撤除教师监督是否保留最终任务能力；物理仿真真值和教师估计如何分离；三通道观测在什么几何与信噪条件下支持可辨识估计。

## 研究目标与假设

1. **任务学习：** 在 D1 的单目标 H0/H1 条件下，直接 IQ 学生应在独立样本上同时学到检测、监视窗距离和连续 Doppler；无噪声/高 SNR、常值预测、边界、幅度和初相测试用于排除数据捷径。
2. **教师价值：** 同一学生、数据和总优化步数下，B/C/D 至少一种教师引导方案可能改善收敛、样本效率或独立最终指标；收益必须由预注册统计比较支持。
3. **中间变量：** 全图 RD 软响应可能提供有用相干信息，也可能只增加训练负担。学生最终推理不必输出 RD 图；辅助分支移除后仍须保持真值任务性能。
4. **前端移除：** D1 从距离压缩 IQ 开始，后续只有阶段门通过才将输入前移到未压缩回波；不预设端到端模型必然优于保留物理前端的混合模型。
5. **联合任务：** 检测和参数估计可共享三通道特征，但漏检、错误检测和条件参数误差需分别评价；几何不可辨识的量不作为学生应当猜中的目标。
6. **性能权衡：** 学生不必同时在速度和精度上超过传统链。一项优势成立时，另一项须满足预先冻结的最低门槛；当前 D1 不做正式实时性验收。

## 研究内容和技术路线

旧路线 P0/P1 的模型与阶段决定作为历史先导档案保留。当前新主线 D0→D5 以及完整的理论、数据、算法、指标、阶段门、失败原因和备选路线见 `docs/research_plan.md` 和 `docs/research/D0_D1_design.md`。

### 历史 P0 信号模型

\[
x[n]=A\exp\{j(2\pi f_d n/\mathrm{PRF}+\phi_0)\}+w[n],
\quad w[n]\sim\mathcal{CN}(0,\sigma^2).
\]

采用连续均匀频率覆盖 \([-\mathrm{PRF}/2,\mathrm{PRF}/2)\)，随机初相、幅度和 SNR。该模型用于 P0 历史实验；其教师最大似然由连续周期图最大化得到，真值、教师值、软目标和学生输出分别存储。D0/D1 使用固定距离监视窗上的三通道复数回波，按 `docs/research/D0_D1_design.md` 建模和评价。

## 历史 P0 实验设计与评价

P0 基线包括 N 点 FFT 峰值、对数幅度三点抛物线插值、单滞后相位差和连续频率最大似然。学生是 2 通道输入的轻量 Conv1D，输出频率的 sin/cos 表示以处理 Nyquist 周期边界。训练分为真值监督 E1、纯教师蒸馏 E2、真值+教师联合 E3。训练/验证/测试分别生成且测试不参与选择参数；模型重复训练三个随机种子。

报告 MAE、RMSE、偏差、半个 FFT bin 阈值下的异常值率、逐 SNR/频率/初相/幅度/FFT 栅格偏移误差、CRLB、种子间变异和 E3−E1 配对 bootstrap 区间。P0 无杂波和检测任务，因此不对 Pfa 作结论。

## D0/D1 实验设计与评价

D0 生成 H0/H1 三通道复数距离压缩慢时间数据，大小为 130×32 个慢时间/距离单元。固定参数为 PRF=1300 Hz、N=130；连续距离/频率、随机相位/幅度和三通道导向响应均由仿真真值单独保存。传统教师使用 APX15 Doppler FFT 子链适配器提供全图响应和检测/参数候选，不读取真值。

D1 学生使用时间感受野覆盖 130 脉冲的轻量二维 TCN，直接输出检测、连续距离单元和连续 Doppler。比较 A 真值监督、B 教师预训练后真值微调、C 联合监督和 D 渐进蒸馏；四组最终推理结构和总训练预算相同，最终推理删除频谱辅助头。具体样本数、loss 权重、训练阶段步数、独立种子、检测阈值校准及 GO/STOP 门槛在训练前冻结于 `experiments/D0-E001/protocol.md` 和 `experiments/D1-E001/protocol.md`。

报告教师错误率/虚警、ROC/AUC、独立校准下的 Pd/Pfa 及 H0 机会数/区间，距离和周期 Doppler 误差的 SNR/边界分组，全部 H1 与正确检测条件下的参数误差、训练收敛/种子波动、完整方法成本。Pfa=1e-6 仅在样本规模或理论尾部模型足以支持时报告。D1 的吞吐/时延只作相同距离压缩输入边界下的初步参考，不作为整链加速证据。

## 预期成果

- 可复现的物理仿真、传统频率基线和轻量学习代码；
- 传统方法与三种学习训练策略的独立测试结果；
- 对学习有效性、泛化、蒸馏收益和 ML 差距的证据化判断；
- 后续三通道建模与实验设计依据。

这些是预期产物而非预先成立的结论。无真实回波、未运行实验或未核实引文不得被写成实测/已验证成果。

## 风险与备选路线

- **高斯单音过于理想：** P0 只作学习可行性门，不外推 GMTI 检测；按阶段增加噪声、通道误差和杂波。
- **传统 ML 已接近 CRLB：** 不以超越 ML 作为成功门槛；转向模型失配、训练样本限制和混合物理方案。
- **教师误差被学生继承：** 保留真值监督对照并独立分析教师错误。
- **周期边界/数据捷径：** 使用圆周误差、连续频率、随机相位和分组测试。
- **环境算力受限：** 当前 P0 用 NumPy CPU 实现并记录环境；只有性能瓶颈证据支持时再启用深度学习框架/GPU。
- **三通道参数不可辨识：** 先做几何和 Fisher 信息分析，不可辨识参数不交由网络猜测。
