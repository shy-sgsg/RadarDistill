# 研究方案

## 研究背景

机载多通道 GMTI 需要从相干复回波中抑制静止杂波，并估计目标多普勒、速度和空间参数。DPCA、ATI、STAP、谱估计和似然方法建立在物理模型上，可解释且提供可靠基线；其性能会受通道误差、非均匀杂波、有限训练样本和模型失配影响。近年的雷达学习工作涵盖汽车 FMCW 原始 ADC 感知、STAP 展开网络和自监督 MTI，但数据体制、阵列/通道几何、任务输出和验收指标并不相同，不能直接移植结论。

本项目采取由简到难的研究路线。首先用单目标慢时间复正弦信号检验频率是否可以从原始 I/Q 学得，再逐步加入三通道相位、参数耦合、杂波检测和多模块蒸馏。实时性是末期目标，不是现阶段目标。

## 科学问题

研究 Q1–Q6 见根目录 `AGENTS.md`。本方案聚焦：有限模型能否从复数观测提取可泛化的 Doppler 信息；教师标签能否在独立真值监督基础上提供额外增益；在真实回波不足时，物理仿真、传统教师和物理一致性是否构成可信训练信号；三通道参数能否在真实几何和可辨识条件下联合估计。

## 研究目标与假设

1. **学习可行性：** 在已知单音 AWGN 模型下，小型网络应在独立随机样本、随机初相位、连续频率和不同幅度/SNR 下优于常数频率猜测；若只在训练分布有效，则不视为学到稳健物理映射。
2. **蒸馏价值：** E3（物理真值+教师似然软目标）可能改善收敛或部分 SNR 的误差；该假设必须与 E1 真值监督作配对测试。若置信区间跨零或增益不稳定，则结论为没有充分蒸馏收益证据。
3. **模型边界：** 在正确的单目标复高斯模型下，连续最大似然是强参考；网络不必超过它。学习方法的后续价值更可能来自模型失配、复杂杂波、有限样本或混合物理/数据驱动处理。
4. **三通道价值：** 只有在三通道几何、相位误差和参数可辨识条件被显式建模后，才能研究网络是否改善相位、角度和速度估计。

## 研究内容和技术路线

阶段为 P0 单目标频率、P1 三通道相位、P2 联合参数、P3 杂波目标检测、P4 多模块联合蒸馏、P5 原始回波端到端、P6 边缘实测优化。完整的理论、数据、算法、指标、阶段门、失败原因和备选路线见 `docs/research_plan.md`。

P0 信号模型：

\[
x[n]=A\exp\{j(2\pi f_d n/\mathrm{PRF}+\phi_0)\}+w[n],
\quad w[n]\sim\mathcal{CN}(0,\sigma^2).
\]

采用连续均匀频率覆盖 \([-\mathrm{PRF}/2,\mathrm{PRF}/2)\)，随机初相、幅度和 SNR。教师最大似然由连续周期图最大化得到；教师软目标是在教师模式附近计算的局部 profile-likelihood 圆周均值。真值、教师值、软目标和学生输出分别存储。

## 实验设计与评价

P0 基线包括 N 点 FFT 峰值、对数幅度三点抛物线插值、单滞后相位差和连续频率最大似然。学生是 2 通道输入的轻量 Conv1D，输出频率的 sin/cos 表示以处理 Nyquist 周期边界。训练分为真值监督 E1、纯教师蒸馏 E2、真值+教师联合 E3。训练/验证/测试分别生成且测试不参与选择参数；模型重复训练三个随机种子。

报告 MAE、RMSE、偏差、半个 FFT bin 阈值下的异常值率、逐 SNR/频率/初相/幅度/FFT 栅格偏移误差、CRLB、种子间变异和 E3−E1 配对 bootstrap 区间。P0 无杂波和检测任务，因此不对 Pfa 作结论。

## 预期成果

- 可复现的物理仿真、传统频率基线和轻量学习代码；
- 传统方法与三种学习训练策略的独立测试结果；
- 对学习有效性、泛化、蒸馏收益和 ML 差距的证据化判断；
- 后续三通道建模与实验设计依据。

这些是预期产物而非预先成立的结论。无真实回波、未运行实验或未核实引文不得被写成实测/已验证成果。

## 风险与备选路线

- **高斯单音过于理想：** P0 只作学习可行性门，不外推 GMTI 检测；按阶段增加噪声、通道误差和杂波。
- **传统 ML 已接近 CRLB：** 不以超越 ML 作为成功门槛；转向模型失配、训练样本限制和混合物理方案。
- **教师误差被学生继承：** 保留真值监督对照并独立分析教师错误。
- **周期边界/数据捷径：** 使用圆周误差、连续频率、随机相位和分组测试。
- **环境算力受限：** 当前 P0 用 NumPy CPU 实现并记录环境；只有性能瓶颈证据支持时再启用深度学习框架/GPU。
- **三通道参数不可辨识：** 先做几何和 Fisher 信息分析，不可辨识参数不交由网络猜测。
