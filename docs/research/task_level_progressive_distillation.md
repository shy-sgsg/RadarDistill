# 教师引导的渐进式任务蒸馏

**内部方法名称：** Teacher-Guided Progressive Task Distillation。该名称暂作项目工作术语；完成文献核查与实验前不宣称学术新颖性。

## 目标

训练阶段充分利用传统雷达处理链和物理仿真真值；推理阶段尽可能移除教师、中间输出和传统前端。最终学生以三通道复数回波为输入，直接输出目标列表及其可辨识参数。学生可以采用不同于教师的内部表征，不需要按传统算法模块逐项仿制。

## 教师、真值和学生的边界

- **仿真真值：** 由受控物理生成器产生 H0/H1、目标数、连续距离/Doppler/角度、幅度、相位、噪声及杂波参数；用于最终任务监督和教师错误分析。
- **T1 工程教师：** 来自传统 GMTI 处理链，提供工程基线和可选中间响应、检测统计量及参数估计。D0 先适配 APX15 慢时间频谱/检测子链，并明确它不是完整 CoreX 处理链的等价替代。
- **T2 离线参考：** 后续可在有需要时采用高分辨搜索或连续参数优化，提供高精度辅助标签；教师仍不是真值。
- **学生：** D1 输入三通道距离压缩 IQ，输出检测、连续距离单元和周期 Doppler；最终推理不依赖教师输出。

所有 teacher/truth/student 字段分别命名和存储。教师漏检不得删除真实目标，教师假警不得更改 H0 标签。

## 渐进训练

1. **教师响应预训练：** 学生辅助分支拟合全图频谱软响应，不得按真值位置裁剪教师图。
2. **任务联合监督：** 真值监督检测和参数；谱响应仅作辅助损失。H0 不计算目标参数损失。
3. **教师权重退火：** 预注册方式降低谱损失权重，同时保持真值任务损失。
4. **去教师微调：** 删除频谱辅助头，只用真值训练最终任务模型。

D1 对照 A/B/C/D 分别代表直接真值、教师预训练后真值微调、教师/真值联合监督、渐进式蒸馏。四组匹配学生主干、数据和总优化步数。教师损失权重及阶段分配先写入冻结协议。

## 主线与阶段门

| 阶段 | 目标 | 允许的任务边界 |
|---|---|---|
| D0 | 可信物理仿真、传统教师、统一评价 | H0/H1、三通道、单目标、距离压缩 IQ |
| D1 | 直接检测、距离和 Doppler 估计；比较蒸馏 | 不加角度、多目标、杂波或通道失配 |
| D2 | 三通道参数与复杂场景 | 仅在 D1 阶段审查通过后逐项增加 |
| D3 | 原始回波渐进迁移 | 比较物理前端加学生及原始回波学生 |
| D4 | 结构和计算优化 | 仅在任务性能已可靠时开展 |
| D5 | 完整场景和系统验证 | 同硬件、同输入边界、全链路计时 |

D0 的仿真/教师正确性未通过时停止学生训练。D1 G1 未通过时先检查数据、标签、训练和信息可辨识性，不跳到复杂场景。蒸馏若不改善收敛、样本效率或最终指标，应如实记为无增益。若学生既无精度优势也无公平速度优势，不继续扩展模型。

## 评价边界

报告训练预算、样本数、随机种子、最终教师/学生误差和统计区间。检测报告 Pd/Pfa 和 H0 独立机会数；参数误差分别报告全 H1 和正确检测条件下的结果。速度比较必须覆盖同一输入边界下所有必需前后处理；训练收敛改善不能称为推理加速。Pfa=1e-6 未有足够独立背景样本或理论尾部依据时不作达标结论。

## 当前状态

2026-10-24 用户批准启用 D0/D1 新主线。D0 仿真与 APX15 慢时间 FFT 教师 12/12 冻结正确性门通过，阶段决定 GO → D1。D1 学生、匹配预算 A/B/C/D 训练、独立校准和最终盲测均已完成；G1 PASS、G2 PASS、G3 FAIL，阶段决定 GO → D2。C 联合训练与 D 渐进蒸馏通过最终任务指标收益规则，但没有蒸馏策略达到收敛加速规则；学生的传统参数估计竞争力仍不足。下一阶段须一次只增加一项复杂度。详细设置和审查见 `docs/superpowers/specs/2026-10-24-d0-d1-task-level-distillation-design.md`、`docs/stage_reviews/D0_review.md`、`docs/stage_reviews/D1-E001_review.md` 与 `experiments/D0-E001/`、`experiments/D1-E001/`。
