# D2-A-R7 传统教师正确性报告

**审查范围：** D2-A静止杂波几何DPCA（B3）及其K2归一化软频谱响应；不评价ACE/AMF、完整APX15生产链、实测传感器或教师蒸馏收益。

## 观测模型和实现

本研究配置采用复数相位`exp(-j 2π(R_tx+R_rx)/λ)`，通道0/1沿航向基线为`0.17 m`，平台速度`60 m/s`。当前发射相位中心与平台参考点共址是明确的、尚未实测验证的假设。固定几何时移公式为：

```text
delay_s = -dot(r_rx[1]-r_rx[0], v)/(2*dot(v,v))
shift_samples = delay_s * PRF = -1.841667
aligned_ch1[n] = periodic_fractional_shift(ch1, shift_samples)
B3[n,r] = ch0[n,r] - aligned_ch1[n,r]
```

NumPy实现对慢时间执行DFT分数移位；K2 CUDA复用同一几何公式和复数双精度移位，再归一化功率图。通道索引、正负方向、频轴和输出功率定义均可从`src/radardistill/d2a_baselines.py`、`src/radardistill/teachers/d2a_k2_cuda.py`及`src/radardistill/teachers/d2a_k2.py`追溯。

## 新实验摘要

R7-B使用新种子生成1,280个独立分离条件场景，分布在5组SNR/CNR组合。对纯静止杂波分量，补偿前复相干幅值中位数`0.8486`，补偿后`0.9858`；补偿后复相关相位绝对误差中位数`0.00209 rad`、95分位`0.00615 rad`；通道幅值比中位数`1.000012`。DPCA残差/输入通道功率中位数`0.02833`，对应杂波抑制`15.4781 dB`（场景bootstrap 95% CI `[15.4201,15.5401]`）。

静止杂波、噪声、目标、H0混合和H1混合分开测量；完整结果在[`R7-B analysis`](../../experiments/D2-A-R7/R7-B/analysis.md)和[`metrics.json`](../../experiments/D2-A-R7/R7-B/metrics.json)。噪声独立通道差分功率比约`2.0`（增加约3 dB），说明该差分不是噪声抑制器。目标分量未缩放功率比中位数`3.615`，可大于1，不是目标能量效率。

## 历史15.406 dB口径

E001中位15.406 dB是1280个分离开发场景里**纯静止杂波分量**的逐场景`-10log10(mean(|DPCA(clutter)|²)/mean(|clutter[channel0]|²))`中位数，不含热噪声或目标。目标未缩放差分功率比是另一统计量，历史中位`3.614`。R7-B以新独立种子复算得到15.478 dB，差`0.072 dB`，新旧95%区间重叠。因此历史结果的公式和量级得到独立复核；它不代表单元级Pfa、目标检测Pd或真实硬件抑制量。

## CPU/CUDA与测试

在AISAR `Python 3.13.7 / NumPy 2.3.4 / PyTorch 2.8.0+cu128 / RTX 3050 Laptop`上，CPU与CUDA K2 map在五组条件的首批纯杂波/H0/H1输入最大绝对差为0；`1e-6`容差通过。GPU峰值分配9.59 MB。测试`tests/test_d2a_k2_cuda.py`和`tests/test_d2a_r7_teacher_diagnostics.py`共12项通过。其余解析测试覆盖1/4个静止散射体、独立噪声、运动目标、混合有限CPI和通道交换符号。

## 对阶段门与教师资格的回答

1. **DPCA是否符合其数学模型？** 在配置声明的共址Tx、坐标和双程传播假设下，时移符号、通道顺序及差分公式通过解析和随机分量检查；没有发现明确软件实现错误。
2. **相干度及残余如何变化？** 纯静止杂波中位相干幅值从0.849升至0.986，残余功率比中位0.0283，补偿后相位残差95分位0.00615 rad。
3. **幅度误差如何？** 通道0/对齐通道1功率均方根幅值比中位1.000012，5–95分位约0.9972–1.0027。
4. **15.406 dB说明什么？** 它是纯杂波、相对单输入通道、未加额外幅度缩放的中位残差抑制；新独立结果15.478 dB支持历史定义与数量级。
5. **CPU/CUDA一致吗？** 在R7-B抽样上归一化K2输出最大差0，并通过12项AISAR测试；该结论限于当前K2计算路径。
6. **当前教师何时可信？** B3/K2可用于当前仿真假设下的静止杂波相干抵消与频谱支持诊断。它不是通用检测器、非杂波场景的最佳参数估计器，也没有证明在所有重叠场景可靠或能教会学生。
7. **哪些限制仍在？** 共址Tx和相位中心配置尚无真实设备验证；有限CPI使用周期分数移位；教师任务检测率和蒸馏收益需要其他阶段指标单独判断。

**R7-B结论：** `PASS_LIMITED_TO_DECLARED_SYNTHETIC_MODEL`。这项局部正确性证据支持在对应合成仿真中继续把B3/K2作为候选传统参考；不构成真实软件/硬件资格，也不解除R7-D/E比较门。
