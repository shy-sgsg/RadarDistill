# D2-A 知识吸收机制研究

## 目标

区分“教师知识与学生表现相关”与“该知识/物理关系被学生吸收并带来任务收益”。在知识内容 pilot 有正向结果后，以独立干预研究公共相位旋转、目标整体频移、通道间相对相位、目标/杂波强度及 overlap 条件。

## 设计

- 记录教师/学生在同一 H0/H1 样本上的四格正确性：双方正确、仅教师正确、仅学生正确、双方错误；估计知识冲突和可能的负蒸馏区域。
- 仅对可观测输入施加预先指定的复相位、频移和相干扰动；真实物理标签按已知变换映射。测试响应需匹配模型声明的等变/不变属性。
- 目标与杂波强度变化分别操纵，报告 C0–C3、SNR/CNR 和可辨识性层；D 精确同流形只作边界参照。
- 梯度范数/方向仅作训练诊断，不单独证明知识机制。若干预改变任务性能但路径不明确，记录为机制证据未决。
- 使用新独立样本；参与架构/策略选择过的 E003 开发集不能作为最终机制盲测。

## 配对错误诊断工具

R5-D准备阶段复用 `evaluation/physical_consistency.py` 汇总同一场景上的教师/学生错误对应关系：presence在H0/H1分别评价；距离和PRF周期Doppler在H1分别对照真值；joint成功必须同时满足检测与两个参数门。每个任务按双方正确、仅教师正确、仅学生正确、双方错误报告计数，并提供学生相对教师正确率差的 `base_scene_id` 簇bootstrap区间。配对H0/H1可共享同一base scene ID并作为一个簇重采样；该区间不代表训练seed不确定性。

调用方必须确保teacher/student数组按相同scene ID对齐，并提供各自独立H0校准得到的检测阈值。错误对应表是描述性诊断，不能单独证明知识迁移的因果机制。R5-C独立方向审查与匹配T0–T3 pilot完成前，不运行学生侧比较或把跨阶段结果按场景强行配对。

H0只评价检测正确性；H0没有目标距离/Doppler真值，因此对应参数字段可以缺失或为非有限值，参数指标只使用H1记录。

## Doppler 频移响应评估接口

`summarize_prediction_intervention` 可选接收对齐的 `scene_ids` 和 bootstrap 设置，对相位、幅度、通道或频率干预中的配对任务指标变化给出 `base_scene_id` 簇 bootstrap 区间。传入 `expected_doppler_shift_hz` 时，用于目标频率干预 `fd → fd + Δf`：干预后的 H1 真值按 PRF 周期回绕，分别计算基线/干预参数正确率，并对学生估计变化减去预期变化的残差给出区间。H0 不计算参数误差；H0 的参数输出和标签可为 NaN，仅检测分数需有效。区间描述场景抽样而非训练种子波动。频移幅度、输入变换方式、条件配额与任务门须在 R5-D 独立协议中冻结，当前代码准备不表示已运行物理干预。

## 目标与杂波强度的配对输入构造

`evaluation/d2a_physical_interventions.py` 中的 `scale_d2a_paired_components` 使用仿真器已保存的目标、杂波和噪声分量，为以后冻结的 R5-D 诊断生成同场景配对输入：

- 输入为功率变化量 `delta_db`，对对应复数 IQ 分量乘以正实数 `10 ** (delta_db / 20)`，保留原有相位、散射体实现、噪声和 base-scene ID。
- 目标强度变化只作用于 H1 的目标分量；H0 保持原样，H1 仍满足 `X1 = X0 + S`，并同步缩放目标幅度真值。目标距离和 Doppler 真值不变。
- 杂波强度变化作用于配对 H0/H1 的共同杂波分量；噪声和目标分量保持不变，输出继续满足 `X0 = C + N` 与 `X1 = X0 + S`。
- 返回各场景的目标/杂波/噪声功率及 SNR、CNR、SCNR，供后续检查功率捷径和强度响应；本构造器不计算检测器/学生输出，也不选干预幅度、样本量、阈值或正式阶段门。

这种对既有分量直接缩放的输入是**固定实现的组件级反事实诊断**，不是重新生成的独立物理场景，也不表示真实硬件或目标/杂波变化必然服从全局幅度缩放。实际 R5-D 需在 R5-C 审查与匹配教学 pilot 前门通过后另行冻结独立协议；诊断时要同时报告 H0 虚警、H1 检测、目标距离/Doppler、联合成功和分量功率，不得只以总功率变化解释任务响应。

## 目标 Doppler 与通道相干输入变换

同一模块提供三个只改变指定输入因素的配对变换：

- `shift_d2a_target_doppler` 对目标分量乘以 `exp(j 2π Δf n / PRF)`，杂波、噪声与 H0 保持不变，并将 H1 的 Doppler 真值按 PRF 周期回绕。它不重建目标轨迹，也不修改径向速度真值；属于连续频率的相位旋进反事实。
- `apply_d2a_channel_phase_offsets` 对每个接收通道的目标、杂波、噪声和 H0/H1 统一乘上该通道的固定复相位。通道间共同偏移用于公共相位变化；差分偏移用于破坏/恢复相对通道相干，range/Doppler 真值不变。对变换输出施加相反偏移可数值恢复原 IQ。
- `mask_d2a_channels` 对指定接收通道的所有 IQ 分量置零，作为通道依赖消融；这改变有效阵列观测，不能称为保持几何的物理场景。恢复完整通道时须从保留的原始配对输入重新构造，已置零数据无法反推。

以上输入变换不生成独立样本、不计算模型预测，也不构成物理定律或学生机制证据。正式协议仍须定义合法/反事实变换、频移与相位取值、分组、独立评价数据和停止门；需结合检测、H0虚警、range/Doppler与联合任务判断，且在 R5-C 审查及 matched T0–T3 前门通过前不运行模型比较。

## 停止条件

若 R5-C 没有知识形式达到任务质量门，不启动教学时机/因果机制搜索；只报告 teacher/student error matrix 和已有物理监督机制证据。不得因为需要填满阶段表而继续。
