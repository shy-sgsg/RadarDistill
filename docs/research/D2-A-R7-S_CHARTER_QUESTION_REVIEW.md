# D2-A-R7-S：研究总纲问题与路线证据映射

本表把本阶段证据映射到总纲v1.4的Q1–Q10。它是历史证据的综合审查，不是新实验协议，也不修改已有假设、阶段门或总纲正文。逐问题可筛选版本见 [`charter_question_evidence_matrix.csv`](../../experiments/D2-A-R7-S/S6/charter_question_evidence_matrix.csv)。

## 研究判断

| 研究问题 | 当前证据状态 |
|---|---|
| Q1–Q2：教师知识能否提高学生，哪种知识有效 | 当前K3全图和K2-local路线未显示 truth-only 之外的预设学生收益。K3有部分教师定位质量，但困难格严重失效；不支持继续当前知识格式的权重/时机搜索。 |
| Q3–Q4：学生能否形成有效表示，物理归纳偏置是否更好 | 多个学生能学到L0/L1映射；R7-B有限支持合成DPCA分量，R6-J4呈现低SNR任务点收益但Doppler及困难格保护失败。没有一项受控证据识别出普遍更优表示。 |
| Q5：距离压缩到更原始IQ的迁移 | R7-S没有同协议、同预算、同场景输入边界的因果比较，保持未评价。 |
| Q6：低SNR检测和连续参数精度 | 检测、距离、Doppler与Joint的最佳模型随SNR变化；部分学生低SNR检测可比或更高，但FFT/profile-ML在中高SNR的连续估计明显更准。不能把Joint单项当作完整能力。 |
| Q7：完整链效率 | 没有满足同硬件、同输入边界、质量门的完整处理链比较；不作效率结论。 |
| Q8：应保留哪些物理计算 | L0/L1支持保留FFT和profile-ML作为强估计参考，DPCA在当前合成几何有物理组件证据；复杂杂波和工程系统的取舍未定。 |
| Q9：教师错误与学生收益 | K1/K3/K2-local的困难格错误被量化，R5-C/R6-G没有显示教师收益；7kg未具可比资格。教师质量与教学能力仍应分开判断。 |
| Q10：预算、容量、架构和知识吸收 | 训练预算及width-only结果有有限开发证据；多架构共同验证仍受单seed/开发材料/虚警保护失败限制。知识吸收结论对当前K3是负向，对其他知识与结构仍未定。 |

## 路线审查

本阶段支持把下一项唯一优先问题放在**检测评价资格**：建立明确的物理CUT dense-score接口和分层独立H0校准/验证预算，再用匹配传统参考核实统计单位与可达到的虚警量级。原因是历史学生和大部分检测参考只有CPI标量输出，无法支撑总纲长期`Pfa_cell≈1e-6`目标；同时参数误差解释必须保护全部H1和检测命中子集两种口径。该建议只指向预注册和评价能力补齐，不代表批准训练、蒸馏或生成blind。

阶段门通过不自动意味着长期方向正确。本次证据没有推翻总纲的GMTI任务级学生目标，但明确否定了“当前K3/K2-local应继续无条件教学”这一受测分支；新教师只有在可比输入、困难条件正确性和匹配学生收益分别成立后才可获得资格。研究总纲v1.4保持未修改。
