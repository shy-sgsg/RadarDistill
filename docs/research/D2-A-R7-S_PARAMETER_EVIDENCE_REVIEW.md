# D2-A-R7-S：参数估计能力与训练充分性证据审查

**范围：** 只整理已有协议、训练记录和结果；未训练模型、未重算预测、未生成盲测。

## 结论摘要

当前资料支持“检测能力、参数估计能力和联合成功率必须并列评价”，但不支持单一最优网络、参数量最优点或已达到模型上限的结论。R7-D是所有可恢复模型在同一批新L0/L1场景上的历史checkpoint复评，估计指标以**全部H1**为主；另按检测命中子集报告误差，以呈现“先检测成功后估计”的条件误差。两者回答不同问题，后者受到筛选影响，不能替代全部H1。

在L1的中高SNR，传统FFT细化和profile-ML的连续Doppler误差明显小于受测学生；profile-ML只评价每SNR预先固定的256个H1，其他大部分方法为2,048个H1，样本量不可忽略。受测学生中，R6-J4低参数混合模型的C2+C3联合成功点值较高，但Doppler RMSE及最难格虚警保护失败。R5-A和R6-C提供了部分容量/预算收益证据，同时也都未解决C3虚警保护。跨不同协议的参数量—性能散点只作描述，不具因果解释力。

## 参数误差口径

1. **全部H1 RMSE是本矩阵的主要估计指标。** 未检测到的目标仍应计入估计误差分母，因为完整处理系统需要同时解决存在检测与参数恢复。
2. **检测命中H1 RMSE是条件诊断。** 它回答“只看被检出的目标时，参数头估得怎样”。模型间检测到的样本集合可能不同，条件RMSE有选择偏差；必须同时看Pd与joint success。
3. **距离误差单位为cell，Doppler用PRF周期回绕误差。** L0无噪声结果是接口/映射诊断；不能与L1随机误差混作同一个工作点。
4. **参数专用方法不应填检测分数。** lag-one和profile-ML在能力表中标为`NOT_APPLICABLE_PARAMETER_ONLY`，而不是Pd/Pfa为0。
5. **置信区间和样本量随行保留。** profile-ML的`n=256`，学生与大多数传统方法的`n=2048`；跨样本量点估计仅作描述性比较。

## 训练充分性和容量判断

| 判断 | 状态 | 证据边界 |
|---|---|---|
| R5-A S0/S2在1,600步已经充分 | 不支持 | 固定长计划内验证结果持续改善至12,800；仅seed101和复用开发材料 |
| Medium优于Small说明容量完全解决 | 不支持 | 受测C2/C3估计和joint改善，但两者C3 Pfa均明显超限 |
| R6-C Large/XLarge证明越大越好 | 不支持 | 同协议单seed下joint改善，但所有候选未过C3 familywise门；训练更新有限 |
| 51,200步代表学习极限 | 不支持 | R6-G最佳点在中后段、R6-H部分曲线末端仍改善；无预算外观测 |
| R7-D的47个模型可作容量因果实验 | 不支持 | checkpoint跨阶段、预算、训练集、损失、种子和结构不同；不能从横截面参数散点作因果归因 |
| Doppler误差主要来自错误距离门或某单一模块 | 未确定 | R7-D同时提供全H1与命中子集误差；但没有对全部候选、同场景、预注册的因果误差分解 |

## 对研究路线的影响

当前最重要的是避免“检测好但频率差”或“条件估计好但漏检多”被一个综合分数掩盖。后续若获准新训练，应在预先固定的共同场景和预算下，明确报告全H1与检测命中估计误差、距离候选错误、连续Doppler误差和joint；检测与估计可探索联合或分开读出，但需要matched数据、容量、训练预算及C3逐格虚警保护。当前证据不支持因参数量散点或单seed改善而扩大模型搜索。
