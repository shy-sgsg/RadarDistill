# D2-A 教师算法文献调研

**调研日期：** 2026-10-26
**问题范围：** 当前三通道、PRF 1300 Hz、N=130、32 距离单元的合成静止地杂波 GMTI；目标是支持检测、距离/Doppler估计及后续学生蒸馏。
**证据规则：** “论文结果”只概述来源实际报告；“本项目判断”是面向 D2-A 的适用性推断，必须由 D2-A-T001 新场景验证。论文间仿真数值不横向比较。

## 结论与适用性边界

1. 没有找到与 D2-A **3 通道×130 脉冲×32 range cells、静止地杂波、低速部分频谱重叠、目标级连续 Doppler** 完全匹配并可直接照搬的已验证方法。
2. full-STAP 390 维样本协方差不能由 32 range samples 稳定支撑；“32 个独立同分布快拍”的前提也未成立。Post-Doppler 将自适应维度降到 3 有统计/计算上的合理性，但 range cells 的相关、异质及目标污染仍要明确审计。
3. ACE/自适应匹配滤波具有明确尺度不变形式，且能把完整三通道相干响应转为每个 range-Doppler cell 的目标导向统计图。以独立仿真 H0 CPI 拟合 population covariance 是本项目的知识辅助适配，不是上述论文已验证的事实；仿真到真实场景的协方差迁移仍未知。
4. 所有论文里“更高 Pd”“CFAR”“少快拍”等结果只在各自数据、协方差、目标流形、门限与仿真假设内成立。本项目通过新独立 H0/H1 场景验证，不能直接借用论文的数值或理论承诺。
5. 本轮调研未找到这些文章对应的、可直接复用到当前仿真器的官方代码。此查找不是对作者仓库的穷尽性审计；T001 采用自有小型 NumPy 实现，并对照论文公式、合成已知向量和边界性质测试。
