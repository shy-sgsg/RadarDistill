## 采用决策与边界

1. **频率：** 有杂波 R0/R1 主配置使用 XML 的 15.8 GHz，因为其为当前实际场景配置；D0 无杂波回归严格调用原 D0 配置和 D0 生成函数，保持 16 GHz，不通过改 D0 历史参数伪造等价。
2. **脉冲数：** D2-A 为纵向可比仍用 130 脉冲；生产场景实际配置为 128 脉冲，后续若进入硬件对齐阶段需单独评估，不在本阶段偷偷把两者混用。
3. **距离轴：** 采用 D0 的 32 个压缩后 range bins 与理论 `c/(2B)` 单元宽度；5 m 的系统表字段作为生产规格并列记录。建模以实际三维传播距离投影到相对距离单元，不把整数 bin 当作真实绝对斜距。
4. **坐标与相位：** D2-A 明确定义平台匀速沿局部 +x（北），y 为东、z 向上；方位角自 +x 朝 +y 计；俯仰由水平面向上为正。发射-接收总传播路程为 `L=R_tx+R_rx`，复相位为 `exp(-j 2π L/λ)`；静止散射体的脉冲间多普勒由 `L(t)` 的变化自然产生，绝不手工置零。
5. **三通道：** 采用 actual-scene 四通道阵列的前三个相位中心做受控研究子集，不能推广成生产完整通道或标定阵列结论。由于通道校准在 XML 中关闭，实际相位偏差未知；先报告理想相干模型，另将失配留作受门控的后续敏感性项。
6. **方向图与地物：** R0 不可避免需要明确场景与波束先验。首版以单束 2.28° 高斯方位主瓣和地面点散射系数工作；主瓣之外的旁瓣、地表相关性、遮蔽、地形高程、传播衰减和实测 clutter statistics 均未知，不把首版当成 APX15 全物理回放。
7. **DPCA：** 接收相位中心存在 0.17 m 沿航向差，但发射相位中心位置未被来源确认。任何时间对齐量必须从双程路径/相位中心模型推导并由静止散射体残差测试校验；在满足该条件前，只能标成“研究几何下的候选基线”，不能宣称生产 DPCA 性能。
8. **数据声明：** 所有 D2-A 指标均为可复现仿真开发结果；本次不读取或发布真实目标观测，不从已多次用于选择的 D0/D1 blind 派生新的“盲测”。

## 未知项

- 实际发射相位中心及其脉间相位稳定性；生产通道的实测相位/幅度/时延校准与漂移。
- 15.8 GHz 以外的真实 chirp 频谱、加权窗、匹配滤波器复响应、采样时钟误差和脉间相位噪声。
- 平台在 130 脉冲窗口内的真实速度/姿态/高度轨迹与波束指向误差协方差。
- 实际天线二维方向图、旁瓣、极化、地物复散射的空间相关模型、地形/植被/建筑统计、遮挡与动态杂波。
- 接收噪声的实际功率与通道协方差，检测产品的量化/饱和及其对弱目标的影响。

这些未知项不阻止“受控、静止、独立点散射 + AWGN”的单因素开发实验，但限制外推范围；阶段报告必须逐条保留此限制。
