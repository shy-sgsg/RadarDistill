# D2-A 教师知识与教学策略研究

## 原则

物理真值 K0 始终作为训练监督主干。教师任务能力、软知识质量和学生学习收益分别审查。既有 R3/T001 的固定阈值检测器失败保持不变；新的软知识资格也不得反向修改旧门。

## 教师知识候选

| 代号 | 内容 | 关键质量问题 |
|---|---|---|
| K0 | H0/H1、距离、连续 Doppler 真值 | 物理仿真与可辨识边界正确 |
| K1 | 完整 Range-Doppler 软响应 | 目标峰质量、杂波响应、H0 合理性、与 truth 的冲突 |
| K2 | 教师仅凭 IQ 自主定位的局部响应 | 区域选择是否依赖真值；定位失败时如何处理 |
| K2-T | 以真实位置定义窗口的辅助响应 | 明确属于 truth-assisted auxiliary，不叫教师独立定位 |
| K3 | 连续 Doppler 候选分布、局部似然或不确定性 | 周期/混叠、概率校准、峰位与置信区间 |
| K4 | 相位、频移、通道相干等物理关系 | 物理扰动/恢复测试；匹配无教师正则化对照 |
| K5 | 从可观测 IQ/候选稳定性产生的可靠性权重 | 无测试真值输入、分层校准、错误教师降权 |

## 质量门

每种候选单独检查独立 H0/H1 的检测/估计、知识定位信息、数值稳定、条件性失败、truth 冲突和标签泄漏。`H1−H0` 或目标/杂波组件真值只能作为离线分析，不能作为可部署教师输入。教师知识对学生的资格可以与固定阈值 detector 资格分开，但必须有预注册独立数据和明确任务保护门。

## 最小内容 pilot

若至少一类知识过质量门，匹配同一学生、初始化、数据、更新、loss 和 checkpoint 选择：T0 truth-only；T1 truth+full response；T2 truth+teacher-local knowledge；T3 truth+与 T2 计算/输出形式匹配的 truth-window auxiliary。保存教师硬标签、软响应、物理真值及学生输出到不同字段。主结论来自检测/参数/joint 任务，不来自 KD loss。

仅当 T1/T2 显示可复现 pilot 价值才比较直接教学、真值优先后渐进教学、教师早期后退火等时机。若没有知识质量或基础学习能力，停止相应 KD，不通过加权复杂度掩盖失败。
