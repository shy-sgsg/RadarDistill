# D2-A 目标与静止杂波可辨识性分析

**观测：** 三接收通道、130 脉冲、32 距离门；`PRF=1300 Hz`、`fc=15.8 GHz`；平地、匀速平台和有限方位主瓣的合成研究几何。

## 由几何得到的杂波频带

中心波长为 `λ=c/fc=0.018974206 m`。平台速度 `V=60 m/s`，波束中心方位为航向侧视的 `90°`，方位范围 `88.86°–91.14°`。远场单站近似下，静止地物的两程传播路程导数给出：

\[
f_c(\theta,\epsilon)\simeq\frac{2V\cos\epsilon\cos\theta}{\lambda},
\qquad |f_c|\lesssim\frac{2V\cos(4.70^\circ)\sin(1.14^\circ)}{\lambda}=125.403\;\text{Hz}.
\]

这是当前平地、窄波束、共址 Tx 研究假设下的理想支撑边缘；有限 CPI 窗、随机散射谱泄漏及范围/角度分布会扩展实际能量，不能把它当作普适杂波谱。

每个 Doppler FFT 的原生间隔是 `PRF/N=10 Hz`。配置的径向速度为正向远离平台；由于 `exp(-j2πL/λ)` 相位约定，目标 Doppler 为负：

| 场景 | 径向速度 | 几何 Doppler | 与静止杂波支撑关系 |
|---|---:|---:|---|
| A separated | `+4.0 m/s` | `−421.625 Hz` | 在理想支撑外约 296 Hz（约 30 个原生 FFT 间隔） |
| B near edge | `+1.2 m/s` | `−126.488 Hz` | 离含 `−4.70°` 俯仰近似的理想边缘约 1.085 Hz，仅为 0.11 个 10 Hz 间隔 |
| C partial overlap | `+0.4 m/s` | `−42.163 Hz` | 位于杂波支撑内；可用距离/角度差异补充区分 |
| D exact overlap | `0 m/s` | `0 Hz` | 目标与指定静止散射点共用位置、角度和慢时间流形 |

速度到 Doppler 的对应值由配置的双程路径公式直接计算，并以每脉冲路程差验证；表中远场支撑是解释用近似。

## 时空流形与信息边界

窄带远场下，一个点目标可近似写为 `a_t(f)⊗a_s(u)⊗h_r(r)`：慢时间向量 `a_t(f)[n]=exp(j2πfn/PRF)`，空间响应由三个接收相位中心 `b_m` 对方向 `u` 的路径差确定，距离响应为 D0 sinc PSF。不同通道不是独立杂波输入；相干相位是可用于 DPCA/相干处理的几何信息。

有限 CPI 中相邻频率的归一化时间流形内积为 Dirichlet 核：

\[
\rho(\Delta f)=\frac{1}{N}\left|\frac{\sin(\pi N\Delta f/PRF)}{\sin(\pi\Delta f/PRF)}\right|.
\]

A 的目标与杂波支撑有明显频率间隔；B 虽略在理想谱边缘外，但与边缘相差约 `0.11` 个原生 FFT 间隔，单靠 130 脉冲谱峰并不稳健；C 存在杂波频率与目标频率一致的可能，因此检测取决于几何相位中心差、距离响应、杂波强度及有限样本；D 中目标与静止散射体使用同一复时空距离流形，单次观测只含未知复散射系数之和 `α_clutter+α_target`。该映射对两源分量不是一一对应，D 的唯一源归因不可辨识，不能要求网络恢复唯一标签。

## R1 数值诊断与解释

B0 单通道 FFT 峰值、B1 三通道非相干功率和 B2 17 角几何相干波束搜索在 A 的 `10/10 dB` 输入 SNR/CNR 条件下 AUC 均约 `0.500`；增加通道或做几何 beam scan 本身没有移除静止地物的强相干谱。B3 对通道 0/1 以几何推导的分数慢时间偏移后相减，在本合成条件下得到静止杂波中位抑制 `15.406 dB`（95% cluster-bootstrap CI `[15.328,15.480]`），分离场景目标相对通道 0 的未缩放差分功率比中位数 `3.614`。该比率未归一化，超过 1 不代表能量效率。

在 `10/10 dB` 主条件下，B3 的 Pd/AUC/条件 Doppler RMSE：A `1.000/1.000/2.828 Hz`，B `1.000/1.000/2.923 Hz`，C `0.605/0.864/3.002 Hz`，D `0.066/0.501/218.721 Hz`。A/B 有可辨识证据；C 仍能部分检测但明显受重叠影响；D 与随机判决一致。D 的检测指标只描述给定先验下的有限样本统计，不推翻两源幅相分解的不可辨识性。

完整协方差 STAP 维数为 `3×130=390`，可用 range bins 只有 32；由这 32 个 range 快拍估计的 390 阶样本协方差秩至多 32，不能支撑常规求逆。范围/地物相关还会降低有效独立样本数。本轮因此没有凑数实现满秩 STAP，也没有构造没有统计依据的 Oracle CRLB。若后续有充分独立训练数据，可另行设计降维或知识辅助 STAP。

## 阶段含义

数据说明目标信息确实可被物理抑制器使用，A/B 与 C/D 之间有明确难度梯度；它不证明纯学习学生会利用该信息，也不证明 B3 可代表生产系统。主条件 A 在独立 H0 阈值标定后出现 `Pfa_CPI=0.0898`（95% CI `[0.0586,0.1250]`），高于标定经验 `0.0508`，所以 R1 之后仍有阈值迁移前门。阈值在开发集上未重调。
