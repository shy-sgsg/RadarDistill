# D2-A-R7-S：传统方法与教师资格审查

教师的实现正确性、物理组件作用、检测/估计任务能力、知识质量和学生教学收益是五个独立资格。本报告不因某算法“传统”“物理”或来自成熟工程软件而默认其是合格教师。

## 总结

- **可直接用于本轮无杂波参考：** B0/B1 FFT 检测与估计链；lag-one 和 profile-ML 仅作为参数估计参考。它们的适用范围是 R7-D 单目标无杂波 AWGN，共同场景与分SNR `Pfa_CPI=0.01`校准；都没有证明 dense CUT 低虚警能力。
- **物理模块资格：** B3 几何 DPCA/K2 在声明的合成几何下通过实现/相干补偿诊断；这只说明静止杂波补偿组件有物理依据，不代表完整检测器、参数教师或真实工程系统已合格。
- **软知识资格：** K1/K3/K2-local提供了部分目标相关响应；K3相对K1定位有小幅改进。但最难C3 partial-overlap / SNR 0 dB / CNR 20 dB格定位率约2.15%–4.10%，这类知识不能无条件等权用于教学。
- **学生教学资格：** R5-C teaching和R6-G的匹配对照均未证明K3/K2-local相对 truth-only 的预注册最终任务收益。T3的小幅差值来自真值辅助，不是教师蒸馏。
- **暂停/未资格：** T001 ACE×AMF在前置门失败后未进入软图审查；7kg未满足版本、许可、接口与正确性证据，未构成可比基线或教师。

## 资格层级

| 层级 | 本项目中的含义 | 现有结论 |
|---|---|---|
| 1. 公式与接口正确 | 代码按声明输入、数据布局、物理量和边界执行 | B3合成DPCA有限通过；7kg未审定 |
| 2. 物理组件有效 | 目标/杂波/噪声分量的响应符合物理预期 | B3纯静止杂波抵消获得合成证据；不能推到真实几何 |
| 3. 任务性能可比 | 在共同输入、H0校准/独立验证、可辨识H1下报告Pd、误差和区间 | B0/B1、R7-D可比；范围限L0/L1 |
| 4. 知识本身合格 | 教师软响应/硬标签在重要条件正确，困难格错误有量化 | K1/K3/K2有条件质量证据，困难格有严重错误 |
| 5. 确有教学收益 | 固定学生/数据/预算下，相对truth-only与truth-assisted控制增加最终任务收益 | 当前K3/K2-local未获支持 |
| 6. 运行资格 | 目标虚警单位、工作点及应用场景有独立统计资格 | 当前没有`Pfa_cell≈1e-6`合格方法 |

## 证据边界及决策

机器可读矩阵 [`teacher_qualification_matrix.csv`](../../experiments/D2-A-R7-S/S5/teacher_qualification_matrix.csv) 为每种候选分别记录输入/实现、任务表现、知识质量、教学结果、虚警资格与来源。用于跨阶段展示的性能数值同时保存在[完整统一矩阵](../../experiments/D2-A-R7/unified_performance_matrix.csv)；R7-D同场景所有方法的检测、距离、Doppler、Joint及样本量见[485行能力表](../../experiments/D2-A-R7-S/S2/all_models_l0_l1_capability_matrix.csv)。

R7-S的结论不是“没有任何传统方法有价值”：FFT与profile-ML给出强且可复核的无杂波参考，DPCA给出受限的物理组件证据。结论是现有证据尚未把这些结果连接成一个在目标复杂度、虚警保护和学生教学三方面都合格的 GMTI 教师。要重新提出教师路线，应说明新增知识是什么、针对哪种已定位错误、为什么不被现有FFT/DPCA参照覆盖，并预先匹配 truth-only 与 truth-assisted 学生对照。
