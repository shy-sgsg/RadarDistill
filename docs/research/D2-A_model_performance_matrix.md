# D2-A R5/R6 综合性能报告：模型与教师总表

本表汇总R5/R6已评价学生、传统检测/估计基线、教师响应及完整处理链，是整条研究路线综合报告的性能主表。不同阶段使用不同数据划分；只有同阶段明确使用同场景的行可作严格配对比较，跨阶段数字只作发展轨迹参考。

## 指标口径

- 检测列顺序：H0 Pfa为“总体 / C3 pooled / 最难格”；Pd为“H1总体 / C3 / 最难格”；AUC为“总体 / 最难格”。R6最难格固定指C3 partial-overlap、SNR=0 dB、CNR=20 dB（condition 10）。R5没有同口径逐格H0最难Pfa时标“—”。
- 参数估计列顺序为“全H1 / C3 / 最难格”的Range RMSE与周期Doppler RMSE，单位分别为距离单元和Hz。Joint success顺序为“总体 / C2+C3 / C3 / 最难格”；要求检测命中、距离误差≤1 cell、周期Doppler误差≤20 Hz，漏检计失败。检测专用、参数专用或无阈值教师行不适用项标“—”。
- K1/K3/K2-local是教师软响应质量审计，不是阈值检测系统。其top-cell定位率不是Pd，也不等于学生吸收知识后的任务收益。K2-local在教师选定距离门内独立归一化，lift量纲不能直接与全RD归一化K1/K3比较。
- R6的H0 verification独立于threshold calibration；H1均为开发集，不是final blind。表中给点估计；配对置信区间、12条件格、配置与门槛见每行证据文件。Oracle候选不混入系统性能。
- R5-A、R5-B及R5-A容量对照复用E003已看开发数据，不是新独立确认。

## 综合研究结论

这张表汇总了 **60 条已运行的模型/方法记录**。它同时记录每行的数据划分、样本量和模型角色；这些结果来自多个独立阶段，不能按表格全列直接做统一排行榜。同阶段、明确共用场景与阈值流程的配对差异，才可支持相对结论。各行底部链接通往指标、协议和分析来源。

### 检测与低虚警

在多组开发实验中，真值监督学生的总体Pd/AUC通常明显高于B3等传统检测教师；但这不等于已获得可靠的低虚警检测器。C3逐条件Pfa是主要瓶颈：R6-H、R6-F、R6-I和R6-J4均没有候选通过六格familywise门。R6-J4总体/pooled C3 Pfa看似接近10%，但condition 6/8/10点值仍约18%–19%。所以总体平均不能代替困难背景的逐格虚警控制。

### 参数估计与处理链

Range误差通常比连续Doppler误差容易改善。R6-F在相同数据上的CE-TCN检测加原生参数读出，Doppler RMSE为18.72 Hz；把Doppler精估换成profile-ML后，误差升至149.61 Hz，说明粗候选与精估方法并非可互换。R6-J4也表现出任务折衷：C2+C3 joint相对J1-J增加3.26个百分点、Range保护通过，但Doppler RMSE明显恶化，最难格joint从10.35%降到2.15%。当前数据不能支持“检测和参数估计分开”或“共享联合模型”在所有任务条件下普遍更好；两者都有待解决的失败模式。

### 容量、架构与训练

R6-C中，约70K参数到292K、再到约1.01M参数的truth-only容量筛选，在其相同开发split上带来C2+C3 joint从81.64%升到86.28%和87.04%的变化；但更大模型仍未解决C3逐条件虚警问题。R6-H的约72K CNN-SSM对约63K CE-TCN提高了C2+C3 joint，却未通过Range保护和C3逐格Pfa门。R6-J4只有约10.5K参数，证明小模型可在一个预注册主端点上获得收益，但以Doppler与最难格损失为代价。不同阶段训练预算、数据split、seed并不相同，因而不据此选出全局“最佳参数量”。现有训练曲线也没有证明这些模型已达到优化或容量上限。

### 教师与知识蒸馏

教师的知识质量不能等同于教学收益。R5-C中K3的C2+C3软响应top-cell定位率约81.22%，但最难C3格仅4.10%；R5-C T1/T2没有优于truth-only T0。R6-G中truth+K3相对truth-only的C2+C3 joint差为−0.00130（95% CI `[-0.00781,+0.00521]`），没有证明独立蒸馏收益。truth-assisted T3提高0.01172，但低于预设+0.02门，且不是教师知识。当前没有证据支持已测K3/K2-local方案能可靠改善学生，也没有依据继续搜索其温度、时机或可靠性权重。

### 研究决策与边界

在现有冻结仿真和已测试候选内，可以确认学生确实从物理真值学到有用的检测与估计能力，物理频谱前端也可改善固定峰值基线；但当前综合主张仍是 **REFINE**：没有候选同时满足C3逐条件虚警、连续Doppler与联合任务保护。所有H1结果仍是开发集，R5部分结果复用了已看过的E003数据；多数模型只有一个训练seed。现有结论不代表final blind、真实机载数据、跨seed稳健性或系统实时成本。

本轮已完成整条R5-C/R6综合报告和一次独立审查请求；不据当前开发集继续增加架构或蒸馏搜索。若未来继续研究，应先围绕C3的可分性与逐条件Pfa失稳提出新的可证伪假设和独立数据协议。

## 阶段报告结论

学生总体检测和联合任务表现会随模型及训练条件变化，但C3低SNR条件仍是低虚警与精细估计的主要瓶颈。R6-F中CE-TCN检测加原生参数链表现较好，改用profile-ML Doppler估计则明显退化。R6-G与R5-C教学pilot均未证明已测K3/K2-local软知识能在truth-only之外带来独立学生收益；R6-I尺度校正降低pooled C3 Pfa却未通过Pd保护。R6-J4显示，小型固定DPCA+学习读出相对raw-IQ J1-J提高了C2+C3 joint，但Doppler误差明显变大，C3逐格虚警门失败，未达到候选晋级条件。教师知识质量和学生教学收益必须分开，pooled指标不能替代C3逐格保护。
