# 统一实验规范

## 编号和材料

使用 `P0-E001`、`P1-E001` 等编号。每项实验保留 `config.yaml`、`metrics.json`、`result.csv`、`analysis.md`。训练时保存结构/权重；需要复核的仿真输入及标签按独立划分保存。汇总结果不得只保留最佳种子。

## 数据划分和生成

- 训练、验证、测试由互不相同的明确种子生成，并把种子和实际配置写入产物。
- 连续随机频率覆盖无模糊区间，不只用 FFT 栅格点。初始相位均匀随机，幅度和 SNR 随机化。
- 目标真值、教师频率、教师软目标、模型预测分字段存储，不能互相覆盖。
- 改变测试 SNR、频率分布、相位、幅度或通道/杂波条件时单独标明；训练与测试的分布重合情况须明确。
- 仿真输出不称为实测数据。没有真实雷达采集时不作实测泛化结论。

## P0 信号与评价

模型为单复正弦加圆对称复 AWGN；SNR 定义为每个慢时间采样点信号功率 \(A^2\) 与复噪声总功率 \(E|w|^2=\sigma^2\) 之比。使用误差

\[
e=\operatorname{wrap}_{[-\mathrm{PRF}/2,\mathrm{PRF}/2)}(\hat f-f).
\]

报告 MAE、RMSE、偏差、异常值比例，异常值定义为 \(|e|>\mathrm{PRF}/(2N)\)；同时按 SNR、频率区间、初相扇区、幅度分位数和 FFT 栅格偏移分组。RMSE 给出 95% bootstrap 区间，E3−E1 使用共享测试样本的配对 bootstrap。

当复幅度/初相未知，噪声为复高斯白噪声且每样本 SNR 已知时，频率 CRLB 方差为

\[
\operatorname{var}(\hat f)\geq
\frac{\mathrm{PRF}^2}{8\pi^2\,\mathrm{SNR}_{lin}\sum_n(n-\bar n)^2}
=\frac{3\,\mathrm{PRF}^2}{2\pi^2\,\mathrm{SNR}_{lin}N(N^2-1)}.
\]

该界适用于所列模型和无偏估计器；不把它解释为低 SNR 有限样本下所有方法都能达到的误差。

## 基线和学习对照

P0 基线：N 点 FFT 峰值、对数幅度三点插值、相邻脉冲共轭乘积相位差、连续 periodogram profile-ML。ML 通过粗 FFT 峰初始化局部连续频率搜索。报告各自适用假设。

- E1：以模拟物理真值优化圆周 sin/cos 频率损失。
- E2：仅以最大似然教师的局部 profile-likelihood 软圆周目标训练；教师估计单独保存并保留其错误。
- E3：物理真值损失加教师软目标损失；配置记录固定蒸馏权重。

三种策略使用相同信号种子、模型容量和验证/测试数据。验证真值仅用于模型选择，不参与 E2 训练。独立测试真值只用于最终测量。

## P0 阶段门

1. **代码正确：** 物理信号/噪声统计、周期回绕、基线、训练/评估接口和复现产物通过测试。
2. **学习有效：** 独立测试明显优于常数/随机频率猜测，且性能随 SNR、频率、初相和幅度变化可解释；没有边界折叠或只记忆频率分布的迹象。
3. **继续价值：** 至少部分正常 SNR 超过 FFT 峰值并对比插值方法；E3 相对 E1 的收益须由跨种子配对统计支持。ML 差距需如实报告，不要求网络全面优于 ML。

任何门未通过时，先定位信号、标签、周期性、归一化、模型欠/过拟合、教师偏差或信息不足；每次只改变少数因素并保留旧结果。

## 后续检测指标

P3 起报告 Pd、单元 Pfa、系统级虚警数量、SCNR、MDV、速度/角度 RMSE、目标损失和异常比例。Pfa=1e-6 需要充分独立背景机会或有理论依据的尾部模型；少量随机试验不得支持该数值声明。

## 复现记录

记录运行命令、Git commit、Python/依赖、硬件、配置、随机种子、数据生成参数、模型结构、训练停止轮数、指标定义和结果路径。部署延时只在指定目标硬件实测，不从 FLOPs 推断实际加速。
