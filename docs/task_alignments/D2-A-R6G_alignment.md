# D2-A-R6-G 主线对齐

- **总纲目标/问题：** 服务由物理仿真真值和传统方法知识训练直接 GMTI 检测/参数估计学生，对应总纲Q1、Q2、Q6、Q9、Q10；不是单独优化传统检测器。
- **当前证据：** R5-C T0–T3在Medium学生上未显示K3/K2-local蒸馏增益；K3整体定位率有有限提升但C3部分重叠/SNR0/CNR20定位正确率仅4.1%。R6-E/F中CE-TCN是当前受测任务表现最强的学生候选，但完整链C3六格虚警门仍失败。
- **本任务问题/假设：** R6G-CE-TCN从头学习时，K3完整软频谱响应是否带来truth-only任务损失以外的最终joint收益或更快任务学习；效果是否仅来自额外辅助响应头，还是存在教师特有贡献。
- **选择理由：** 选择K3而非R5-C表现更弱且局部尺度不可直接比较的K2-local；选择CE-TCN是依据R6-E/F的任务表现，不宣称其参数量更大或低虚警合格。以T3真值辅助响应隔离辅助头/一般响应监督作用。
- **方法：** 新协议比较T0 truth-only、T1 truth+K3、T3 truth+真值Dirichlet响应；seed707从头bit-identical初始化，固定同数据、训练顺序、effective batch64、51,200 updates和validation truth-task-loss checkpoint选择。T1教师只读H1 IQ+物理配置；训练target错误不由真值纠正。
- **决策影响：** 若T1相对T0达到+0.02的C2+C3 joint门且任务保护通过，保留作为后续独立多seed候选；若没有，则停止当前K3教学内容，不调权重/可靠性/时机。C3 absolute Pfa门独立判定检测资格。
- **替代方案：** 重复Medium四臂不测试新学生结构对知识吸收的影响；一次扩展多个学生/教师/时机混杂因素，不能清楚归因。本次采用一个学生和一个知识形式的matched pilot。
- **成功与失败含义：** T1任务收益且胜过T0支持K3在本CE学生/当前仿真中的增量价值；若T3同样或更好，教师特异性未证实；K3未过门或困难格负迁移则停止当前分支。单seed不能估计seed方差或证明普遍教学规律。
- **停止条件：** G0 scene ID/隔离、预算、资源失败，G1目标图/梯度/无泄漏/CUDA检查失败则不训练；训练OOM只降低microbatch并保留有效batch64；C3绝对虚警失败只阻止系统资格，不覆盖教学机制指标。
- **总纲与历史：** `docs/RESEARCH_CHARTER.md` v1.3不变；R5-C与R6-E/F协议和负结果不修改；整条R6 P0–P7结束后才形成唯一ChatGPT综合审查材料。
