# D2-A-R6 P7 候选准入判断

**状态：** 基于 R6-H 冻结结果作出的路线判断；未创建 P7 实验 protocol，未启动新训练或 final blind。
**研究总纲：** `docs/RESEARCH_CHARTER.md` v1.3。

## 任务与研究目标

R6 P7 原计划对少数最有希望的学生进行多训练种子、独立场景、低虚警和完整成本确认。该任务服务于总体目标中的 GMTI 任务级检测/参数估计与真实质量约束下的学生筛选，对应 Q3、Q6、Q7、Q10，以及 H-ARCH-SSM-001/002。

## 当前证据

- R6-H seed808 中，SSM−CE-TCN 的 C2+C3 joint 差为 `+0.01931`（97.5% CI `[+0.01085,+0.02778]`），未达到预注册 `+0.02` 点增益。
- CNN-SSM−CE-TCN 为 `+0.03016`（`[+0.02214,+0.03798]`），通过 joint 主端点；但 Range RMSE ratio `1.070`、97.5% 上界 `1.165`，未通过 1.05 保护门。
- 三臂 C3 六格 familywise Pfa 门均失败。最难的 C3 partial-overlap / SNR=0 dB 格中，CE-TCN、SSM、CNN-SSM H0 Pfa 点值为 `0.0986/0.1016/0.1048`；CNN-SSM 同格 H1 Pd/joint 为 `0.414/0.219`。
- 没有可同时满足主任务收益、任务保护与 C3 虚警要求的 R6-H 候选。R6-H 仅一个训练 seed，无教师知识监督，也没有 final blind。

## 决策影响与替代方案

基于这些结果，**暂不启动当前候选组的 P7 多种子确认**。直接进行更大样本量的正式评价只能缩小虚警置信区间，不能保证修复 CNN-SSM 最难格高于 0.10 的点估计或 range 保护退化。反过来，当前结果也不足以否定 SSM 家族：只测试了协议中两个固定参数化。

比扩大多种子架构训练更有价值的下一项工作，是建立一个只依赖可观测 IQ/背景统计的 C3 分数稳健化候选，对照 CE-TCN、CNN-SSM 和 B3；保留独立 H0 校准/验证、困难条件 H1 和任务保护门。若该候选提高固定阈值下的 C3 资格并保留 Pd/joint，再单独冻结 P7 的多种子方案；若无法改善，保留负结果并重新评估低虚警学生路线。

## 成功/失败含义与停止条件

- 若新的分数/归一化在独立 C3 H0 上通过 familywise Pfa 门，且 Pd、range、Doppler、joint 保护通过，支持进入正式候选确认；不自动证明蒸馏有效或实测 GMTI 可用。
- 若条件 ROC 仍弱或 Pfa/Pd 存在不可接受的折衷，则停止当前分数调整，不无限搜索归一化公式；在总纲授权范围内重新审查可辨识信息和任务路线。
- 研究总纲及 R6-H 冻结协议、结果均保持不变；ChatGPT 综合审查请求留到整项已授权 R5-C/R6 路线收尾时一次性提交。
