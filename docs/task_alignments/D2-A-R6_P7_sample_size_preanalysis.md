# D2-A-R6 P7 低虚警样本量预分析

**状态：** 预分析；不是实验协议、不是阈值选择，也不授权启动 P7。
**依据：** RadarDistill 总纲 v1.3、R6 路线及用户授权的 P7 低虚警确认要求。
**适用范围：** 单个最终候选系统的 H0 verification；C3 的六个预注册条件格分别评价。

## 目的与边界

R6-G 尚未完成，P7 候选、主要工作点、校准规则和训练 seeds 均未冻结。本文只给出独立 H0 验证所需样本量的精确二项下限，供 R6-G 完成后的协议设计使用。不得把这些数字解释为已取得某一 Pfa 资格。

统计单位是一个独立 H0 CPI。阈值必须先由另一组 H0 calibration 场景确定，再固定应用于本表所指的 H0 verification 场景。不得把 calibration 与 verification 样本合并计算虚警区间。

## 计算方法

对某一目标虚警率 `p`、独立验证样本量 `n` 和观察到的虚警数 `k`，单侧 Clopper–Pearson 上界不超过 `p` 的条件为：

```text
P[Binomial(n, p) <= k] <= alpha_cell
```

以下分别按六个 C3 条件格使用 Bonferroni 校正。若只对一个主要 Pfa 工作点作同时确认，`alpha_cell = 0.05 / 6`。表内数字是满足该不等式的最小每格 H0 CPI 数；总数为六格之和。

## 一个主要工作点：六格 C3 familywise 95% 控制

| 目标 Pfa | 0 次虚警：每格 / 六格 | 1 次：每格 / 六格 | 2 次：每格 / 六格 |
|---|---:|---:|---:|
| 0.05 | 94 / 564 | 135 / 810 | 170 / 1,020 |
| 0.01 | 477 / 2,862 | 682 / 4,092 | 861 / 5,166 |
| 0.001 | 4,786 / 28,716 | 6,845 / 41,070 | 8,633 / 51,798 |
| 0.0001 | 47,873 / 287,238 | 68,475 / 410,850 | 86,358 / 518,148 |
| 0.000001 | 4,787,490 / 28,724,940 | 6,847,712 / 41,086,272 | 8,636,084 / 51,816,504 |

## 多个同时确认的工作点

若四个工作点（0.05、0.01、0.001、0.0001）都要作为同时确认的结论，使用更保守的 `alpha_cell = 0.05 / 24`。此时：

| 目标 Pfa | 0 次虚警：每格 / 六格 | 1 次：每格 / 六格 | 2 次：每格 / 六格 |
|---|---:|---:|---:|
| 0.001 | 6,171 / 37,026 | 8,413 / 50,478 | 10,342 / 62,052 |
| 0.0001 | 61,735 / 370,410 | 84,159 / 504,954 | 103,458 / 620,748 |

若再把 0.000001 作为第五个同时确认的工作点，六格与五个工作点共 30 项比较。0.000001 工作点在 0、1、2 次虚警下分别需要每格 6,396,927、8,665,488、10,615,916 个 CPI；六格合计约 3,838 万、5,199 万、6,370 万个 CPI。

## 对 P7 设计的影响

1. 建议在 P7 protocol 冻结时指定一个主要 Pfa 工作点；其余工作点标为次要分析，或对全部确认性声明预先作多重比较校正。
2. 0.0001 工作点即使只观察到零次虚警，六格 C3 verification 也至少需要 287,238 个 CPI；若四个工作点同时确认，则至少需要 370,410 个 CPI。出现虚警后所需数量按表增加。
3. 0.000001 对应数千万个 C3 H0 CPI，须先做独立资源/仿真吞吐评估；若预算不支持，应明确标为未评估，不能声称达到该 Pfa。
4. 本分析不规定 calibration 数量。校准样本预算还需要预注册分位数/容忍区间规则、可接受的阈值波动，以及独立重复校准设计；不能从 verification 的零虚警下限直接推导。
5. 正式多训练 seed 若对每个 seed 分别作虚警资格声明，需在 P7 另行规定 seed 与条件的多重性控制。本文表格不包含该额外校正，也不替代 H1 Pd、参数 RMSE、joint success 或完整链成本门。

作为资源量级参考，若校准设计要求每格目标尾部约有 100 个独立 H0 样本，则数量级约为 `n ≈ 100 / p`：Pfa为0.001、0.0001、0.000001时，分别约为每格10万、100万、1亿个 H0 CPI。该经验值只描述固定阈值下的尾部计数分辨率（在小 Pfa 时约对应20%的95%相对误差量级），不是经验分位阈值的置信保证；实际阈值波动仍须通过预注册的重复校准、独立验证和容忍区间规则评价。

P7 仅在 R6-G 结果完成并冻结后设计。届时应依据入选候选数、主要工作点、完整统计家族、校准方法及可用资源更新本预分析并冻结新 protocol；不得回改 R6-G 或历史阶段门。
