## 总纲映射

- **总体目标：** 以可信物理真值与传统算法知识训练任务级 GMTI 学生，直接从多通道复数回波检测目标、估计距离和连续 Doppler，并最终在任务质量约束下判断精度/完整处理成本价值。
- **科学问题：** Q1（教师/课程能否改善最终任务、样本效率或收敛）、Q2（哪种中间教师响应有用）、Q3（学生能否学习不同于传统链的最终任务表征）、Q4（物理先验怎样帮助优化并限制教师偏差）、Q6（低 SNR 任务质量和 Doppler）。
- **可证伪假设：** H-LEARN-001 课程排序；H-KD-D2-001 K2 软响应增益；H-ARCH-D2-001 普通实值 TCN 相干归纳偏置是否不足；H-OPT-D2-001 range/Doppler 多任务优化及训练—推理 range index 一致性。

## 证据、优先理由与路线决策

D1-E001 已证明 `TaskStudent` 在简化 AWGN 下可学任务，但高 SNR Doppler 精度明显落后频谱/ML 基线；D1-R1 没有证明时间均值池化是主要误差原因，也没有持续强梯度冲突证据；D1-E002 S2 的 Doppler 改善没有保护低 SNR 检测门，故不能继续把单一 lag-one 改动当作已解决路线。D2-A-E001 显示复杂静止杂波下可辨识任务存在，但 C 部分重叠困难。R3 证明 T0/T1/T2 固定阈值 G2 未通过，T1/T2 的幅度尺度和 H1 保护结果也不能替代教师阈值稳定性。

本任务不要求 truth-only 单独通过后才允许研究蒸馏；改为 A 全难度真值、B 课程真值、C 同课程加 K2 的匹配对照。C 中任务真值从头到尾保留，K2 是由 IQ 生成且经独立质量门审查的训练软目标。该问题比继续扩展 T1/T2/CFAR 搜索更直接推进总纲的任务级学生主线；也比直接扩大模型结构更能区分难度顺序与教师信息的作用。

## 成功、失败和边界

- 若 B 相对 A 出现预注册课程信号，支持继续研究课程机制；若 C 相对 B 出现预注册增量信号，支持另提多 seed K2 确认实验。单 seed 不证明跨种子收益。
- 若 A/B/C 仅某一臂成功，按其限制解释；若全失败，只有在数据、损失、梯度、参数输出、CUDA 和小样本过拟合检查均通过后，才把失败视作模型/优化证据。
- 若 K2 数值或尺度检查错误，或 C3 预注册的严重误导规则触发，只停止 C 并保留 A/B；不得以 K2 覆盖物理真值。
- 本轮不改教师固定阈值资格、不启动 formal 三 seed、不生成 final blind、不评价真实数据或完整链速度。
