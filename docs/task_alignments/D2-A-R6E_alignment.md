# D2-A-R6-E 研究主线对齐

- **总体目标：** 以物理真值和传统处理知识训练任务级学生，推进GMTI目标检测与参数估计；最终收益必须在完整任务指标中体现。
- **对应科学问题：** 总纲Q3（学生表示/架构）、Q4（物理先验与优化）、Q6（困难检测与参数精度）、Q10（学生如何获得并使用有效知识）。
- **可证伪假设：** 在相同场景和训练暴露下，显式公共相位等变CE-TCN相对普通卷积J1-J可改善C2/C3任务，且保护Doppler和C3 Pfa；保留完整网格交互的RAX也可能改善长程时间—距离建模。
- **执行依据：** R6-D确定J1-J为联合学生基线，现有训练结果仍受预算/容量和C3阈值限制；有限代表性架构筛选可为后续完整链与教学机制选择学生候选。历史TFAS单一负结果不否定所有非CNN模型。
- **本轮证据：** 新独立数据、单seed606、每臂51,200 matched updates。CE-TCN通过预注册C2+C3 joint增益与Pd/range/Doppler相对保护；RAX未通过。三个候选均未通过C3六格familywise绝对虚警门。CE-TCN公共相位一致性强，但频移诊断不通过；无蒸馏或传统算法对照。
- **决策影响：** CE-TCN可作为R6-F优先NN候选；J1-J保留为matched学生基线；当前RAX配置停止扩展。相对收益不等于低虚警资格，也不等于教师教学收益。
- **替代解释：** 单seed差异、架构/优化交互、各臂不同microbatch（但有效batch、顺序与update匹配）及重复场景暴露均限制因果归因。公共相位收益也可能只是归纳偏置影响，而不等于更广义频率等变。
- **成功/失败含义：** CE-TCN相对门通过支持其进入后续有界比较；C3绝对门失败阻止可靠检测器/盲测声明。RAX负结果只针对该配置。物理相位不变成立不能单独证明有益知识已被学会。
- **停止条件与下一步：** 不追加单臂训练、不搜超参数、不做蒸馏权重搜索。完成R6-E审计和缓存清理后，按总路线进入R6-F：先冻结完整pipeline对照及每链H0重校准；再基于R6-F与R5-C证据决定R6-G至多一种教师内容pilot。最终ChatGPT综合审查留至全部获批P0–P7目标完成后。
