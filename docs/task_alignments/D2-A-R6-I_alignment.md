# D2-A-R6-I 任务主线对齐

**日期：** 2026-11-23
**对应总纲：** `docs/RESEARCH_CHARTER.md` v1.3
**对应路线：** D2-A-R6 P1低虚警稳健性，服务P7候选准入；不构成独立CFAR研究。

## 研究目标与问题

R6-I服务总纲中“通过物理仿真真值和传统算法知识蒸馏，训练直接完成GMTI动目标检测与参数估计的学生”这一目标，并检查当前学生能否在可观测输入尺度变化下可靠检测。它聚焦的可证伪问题是：R6-H CNN-SSM的C3高虚警是否与每CPI可观测背景功率引起的检测分数尺度漂移有关；单一H0拟合的尺度校正能否降低C3虚警，同时保护检测、距离和Doppler任务。

本实验不重新训练学生，也不评估知识蒸馏收益。CUDA只用于冻结模型的学生推理，B3在相同IQ场景上作为传统检测基线。它是P7候选门前的有限诊断，不将传统统计量扩展为独立研究主线。

## 支持该任务的证据

- R6-H中CNN-SSM相对CE-TCN的C2+C3 joint-success差为`+0.03016`，但Range RMSE ratio为`1.070`且上界`1.165`，未通过1.05保护；三臂均未通过C3六格familywise Pfa门。
- R6-H CNN-SSM最难的C3 partial-overlap/SNR0/CNR20格Pfa点值为`0.1048`。
- R6-A困难C3 partial-overlap/SNR0格AUC约`0.596`，R6-B matched hard-negative pilot未证明最终joint收益。因此单纯阈值归一化未必能恢复困难格可分性；R6-I只检验一个明确定义的分数尺度假设，不预设其有效。
- R3已观察到可观测幅度统计和归一化统计能够抵消公共幅度缩放，但固定阈值跨条件门仍未通过。这支持区分公共尺度变化与条件内目标/杂波可分性，而不是用总体Pfa代替分层评估。

## 优先理由与决策影响

在启动新的训练预算、学生结构或教师损失研究前，先对已冻结CNN-SSM实施一次H0-only、单斜率、可观测尺度校正，可直接判断R6-H失败是否包含检测分数尺度问题。新H0拟合、阈值校准、H0验证和H1开发集分离；如候选通过预注册P7准入门，下一步才另行冻结多训练种子确认协议。若失败，则保留负结果并停止该校正，不在同一开发集搜索更多公式，也不据此引入知识蒸馏。

## 假设、替代方案与停止条件

- **主要假设：** `H-R6I-001`：CNN-SSM H0高分尾部与仅从IQ计算的稳健CPI功率存在可重复的尺度关系；一条在独立H0拟合的右尾斜率可达到C3逐格低虚警门，并保护Pd、C2+C3 joint、Range及Doppler误差。
- **替代方案：** 条件专属阈值需要部署时不可用的条件标签；重新训练并做尺度增强会混合训练/表示机制，不能单独检验分数尺度假设；raw分数是配对基线。
- **成功含义：** 只支持当前固定模型和该仿真场景中的一个可观测尺度校正值得进入新的P7多seed协议，不代表模型已满足部署可靠性。
- **失败含义：** 否定本次单斜率校正假设或其对当前固定模型的实际用途；不能否定所有可观测归一化、模型结构或教师知识。
- **停止条件：** 任意G0/G1失败即不生成正式评价数据；评价后未同时满足P7的overall/C3 Pfa、配对虚警收益和任务保护门即停止该校正，不启动final blind。

## 数据与边界

协议固定三通道、PRF 1300 Hz、130脉冲、32距离单元和R6-A的12个条件格。四个评价split计划合计246,144个独立CPI；训练与模型权重不变。场景ID先与历史CSV manifests及R6-D/E/F/G/H注册计划核查。所有差异都限于新开发数据；既有R6-H结果、冻结协议、研究总纲v1.3及历史负结果保持不变。
