# D1-E002 task alignment

**Date:** 2026-10-24
**Priority:** highest current experiment after D1-R1
**Status:** protocol frozen before candidate training; pilot not started.

## Research question

Does a low-cost, normalized lag-one complex-coherence readout (S2) improve continuous Doppler RMSE over frozen D1-A in the D1 single-target, three-channel complex-AWGN setting, while preserving detection and range? S1 is retained as a one-seed test of the weaker pooling hypothesis. S3 is a separate FFT-assisted hybrid with an exactly matched nonlearning interpolation reference.

## Existing evidence

- D1-R1 used D1 development/train/validation material only. For A, predicted-range and true-range-oracle Doppler RMSE were nearly equal at 0/5/10/20 dB; high-SNR range selection is therefore not the main observed error source.
- The fixed ridge probe after temporal pooling was lower-error than the 4160-dimensional pre-pooling probe, but the sample/feature ratio prevents a causal conclusion. This supports testing S1 once, not broad pooling searches.
- Final-checkpoint task-gradient cosine means were near zero, with seed/SNR variability and no training-only spectrum checkpoint. This does not support changing multi-task weights or adding teacher losses.
- D1 A high-SNR RMSE remains roughly 20–32 Hz; the APX15/FFT and profile-likelihood references are substantially more precise. R1 supports a frequency-readout experiment, not an assumption that the student should exceed ML.

## Accepted design and rationale

- S2 is the primary pure-IQ candidate because lag-one phase directly represents pulse-to-pulse phase advance while adding only 12 parameters and no FFT.
- S1 is one four-segment readout with no new convolution. It enters formal seeds only if its single pilot clears the same predeclared validation screen.
- S3 is explicitly hybrid: fixed 520-point FFT plus a 385-parameter residual MLP. Its learned contribution is compared with parabolic and five-bin nonlearning estimates using the same FFT, patch, sample IDs, and predicted range gate.
- All candidates use E1 simulator-truth supervision only. Teacher hard outputs and soft responses are not training targets; D1-D remains a frozen historical reference.
- Train/validation/pilot/calibration/blind seeds are allocated in new, disjoint ranges. No E002 blind sample has been generated. Existing D1 final-blind predictions remain unopened for model selection.
- S0, training budget, optimizer, data counts, primary endpoint, detection/range guardrails, pilot screen, bootstrap and stop gates are fixed in `experiments/D1-E002/config.yaml` and `protocol.md` before training.

## Success interpretation

A pure-IQ result supports H-ARCH-002 only if S1 or S2 improves the equally weighted 0/5/10/20 dB Doppler RMSE by at least 10%, the paired hierarchical 95% CI for candidate minus S0 is below zero, at least two of three formal seeds improve, and the frozen low-SNR detection and high-SNR range noninferiority gates pass. S3 can only support a claim about the FFT-assisted hybrid if it also beats its matched nonlearning FFT estimate under the separate gate.

## Failure interpretation and stop rule

Pilot failure means the candidate is not trained on three formal seeds. If no pilot passes, no new blind set is generated. If formal results fail the primary criterion, remain statistically inconclusive, or violate either guardrail, the pure-IQ structure search stops; no extra architecture, loss, or threshold tuning is allowed under E002. A successful S3 alone is reported as a hybrid result and does not count as pure-IQ learning success. D1-E001 G1/G2/G3 remain unchanged in all cases.

## Alternatives rejected

- More temporal bins or larger TCNs are not justified by the R1 probe and would confound this bounded test.
- Changing task-loss weights is not justified by the final-checkpoint gradient evidence and would add an independent factor.
- Adding KL/distillation before establishing the base frequency mapping would obscure whether the readout learned the signal. D1-E002 therefore uses only E1 truth supervision.
- Using old D1 blind data or lowering thresholds after pilot would bias the comparison and is prohibited.
