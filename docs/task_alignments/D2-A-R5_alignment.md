# D2-A-R5 研究主线对齐

**日期：** 2026-10-27
**对应总纲：** 本次用户授权修订前为 v1.2；Phase 0 更新为 v1.3。

## 对齐

- **总体目标：** 找到适合机载多通道 GMTI 复数观测的学生结构，以物理真值监督并检验传统教师知识能否改善最终目标检测和连续参数估计。
- **科学问题：** Q1/Q2/Q3/Q4/Q6/Q8/Q9，以及 v1.3 新增 Q10（模型容量、训练充分性、架构归纳偏置和知识吸收机制）。
- **现有证据：** E003 在 51,200 配对场景上训练 1,600 updates，仅一轮；S0 验证损失末段仍改善，S2 末次验证也达当前最低。E003 负结果有效于其单轮预算/结构，不是架构最终能力上限。E002 的课程/K2 单 seed pilot 未给出任务收益，R3/T001 固定阈值教师门失败；这些结果未检验所有可蒸馏知识形式。
- **现在优先理由：** 在扩模型或蒸馏之前先排除欠训练；再用单因素容量比较和一个非 CNN pilot 检验架构适用性；只有经过质量审计的教师知识才进入教学对照。
- **路线影响：** 若 6,400 更新仍改善，不推断容量受限；若训练充分 S0 优于 S2，则停止当前 S2，而不否定一般物理表征；若适用知识无质量/教学收益，则收缩 KD 分支，保留真值学生路径。
- **替代方案：** 直接开展更多教师变体或更复杂 KD；当前不优先，因为教师资格和学生训练充分性尚未确立，信息效率较低。
- **成功含义：** 获得可复现、预算匹配的训练曲线；识别容量/架构与可吸收知识；至少一个模型在任务保护下较强基线或真值基线有有意义收益。
- **失败含义：** 按门停止相应结构或知识形式，保留负结果；若所有模型无法达到基本任务质量，重新评估学习主线价值，不无限搜索。
- **停止条件：** 数值/数据错误；无法在 CUDA 上保持预算；训练后仍无基本可学习性；新增容量/架构无任务收益或明显退化；教师知识不可观测、泄漏或错误严重；KD 不胜同条件真值监督。

## 数据和盲测边界

R5-A 复用 E003 的冻结训练/验证样本用于可控预算曲线；这些样本不是新盲测。旧开发集只用于诊断和候选筛选。最终确认仅在架构/损失/阈值/模型选择冻结后，生成全新的独立测试场景。
