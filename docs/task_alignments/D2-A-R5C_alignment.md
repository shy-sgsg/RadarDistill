# D2-A-R5-C 教师知识质量审计任务对齐

## 研究主线

- **总纲目标：** 通过可信物理真值和传统处理知识训练可直接完成 GMTI 检测与参数估计的学生；分别评价教师任务能力、知识质量与学生教学收益。
- **科学问题：** Q1/Q2/Q4/Q9/Q10；检验 B3 DPCA 输出的完整谱图与连续频率局部响应是否包含可辨识的目标位置/Doppler 信息，以及可观测响应尖锐度是否能识别不可靠的教师输出。
- **假设：** H-TEACH-002（局部/连续知识是否优于完整响应）和 H-TEACH-004（可观测可靠性信号能否识别错误知识）。不重新解释 H-ARCH-003 或 H-LEARN-002。

## 证据、优先性与路线

- E002 的 IQ-only K2 质量审计在可辨识 A/B/C 有正 target-window lift，但 C3 partial-overlap/SNR=0 dB 定位率仅 0.0471、lift 仅 0.000673；K2 学生相对 matched truth-only 的 joint 差 +0.0036，95% CI 跨 0。
- R3 的 T1/T2 未通过固定阈值迁移门；T001 ACE×AMF 的正确性/检测门失败。它们不自动否定非阈值软响应，但目前没有已获完整检测门认可的传统教师。
- R5-A Medium 在 C2/C3 任务指标优于 Small，却未通过 C3 H0 Pfa 绝对门；R5-B TFAS 未通过 G3。教师质量审计不依赖 TFAS 晋级，也不把 Medium 视为已通过完整任务门的学生。
- 原始用户任务明确授权 R5-A 至 R5-D 并允许证据支持的阶段交叉。R5-B ChatGPT 审查仍待用户外部完成；本次仅继续与学生架构无关的 R5-C G4 教师质量审计，不训练学生、不运行 KD、不生成 blind。此路线边界不修改 R5-B 失败门或历史结论。

## 最小实验、决策影响与停止条件

- 在全新 scene seeds 上，对同一冻结 B3 DPCA 前端比较 K1 原生 RD 软响应、K3 4× Doppler 支持响应及从教师自选距离门提取的局部频率响应；教师只接收 IQ 与冻结物理配置，运行于 RTX 3050 Laptop `cuda:0`。
- H0/H1 使用相同 base scene 背景/噪声配对；预注册分层关注 C3 六个场景/SNR组合，并保留 C0/C1/C2 作为难度参照。真值只进入离线评价。
- 若没有任何候选在可辨识条件提供可检验的目标相关响应，或数值/输入隔离失败，停止该知识形式；不追加学生训练。若存在正信息但严重局限于部分条件，只能提出后续有明确可靠性分层的独立学生 pilot，不能声称普适有效。
- 完成将改变“哪些知识值得做一次 matched student pilot”的判断；不会改变固定阈值教师资格，也不会回答蒸馏收益、学习时机或机制因果问题。
- 更简单替代方案是只重复旧 K2 audit，但其样本已参与既有选择，不能提供新场景复核或连续频率知识比较；更复杂的新 ACE/AMF/教师搜索会混淆教师算法与知识表达。本轮使用有界的共同 B3 前端比较。
