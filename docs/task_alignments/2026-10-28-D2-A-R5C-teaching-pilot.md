# D2-A-R5-C Teaching Content Pilot 任务对齐

## 研究主线

- **总纲：** `docs/RESEARCH_CHARTER.md` v1.3；本任务不修改总纲和历史冻结协议。
- **总体目标：** 用物理真值与教师知识训练可直接完成 GMTI 检测及参数估计的学生，检验教师软知识是否带来独立的最终任务收益。
- **科学问题：** Q1/Q2/Q4/Q6/Q9/Q10；验证完整 K3 响应和 IQ-only K2-local 响应能否改善同一学生，及收益是否只是额外辅助监督的效果。
- **待检验假设：** H-TEACH-002（任务相关教师知识能否改善最终任务）、H-LEARN-002（学生能否吸收相干频率信息）。本 pilot 不检验教师时机、置信度校准或可靠性加权。

## 证据与优先性

- R5-C 的 K3 相对 K1 在 C2+C3 的教师定位率增加 `0.03125`（配对 95% CI `[0.02474, 0.03776]`）；该证据只说明教师响应含任务相关信息，不证明学生能吸收。
- 在 C3 部分重叠、SNR 0 dB、CNR 20 dB 子组中，K3/K2-local 定位率仅 `0.0410`。新实验须保留负蒸馏保护，并分别报告教师正确与错误样本上的学生指标。
- R5-A Medium width=96 是当前受测学生中表现最佳者，但 C3 H0 Pfa=`0.18896`，尚未达到 `0.10` 保护门。R5-B 当前 TFAS 候选按冻结门停止。
- 独立审查针对 R5-C 结果提交 `7563c822e70afe761897ddd5e91bb64207720f89` 返回 **REFINE**，明确支持完成协议、实现、前置测试后运行一次 T0–T3 单种子 pilot。

## 已冻结的最小验证实验

- 四臂使用同一 `TaskStudent(width=96)`、seed-303 位相同初始化、相同场景顺序、12,800 updates、有效 batch 64、FP32 和同一验证 checkpoint 规则。
- T0 为 truth-only；T1 为 truth + K3 全图软响应；T2 为 truth + IQ-only K2-local；T3 为匹配的 truth-assisted 局部响应对照，不是教师。
- T1–T3 使用同一 `[520,32]` 归一化响应支持与展平 KL。局部响应放在各自选定距离门；错误教师距离门只影响辅助损失，不替代物理真值。
- 训练 51,200 对和验证 5,000 对场景使用新 seed 与 R5-C 阶段专属 memmap；与 R5-A ID 不重叠。评估校准、验证和 H1 开发集另用互斥 seed 区间。所有 IQ-only 教师调用均在 `cuda:0`，不静默回退 CPU。
- 主终点是配对 C2+C3 joint success 的 T1−T0 与 T2−T0 差值；另保护 Pd、C2+C3 RMSE 和 C3 H0 Pfa。C3 部分重叠、0 dB 子组与 teacher-correct/incorrect 分层预先单列。

## 决策影响与停止条件

- G0 通过、fresh 数据生成完成且 G1 对四臂均通过后，只允许执行本协议规定的一次单种子 T0–T3 pilot。
- 只有主收益门和所有任务保护门都通过的教师臂，才可提出独立多种子确认协议。单种子场景 bootstrap 不代表训练 seed 不确定性；C3 Pfa 不通过时不得宣称学生具备检测资格。
- 若 T0 学会基础任务而 T1/T2 均无最终任务收益，停止当前教师内容分支；不进入时机、可靠性搜索、多种子正式实验、final blind 或完整 R5-D 机制实验。
- 评估完成后仅移除本阶段 manifest 明确列出的四个 IQ 缓存文件，保留 checkpoint、历史、scene/seed manifest、配对计划、物理真值、指标及负结果；最终项目体积小于 20 GiB，不删除用户未跟踪文件。
