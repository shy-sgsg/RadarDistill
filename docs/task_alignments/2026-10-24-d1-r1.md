# D1-R1 研究主线对齐

**日期：** 2026-10-24
**基线提交：** 09724a4
**当前阶段：** D1 有界误差诊断

- **服务的研究目标：** 提高任务级学生的连续 Doppler 估计精度，并判断是否值得保留当前 IQ 主干或改变读出结构。
- **科学问题 / 假设：** Q3、Q4、Q6；H-ARCH-001（时间均值池化限制频率读出）和 H-OPT-001（多任务梯度冲突）。
- **已有证据：** D1-E001 真值监督 TCN 在 20 dB 的 Doppler RMSE 为 25.95–35.13 Hz，远高于 4× FFT 插值和 profile-ML；模型在 temporal blocks 后按时间均值池化。学生的时间感受野覆盖输入，因而误差不能仅归咎于感受野不足。C/D 联合指标有有限收益，但没有收敛加速证据。
- **优先理由：** Doppler 是 D1 与传统估计器差距最大的任务。先分开距离门选择、特征池化和损失优化等解释，能让后续 E002 只改变有证据支持的一项。
- **完成后将改变的判断：** 标记频率信息主要在读出、距离耦合、优化或教师辅助中的哪个位置受限，并选出是否值得进入 pilot 的最小结构修改。
- **与总纲一致：** 一致。仅复核已有 D1 AWGN 训练/验证材料，不加入杂波、多目标、通道失配，不重开冻结盲测。
- **替代方案：** 立即扩大网络或加入 FFT 会混淆原因；继续原架构训练不能区分既有竞争性解释。先用开发数据诊断成本更低。
- **成功意味着：** 数据、checkpoint 和计算诊断可复核，至少能排除一项竞争解释并提出一个有界 E002 候选；不代表因果已被证明。
- **失败意味着：** 若诊断无区分力或训练期 checkpoint 缺失，应明确给出不可计算项；不得以猜测为结构修改背书。
- **停止条件：** 不触碰盲测；若缓存或 inference checkpoint 不完整则停止对应分析并保留现状；若没有某结构机制的差异证据，不继续叠加结构与损失改动。
