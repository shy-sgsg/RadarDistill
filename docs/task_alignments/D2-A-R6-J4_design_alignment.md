# D2-A-R6-J4 设计对齐

- **研究总纲：** `docs/RESEARCH_CHARTER.md` v1.3；服务于任务级学生、物理先验与完整处理成本，主要关联Q1/Q3/Q4/Q6/Q8/Q10。
- **目标：** 为R6用户路线中明确要求的J4（物理驱动联合检测估计）给出可证伪设计，区分固定相干前端、学习读出与二者协同。
- **问题/假设：** 几何DPCA与慢时间候选响应是否能帮助学习器从同一复IQ中联合估计检测、距离和周期Doppler，并在固定虚警评价下优于匹配J1或传统峰值读出？尚未测试。
- **当前证据：** R6-D已运行J1共享多任务与J2学习式软候选/反馈；J2有joint/range收益但Doppler保护失败。R6-F显示B3+频谱链可作同场景物理参照。两者均不是J4证据。`d2a_baselines.py`已有几何分数时移DPCA实现可供复用。
- **优先理由：** 用户明确要求设计物理驱动联合候选；J4可补足“学习式软候选”与“固定物理前端”之间的对照，且设计工作不占用正在运行的R6-G GPU资源。
- **方案与取舍：** 首选固定DPCA+520点零填充频谱候选层，再由学习头完成null候选、连续参数和有界反馈。物理初始化可学习滤波器与展开式似然作为后续备选，首轮不混入。
- **决策影响：** 若后续协议入选J4，物理峰值、J4学习读出、J1原始IQ三者分层评价；只有学习读出超出物理参照并保护最终任务门，才支持学习器的增量贡献。
- **成功含义：** 新独立场景上joint收益具配对统计支持，Pd/参数保护通过，且C3虚警门通过；这是候选晋级证据，不是生产资格。
- **失败含义：** 正确性通过但无任务增益，仅否定当前J4参数化；若固定物理前端有效而学习读出无增益，收益归于物理处理，不归于学习贡献。
- **停止条件：** G1数值/物理/梯度门失败则不生成正式数据；任务保护或C3门失败则不晋级；不加KD掩盖基础映射失败，不根据开发集无限调参。
- **路线边界：** R6-G完成前不做J4 G0/G1、场景ID扫描或CUDA训练；R6-D冻结协议与结果不改写；final blind未获授权；ChatGPT最终审查提示词留到整条批准路线完成后。
