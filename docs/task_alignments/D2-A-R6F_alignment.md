# D2-A-R6-F 主线对齐

- **总纲目标与问题：** 服务于由复数多通道观测直接完成 GMTI 检测和参数估计，并评价完整链路而非孤立子模块。对应 Charter v1.3 的 Q1/Q3/Q6/Q7/Q8/Q9/Q10；不把传统模块本身变成独立研究主题。
- **当前证据：** R6-E 的单 seed development 显示 CE-TCN 相对 J1-J 的 C2+C3 joint 提升 +0.02713，但二者 C3 六格 familywise 虚警门均失败。CE 具有相位旋转不变的实现证据但没有频移等变证据。R6-E 没有传统/传统、混合链、KD 或完整前后处理成本比较。
- **本任务问题/假设：** 在每条完整链重新用自身 H0 校准后，CE-TCN 与 profile-ML 组合是否比 B3+4×FFT 传统链或 CE/J1 原生联合链改善可辨识 C2+C3 joint success；改进由检测、估计还是二者共同造成；是否能满足完整链 H0 资格。
- **为什么现在做：** 用户已批准 R6 P0–P7 顺序路线；R6-E 已按协议选出 CE-TCN 优先候选、J1-J 配对参考。完整链结果是决定 R6-G 教师知识 pilot 是否有可教且可保护的任务链所需证据。
- **决策影响：** 仅将通过自身 H0 与任务保护门的链作为候选合格系统；相对开发收益不能替代全链资格。结果将确定是否保留 CE、传统检测+神经估计、神经检测+profile-ML 及统计验证作为下一阶段学生/教师工作载体。
- **替代方案：** 继续只测子模块会遗漏阈值转移、候选传播和端到端估计损失；直接开始蒸馏无法分清基线完整链瓶颈。当前六条链是预先有界的 A–F 对照，不进行额外架构、统计组合或阈值搜索。
- **成功含义：** 至少一条神经/混合链在同一新场景上，相对 A 有达到预注册幅度且有置信区间支持的 joint 收益，同时保护 Pd、参数误差并通过自身 H0 门，才支持其进入 R6-G/P7 候选。
- **失败含义：** 若任务收益或 H0 保护失败，保留子链的分层证据，但不能宣称系统优势；若所有链均无有价值收益或不合格，应在阶段报告中评估缩减/停止当前完整系统路线，不用蒸馏掩盖全链失败。
- **停止条件：** G0/G1 真值泄漏、scene 冲突、实现/数值错误或 CUDA 不可用时不生成正式结果；全链 evaluation 只运行一次，不能用 H0 verification 或 H1 development 反复改阈值/组合。`docs/RESEARCH_CHARTER.md` 保持不变。
- **阶段结论：** 已按冻结方案完成G0/G1与一次开发评价。CE-TCN原生链的C2+C3 joint差相对A为`+0.57813`（99%区间`[+0.56141,+0.59397]`），但六条链全部未过C3 familywise Pfa门；C/F profile-ML链及D传统检测混合链均未提供全链晋级依据。阶段分析见`experiments/D2-A-R6/R6-F/analysis.md`；结论为REFINE。R6-G可按授权另立有界教学协议，不能视为已有KD收益。
