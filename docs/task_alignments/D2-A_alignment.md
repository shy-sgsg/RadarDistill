## 对齐检查

- **服务的研究目标：** 在进入三通道学生训练前，验证三通道复回波中的地杂波相干结构、目标可辨识条件和传统处理上限；为后续 GMTI 检测及参数估计建立物理可信的训练任务。
- **科学问题 / 假设编号：** Q1、Q2、Q3、Q4；检验“共用散射点和真实运动几何生成的静止杂波仍保留通道间相干性”及“分辨能力随目标与杂波距离/多普勒重叠而下降”等 D2-A 假设。具体假设及门槛在 `experiments/D2-A-E001/protocol.md` 冻结。
- **可检查的已有证据：** D0-E001 已验证无杂波三通道 range-compressed IQ 的基本生成和 12 项回归测试；D1-E001 / E002 已暴露低 SNR 检测和传统基线差距；D1-E002 后审查明确要求转入静止杂波因素。APX15 只读审计发现生产场景 XML 与研究配置在载频、脉冲数、距离分辨率和通道数量上存在差异，详见 `docs/research/D2-A_system_parameters.md`。当前 `CURRENT_STATUS.md` 的基线 SHA 字段也与实际 `main` 不符，按本任务证据更新。
- **优先开展的理由：** 杂波是三通道 GMTI 的核心观测因素；若继续用 AWGN-only 学生结果推导三通道检测能力，会跳过研究问题。必须先确认仿真符合运动平台传播几何、配对 H0/H1 和基线实现正确，再决定是否训练学生。
- **完成后将改变的研究判断：** 判定 R0 信号生成和物理测试是否成立、R1 传统检测基线/可辨识场景是否足以支撑学生任务，并冻结后续学生比较方案；只有前门通过，才另行启动正式训练和新盲测。
- **与研究总纲是否一致；如有偏离及依据：** 一致。遵守先模型/基线/可辨识性、一次只增加有限困难、教师标签与物理真值分离、旧负结果不改写、训练/验证/校准/盲测隔离。D2-A 以开发仿真和已用开发集诊断协议，不把开发结果冒充盲测。
- **更简单或更有价值的替代方案：** 继续 AWGN 结构搜索已被 E002 冻结停止门否定；直接开始 D2 网络训练会把仿真失配与学习失败混为一谈。先完成配对物理模型和传统基线是能区分这些原因的最低复杂度方案。STAP 若受快拍数/独立训练样本限制，将记录限制而不把欠定协方差结果包装成强基线。
- **成功结果意味着：** R0 的规定物理/统计测试通过；共享场景与噪声配对可复现；A–D 可辨识场景符合观测信息；R1 在独立 H0 校准下给出可解释的 Pfa/Pd、误差、杂波抑制和目标保真结果；R2 协议包含数据划分、监督/蒸馏消融、预算、指标、阶段门和停止规则。成功不等于 AI 优于传统算法，也不自动授权正式训练。
- **失败结果意味着：** 先按失败测试修复模型/实现；若 R0 基础物理或无杂波回归不成立，停止 R1/R2 结论并保留失败记录。若模型成立但重叠区目标不可辨识或传统检测失败，则如实记录可辨识边界并据此停止/重定 D2，而不是要求学习模型恢复不可用信息。
- **停止条件：** T1–T12 任一核心物理/配对/泄漏测试失败且未修复；H0 误警校准无效；基线没有按相同观测和预算比较；目标-杂波重叠场景被错误宣称可恢复；或正式协议门槛被结果事后修改。学生训练和最终盲测在 R0/R1 验收之前禁止启动。

## 执行边界

- **数据和拆分：** 保持 D0/D1 的 PRF=1300 Hz、N=130、3 通道、32 个距离单元和 range-compressed IQ 接口。场景按 base-scene ID 分 train/validation/calibration/development-test；H0/H1 在同一散射场和噪声 realization 上成对生成。此阶段不生成 final blind 数据。APX15 包和已有 D1 缓存只读、不暂存。
- **传统基线：** B0 单通道；B1 三通道非相干融合；B2 几何感知相干波束形成/角度搜索；仅当真实仿真几何支持且分数对齐测试通过时评估 B3 DPCA。STAP 依据独立训练快拍与自由度作出实现/排除决定；oracle 只可标记为不可部署诊断上限。
- **训练预算 / 资源：** R0/R1 为 CPU 仿真与确定性传统算法，不开展正式神经网络训练。R2 只冻结模型和训练协议；未来若进入正式训练，沿用 RTX 3050 Laptop GPU 4 GiB 约束，顺序训练并实测资源。
- **盲测是否冻结：** 不生成或解封 final blind；预注册并冻结未来盲测拆分、场景和门槛，但模型选择阶段只能查看已有开发数据。
- **输出文件：** 任务对齐、APX 参数审计、设计与实施计划、R0 源码/测试、R1 配置/结果/分析、`experiments/D2-A-E001/protocol.md`、R2 冻结配置、动态状态/路线/假设/进展/决策/阶段审查。
- **禁止事项 / 历史结论保护：** 不改写 D0/D1 的数据、指标和负结果；不触碰生产 GMTI 链；不把 APX15 未跟踪源码包、实验缓存或模型文件加入提交；不开始正式学生训练或生成最终 blind；所有本任务改动直接提交到 `main` 并推送到 `origin/main`。
