# D2-A-R6 SSM / 混合架构后续任务对齐（草案）

> 状态：非冻结草案，仅用于记录覆盖缺口与后续设计方向。不得据此启动训练，也不修改 R6-G 冻结协议或历史结果。

## 任务与研究主线

R6 的架构研究应检验哪些学生表示能从三通道复数慢时间 IQ 中学习目标检测、距离与 Doppler 信息，并为后续教师知识迁移提供合适学生平台。状态空间模型（SSM）和 CNN-SSM 混合结构属于已列入研究路线、但尚未在当前受测架构中验证的方向。补充评估它们可回答：保留复数相干结构的序列模型是否比当前 CE-TCN 更适合短 CPI；局部卷积特征与序列状态建模组合后是否改善 Doppler 学习与困难场景检测。

本任务服务于 RadarDistill 的任务级学生与知识迁移目标，不扩展为独立架构竞赛。研究总纲、冻结阶段结果和 R6-G 运行均保持不变。应在 R6-G 完成后再形成正式独立 protocol。

## 已有证据与覆盖边界

- `docs/superpowers/specs/2026-10-28-d2-a-r6-research-design.md` 的 P4 将 SSM / 混合结构列入研究范围。
- `docs/superpowers/specs/2026-11-01-d2-a-r6e-architecture-screen-design.md` 的有界筛选实现了 J1-J、相位等变 CE-TCN 和 RAX Transformer，并明确将 SSM / 混合结构留待后续；这不是对这些架构族的否定。
- 当前 CE-TCN 可作为已有基线；单个 RAX Transformer 候选的负结果不能外推为所有序列架构失败。
- 相邻雷达研究展示了 SSM 在雷达任务中的可行性，但应用任务和输入不同，不能作为本项目效果证据：[Unfolding Target Detection with State Space Model](https://arxiv.org/abs/2410.22774)研究 FMCW 雷达距离-方位检测；[RadMamba](https://arxiv.org/abs/2504.12039)研究微多普勒人体活动识别，并强调保留时间/多普勒轴结构。基础 Mamba 的选择性状态空间设计来自一般序列建模：[Mamba](https://arxiv.org/abs/2312.00752)。以上只支持开展有界验证，不支持预判优于 CNN。

静态检查 `src/radardistill/students/r6_architectures.py` 确认，R6-E CE-TCN 从 `[B,6,130,32]` 六平面输入还原三通道复数 IQ；使用无偏复数 `(1,3)` 距离 stem、七个慢时间扩张率为 `1,2,4,8,16,32,64` 的复数残差 TCN block、幅度 RMSNorm 与径向 modReLU，最后沿时间平均模长并输出 presence、range cell/offset、Doppler 向量。它不包含 FFT 或固定频谱层；公共相位等变性来自复线性、径向非线性和模长读出。代码和协议不声称 Doppler 频移等变。后续比较应保留 CE-TCN 作实际基线，并把公共相位性质和慢时间频率学习分开验证。

## 候选方案

### A：复数双向对角 SSM

输入沿用六平面复 IQ。先用无偏复数 `(1,3)` 距离 stem 在每个脉冲提取局部距离上下文；将每个距离位置的 130 脉冲序列送入复数状态空间层。对每个通道 d，用多个稳定复极点构造可学习状态响应核 `K_d[l]=Σ_m C[d,m]·λ[d,m]^l·B[d,m]`，约束 `|λ[d,m]|<1`；对核做零填充线性卷积，而不是循环卷积。前向和反向扫描分别用各自的因果核，反向支路先反转 CPI 序列再卷积。门控仅由模长生成并作用于输入/残差，不改变核内状态转移。每个距离单元独立沿130脉冲处理，不能把32个距离单元和慢时间展平成一条序列。

AISAR 使用 PyTorch 2.8；本机 `torch._higher_order_ops.associative_scan` 文档明确为 prototype、需要 CUDA codegen 且不支持 autograd，因此本轮不依赖该 API。固定极点 SSM 的递推可等价写成有限长卷积；使用标准可微 `torch.fft.fft`、至少259点且建议512点的零填充计算线性卷积。该 FFT 只是实现可学习状态核的数值卷积，不是固定雷达频谱层。此候选是复数对角 SSM，不宣称等同于完整 Mamba 的输入依赖状态转移；若基础 SSM 有收益，动态选择转移另作单因素后续研究。

全局公共相位乘子会同时旋转复数输入、状态核输出和残差；因门控只依赖模长、核和通道映射均为复线性，模型理论上可保持特征等变与任务读出不变。需通过单元测试确认，不能只凭结构描述宣称通过。

### B：复数卷积前端 + 复数双向 SSM

使用 CE-TCN 风格的复数 `(1,3)` range stem 和一个复数 `(3,1)` 时间局部残差 block，再用与 A 相同类型的三层双向 SSM 聚合 130 脉冲范围内的信息，最后接与 CE-TCN 相同的任务输出头。此臂检验局部卷积归纳偏置是否能改善 SSM 的任务学习；参数量、深度和有效状态维数须受限，以便与 CE-TCN 进行有界匹配。

### C：继续扩大通用注意力模型

当前没有足够证据支持将其列入本轮。已有 RAX 结果只代表已测实现；再次扩大注意力模型会增加变量，且无法直接填补 SSM / 混合结构覆盖缺口。本草案建议先比较 A、B 与已有 CE-TCN。

当前主效应对照为 CE-TCN、A、B 三臂；A 与 B 是预注册前的候选设计，并非已冻结实验臂。对照统一使用三通道原始复 IQ、相同四任务输出接口、真值损失、训练/验证/校准/开发数据、有效 batch、更新数、优化日程和 checkpoint 选择。建议按 CE-TCN 推理模型 63,429 参数作容量参照，目标参数量暂定在其 ±20% 内；正式容差和各模型具体参数数须在协议冻结前静态核算。

按每块宽度 D、每通道 M 个复状态极点估算：无偏复输入/输出通道映射共 `4D²` 实参数，实值幅度门控约 `D²`，双向 B/C/极点主项约 `12DM`，其余方向融合、归一化与阈值为 O(D)。独立实现后的静态计数为：D=56、M=8、三块 SSM **65,077** 参数；加入一个复数局部残差块的 CNN-SSM **71,909** 参数。相对 CE-TCN 的63,429参数，二者均在预设±20%匹配范围内。正式 G0 仍须对冻结实现重新计数，不允许查看训练或开发结果后调宽度。

目前只完成独立模型模块和 CPU 单元测试，尚未生成 R6-H 正式数据或训练。测试已覆盖复数线性卷积与直接卷积对照、CPI边界不循环、range 轴隔离、complex64/complex128、复数公共相位等变、有限非零梯度、四任务输出形状、默认参数量范围及整 bin/off-bin/Nyquist邻域 tone 的有限输出。R6-E相关架构测试与新测试合计18项通过；正式 preflight、CUDA显存和吞吐测试仍需在 R6-G 安全结束后执行。

建议在 R6-G 完成后，对 A、B 和 CE-TCN 做参数规模、训练数据、场景顺序、有效 batch、优化器更新数和模型选择规则匹配的有界筛选。训练预算不在本草案中定死：结合 R6-E 与 R6-G 的验证曲线，选择足以识别学习趋势且三臂完全匹配的首轮预算；若三臂在预算末端仍明显改善，后续只能按共同预算另行预注册延长，不单独追训表现较弱的臂。候选层数、状态维数、参数量容差、预算与阶段门均须在正式 protocol 中冻结。

## 拟议的独立筛选框架（非冻结）

- **监督与输入：** 仅使用 E1 物理真值监督。三臂输入相同三通道复 IQ，输出 presence、range cell、range offset 和周期 Doppler 向量；不含教师损失、FFT 输入或真值推理特征。R6-G 结果单独归档，不与本比较合并。
- **比较臂：** 重训 CE-TCN、复数双向 SSM A、卷积加 SSM B。以同一实际训练/验证样本、场景顺序、初始化 seed、有效 batch、优化器与 checkpoint 选择比较；不同模型不能逐权重匹配，因此报告参数量及预算。
- **数据：** 正式 protocol 应在全仓历史 manifests 上选取从未用过的新 seed/scene IDs；初步预算可按 R6-E 量级规划：51,200 H0/H1 配对训练场景、5,000 配对验证场景、独立 H0 calibration/verification 各120,000 CPI、H1 development 6,144 CPI。H1 development 仅用于完成训练选择后的单次架构评价，不叫 final blind；P7 另建确认集。
- **分级预算：** 先为三臂预注册同一个25,600-update筛选预算及共同 checkpoint 规则。若验证曲线触发预先冻结的延长条件，进入第二阶段的比较臂必须统一延至51,200 updates；若不触发则三臂均在25,600结束。趋势规则、学习率计划及延长条件在正式 protocol 中冻结，不能看 H1 development 再决定。该分级设计旨在限制资源，同时避免把短预算结果误写成模型上限。
- **阈值与任务：** 每个模型只由自己的独立 H0 calibration 阈值设定同一总体 `Pfa_CPI=0.05` 工作点，H0 verification 验证迁移，H1 development 报告全局与12个条件格的 Pd、Pfa、AUC、range/Doppler RMSE及 joint success；六个 C3 格的 familywise 虚警保护独立判定。该筛选不声称验证 `1e-3` 或更低 Pfa。
- **晋级边界：** 单 seed paired scene bootstrap 只作架构筛选。若候选相对重训 CE-TCN 有预注册的联合任务收益且主要任务不退化，可提名进入 P7 多 seed/新确认集；C3 低虚警绝对门失败时仍不得称为合格低虚警检测器。架构筛选结果本身不证明教师更会教学，教师增益须在后续 matched truth-only / truth-assisted 对照中单独验证。

## 必要诊断与停止条件

1. 测试公共复相位旋转：对输入乘以 `e^{jφ}`，检测、距离和 Doppler 输出应保持不变；同时检查复数中间特征应随输入相位共同旋转。
2. 测试单音及混合频率慢时间频移：对输入乘以 `e^{j2πΔf n/PRF}`，报告 Doppler 输出的周期回绕误差、检测变化和距离变化。频移等变不是 SSM 的理论保证，必须以实测结果判断。
3. 检查递推方向、状态初始化、序列两端和 Nyquist 邻域；前向/反向状态不能把跨距离 token 当作连续慢时间样本。
4. 做小样本过拟合和梯度检查，确认复数状态分支、门控分支及各任务头都有有限、非零梯度。
5. 在同一独立开发划分上报告不同 SNR、A/B/C/D 与困难 C3 子组的检测、参数误差和 joint success；不得用多次用于架构选择的开发集冒充最终盲测。
6. 记录参数量、样本暴露量、优化更新、训练/验证曲线和实际 CUDA 资源；模型顺序训练，禁止静默 CPU 回退。
7. 若在排除实现错误后，A 或 B 仍无法学会基础频率映射，或任务表现显著落后且训练曲线已停止改善，则保留该负结果并停止该候选，不扩展为无界搜索。单候选失败不否定整个 SSM 或混合架构家族。

只有候选在真值监督下已显示可靠的任务学习能力，才进入新的、匹配对照的知识迁移实验；不把架构筛选与教师蒸馏收益混为一谈。若候选没有带来有意义的学习或困难场景收益，应保留 CE-TCN 基线并重新评估是否继续投入。

## 执行顺序

1. 等待 R6-G 正常完成；不查看中间H1开发结果，不修改其代码、配置、冻结协议或运行文件，也不做训练状态轮询。
2. 使用 R6-G 结果及本草案形成独立任务对齐与正式 protocol，审查数据独立性、预算、公平性和停止门。
3. 对已实现的 A/B 完成正式 preflight、显存/吞吐核验和匹配的小样本学习检查；这些验证顺序训练，不能与 R6-G 争用 GPU。
4. 先按共同25,600 updates进行筛选；只有正式协议预注册的验证趋势延长门触发时，所有仍在比较的模型才共同延长至51,200，不默认所有模型都训练到51,200。
5. 根据冻结筛选门决定是否晋级多种子实验或后续教师教学比较。

## 当前未决项

- SSM 与混合模型的精确状态维数、层数和参数量匹配范围。
- 筛选更新预算及检查点间隔。
- 是否沿用 R6-G 训练数据生成规则，或另建独立种子场景集。
- 学生通过架构筛选后，教师实验所需的样本量与知识形式。

这些项目应在正式 protocol 中结合 R6-G 结果一次性确定；在冻结前不得运行正式筛选或据此宣称模型优劣。
