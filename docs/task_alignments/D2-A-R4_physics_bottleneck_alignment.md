# D2-A-R4 与研究总纲对齐

**研究总纲版本：** docs/RESEARCH_CHARTER.md v1.2（提交 289b812e8bc93fbdabca0cfb3722ad24f045351b）
**当前协议：** D2-A-R4 教师—学生物理信息瓶颈诊断；总纲正文不改。

## 总纲关系

R4 服务于“物理模型与知识蒸馏驱动的三通道 GMTI 动目标检测及参数估计”核心目标，当前只验证已有仿真条件下传统教师的信息损失、冻结学生的物理一致性，以及最小相位增强是否值得继续。它对应 Q1（复数观测中的相干物理量学习）、Q2（教师知识是否含可迁移信息）、Q3（物理仿真真值与传统教师的边界）和 Q4（三通道回波的检测与参数估计）；不宣称实时性，也不将其包装为独立 CFAR 项目。

## 可检查证据与任务必要性

- D2-A-E002 A/B/C 在开发样本上通过基础任务学习门，但分层 H0 虚警、公共相位一致性和频移等变性存在失败。
- D2-A-T001 ACE×AMF 的 G1/G2 失败，G3 未评价，S2 未运行；原 protocol 的 1e-6 门槛及 STOP 结论冻结。
- R4 将定位实验瓶颈拆为计算精度、教师分数信息损失和学生映射/标签诊断，避免把教师失败误当成学生学习失败。

## 替代方案与停止条件

更简单的替代是直接结束当前传统教师开发并只复核学生真值监督；但它无法区分 T001 的数值构造误差、教师统计量的信息损失与学生输入映射问题。R4 有界复核这些差异，不重新训练旧网络或搜索第二种复杂教师。若可靠证据显示教师信息本身不含定位能力，或冻结学生的误差无法由受控相位变化解释，则停止相应 pilot；不得用增加蒸馏复杂度掩盖失败。

R4 的新诊断结果只影响后续独立协议建议，不回写 D0/D1/D2-A-E001/R3/E002/T001 历史结论。任何新训练均标为 exploratory，且只限预注册的一种公共相位增强和 E1 真值监督。
