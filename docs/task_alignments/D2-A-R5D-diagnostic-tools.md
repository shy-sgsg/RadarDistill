## 本次补充：目标 Doppler 频移响应统计

- **证据与缺口：** 原有 `summarize_prediction_intervention` 对基线和干预预测使用同一个 Doppler 真值，无法正确评价目标频率受控平移 `fd → fd + Δf` 后的预测响应，也会把 H0 不存在的参数值错误要求为有限数。
- **实现范围：** 增加可选 `expected_doppler_shift_hz` 路径，按 PRF 周期映射干预后的 H1 真值，报告估计频移相对预期频移的回绕残差及 base-scene cluster-bootstrap 区间；H0 只评价检测变化，参数预测/真值可为 NaN。
- **场景区间：** 通用相位、幅度或通道干预在提供 `scene_ids` 时也报告检测、H0虚警、H1 Pd、参数定位、联合成功及参数绝对误差变化的配对簇bootstrap区间。区间针对场景抽样，不代表跨训练种子方差。
- **决策影响：** 后续 R5-D 可以对单个预注册频移量分别评价学生的频率响应，不再复用固定真值误差冒充等变残差。此工具不定义频移幅度、样本量、学生或前置门，不运行物理干预，也不形成任何模型能力结论。
- **停止条件：** 仍须先取得 R5-C 独立方向审查，并完成获准的匹配教学 pilot；之后如未冻结具体频移协议，不运行正式 R5-D 比较。

## 本次补充：固定实现的目标/杂波强度输入干预

- **证据与缺口：** `D2APairedBatch` 已分别保存同一 base scene 的 `target_signal_iq`、`clutter_iq` 与 `noise_iq`，满足组件级受控干预所需的信息；此前缺少独立工具来缩放组件并重建一致的 H0/H1 IQ。
- **实现范围：** 新增 `evaluation/d2a_physical_interventions.py` 的 `scale_d2a_paired_components`。输入为目标/杂波功率变化 dB，按 `10 ** (delta_db / 20)` 缩放相应复数分量，噪声固定；目标干预只改变 H1 并同步目标幅度真值，杂波干预在 H0/H1 同时改变共同背景，保持 `H0=C+N`、`H1=C+N+S`。输出记录 component power、SNR/CNR/SCNR 与原 base-scene ID。
- **解释与决定边界：** 这是复用单次随机实现的组件级反事实输入，不重新抽取场景、不替换仿真器、不代表实测幅度/AGC变化；未运行模型、传统检测器或统计比较。它只使未来有界干预能隔离目标与杂波分量的作用。
- **决策影响：** 后续可在同一背景上分别测量目标强度响应、杂波响应和总功率捷径；仍须联合报告 H0虚警、H1检测、range/Doppler与joint结果。干预幅度、样本分组、估计阈值和验收门全部留给 R5-C 审查和匹配教学 pilot 后的独立预注册协议。
- **成功/失败含义：** 成功表示受控输入保持配对关系、分量恒等式、真值映射和功率账目；失败只表示输入构造工具不正确，不改变现有模型、教师或科学假设结论。
- **验证：** 新增的物理干预定向测试 7 项通过；AISAR 环境整仓测试 414 项通过。测试覆盖零移位、目标/杂波单独缩放、H0/H1组成关系、功率/真值更新和非法输入。
- **停止条件：** 不运行物理干预实验或学生比较，不选幅度网格；R5-C 独立审查及匹配 T0–T3 pilot 前门未通过时，只保留该准备工具。

## 决策影响与替代方案

- **优先理由：** 任务要求将教师错误、学生纠错、负迁移与检测/参数错误分开；现有物理诊断工具没有对应的教师—学生配对错误矩阵。把统计逻辑放进已有评价模块，比在未来每个runner中各写一份更可复核。
- **成功含义：** 输入场景已配对时，工具能给出可复现、按H0/H1和条件分层的计数与scene-cluster区间，并明确教师错误后学生纠错、教师正确时学生退化的比例。
- **失败含义：** 只表示诊断实现或输入合同不正确，不改变R5-C教师质量、学生性能或任何历史阶段门。
- **解释边界：** 错误表及物理一致性相关性本身不能证明因果知识迁移。只有R5-C审查通过、匹配pilot产生同场景教师/学生输出后，才可在冻结的独立数据上使用；机制结论还需预注册物理干预。
- **停止条件：** 不新增训练或教师候选；若外部审查不支持pilot，不进行R5-D学生侧机制比较，只保留此通用评估工具，不把已有不同scene ID结果强行配对。
