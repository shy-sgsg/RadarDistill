## 本次补充：目标 Doppler 频移响应统计

- **证据与缺口：** 原有 `summarize_prediction_intervention` 对基线和干预预测使用同一个 Doppler 真值，无法正确评价目标频率受控平移 `fd → fd + Δf` 后的预测响应，也会把 H0 不存在的参数值错误要求为有限数。
- **实现范围：** 增加可选 `expected_doppler_shift_hz` 路径，按 PRF 周期映射干预后的 H1 真值，报告估计频移相对预期频移的回绕残差及 base-scene cluster-bootstrap 区间；H0 只评价检测变化，参数预测/真值可为 NaN。
- **决策影响：** 后续 R5-D 可以对单个预注册频移量分别评价学生的频率响应，不再复用固定真值误差冒充等变残差。此工具不定义频移幅度、样本量、学生或前置门，不运行物理干预，也不形成任何模型能力结论。
- **停止条件：** 仍须先取得 R5-C 独立方向审查，并完成获准的匹配教学 pilot；之后如未冻结具体频移协议，不运行正式 R5-D 比较。

## 决策影响与替代方案

- **优先理由：** 任务要求将教师错误、学生纠错、负迁移与检测/参数错误分开；现有物理诊断工具没有对应的教师—学生配对错误矩阵。把统计逻辑放进已有评价模块，比在未来每个runner中各写一份更可复核。
- **成功含义：** 输入场景已配对时，工具能给出可复现、按H0/H1和条件分层的计数与scene-cluster区间，并明确教师错误后学生纠错、教师正确时学生退化的比例。
- **失败含义：** 只表示诊断实现或输入合同不正确，不改变R5-C教师质量、学生性能或任何历史阶段门。
- **解释边界：** 错误表及物理一致性相关性本身不能证明因果知识迁移。只有R5-C审查通过、匹配pilot产生同场景教师/学生输出后，才可在冻结的独立数据上使用；机制结论还需预注册物理干预。
- **停止条件：** 不新增训练或教师候选；若外部审查不支持pilot，不进行R5-D学生侧机制比较，只保留此通用评估工具，不把已有不同scene ID结果强行配对。
