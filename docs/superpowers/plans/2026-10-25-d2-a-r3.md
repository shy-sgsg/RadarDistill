**Goal:** Explain the D2-A fixed-threshold Pfa migration anomaly, test bounded scale-normalized B3 statistics against frozen B0–B3, and run one truth-only student pilot only if the preregistered front gate passes.

**Spec:** `experiments/D2-A-R3/protocol.md`

## Global Constraints

- Keep PRF `1300 Hz`, `N=130`, 3 channels, 32 range cells, stationary clutter, and existing geometry/waveform assumptions.
- Do not change or overwrite D2-A-E001 protocols, code paths, results, thresholds, or historical conclusions.
- Generate all R3 scenes from the new seed ranges in the frozen configuration; do not create a final blind set.
- Run the raw H0 B0–B3 phase before any candidate-score analysis; do not use H1 truth, latent amplitude, or component powers as detector inputs.
- T1/T2 formulas, windows, comparison rule, sample sizes, gates, and E1 authorization condition are frozen in the protocol before data collection.
- If E1 is authorized, use exactly one seed, E1 truth-only, frozen R2 model/training budget, visible RTX 3050 CUDA, and no E2/E3.
- Commit and push each completed deliverable to the currently authorized `main`; stage exact paths only.

## Review Focus

- H0 noise/clutter scaling is tied to the latent target reference amplitude by the existing SNR convention; tests must expose its effect without feeding the latent value to detectors.
- Fixed thresholds use the existing `higher` empirical quantile and inclusive `>=` decision; report strict `>` and tie counts separately.
- Calibration and validation groups must remain distinct and be analyzed at their experiment-group level.
- T1/T2 background references must exclude or guard the target peak; paired H0/H1 diagnostics must quantify remaining contamination.
- The exact-overlap D scene is an identifiability limit; do not use it as a unique-source recovery gate.
