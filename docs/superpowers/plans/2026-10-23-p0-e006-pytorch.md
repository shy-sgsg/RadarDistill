# P0-E006 PyTorch architecture comparison plan

## Objective

Complete the requested R0 audit and one bounded P0-E006 study in AISAR. Compare the frozen P0-E005 CNN with two signal-informed PyTorch students, then make an evidence-based P0 decision. If the decision permits it, run the minimum P1-A three-channel relative-phase simulation. Training must use the RTX 3050 GPU; the launcher will refuse to train on CPU.

## Frozen P0-E006 design

- Signal: PRF 1300 Hz, N=130, continuous frequency on `[-PRF/2, PRF/2)`, random phase/amplitude, circular complex AWGN; no clutter, channel errors, or multiple targets.
- Training: 6000 samples for each of three training seeds 1101/1202/1303; 1200 validation samples per seed from independent seeds 3303/3404/3505; SNR levels -15, -5, 0, 10, 20 dB.
- Development: old E001–E005 test data at seed 7070. It is explicitly not a final test set.
- Final blind evaluation: new seed 909090, 1024 samples at each of -15, -10, -5, 0, 5, 10, 15, 20 dB. The final set is generated/evaluated only after models and selection rules are fixed.
- Optimization: PyTorch Adam, learning rate 1e-3, batch size 128, maximum 160 epochs, patience 40; seeds are fixed in the protocol. Report each seed and do not select by final-test results.
- S0: frozen P0-E005 phase-increment CNN checkpoints, no tuning.
- S1: MLP over normalized complex autocorrelations at lags 1, 2, 4, 8; include a multi-lag phase-coherence estimator using the same features.
- S2: MLP over normalized 4N zero-padded FFT log-power response; identify as a physics-guided hybrid and compare to FFT peak/interpolation and profile ML.
- E1/E2/E3: truth supervision; teacher-only; truth plus teacher. E2-A uses teacher-only validation, E2-B preserves truth validation as an explicitly labeled comparison. Compare teacher hard point, existing circular soft target, and a 65-point local profile-likelihood response on the primary correlation student; do not cross every teacher variant with every architecture.
- Primary gate: E1 must beat the N-point FFT peak at two adjacent SNR points among 0, 5, 10, 15, 20 dB, with each paired 95% bootstrap interval for `student RMSE - FFT RMSE` wholly below zero. Report G1, G2, and G3 independently; this legacy performance gate does not itself decide whether a minimum P1-A feasibility study is scientifically permitted.
