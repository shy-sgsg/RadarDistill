- Calibration, background fitting, model selection, H0 verification, and H1 evaluation remain independent.
- DPCA shift, phase convention, channel geometry, finite CPI, normalization, and reported CCR must match the declared model.
- Report detection and parameter estimation separately, with candidate-selection failure separated from conditional refinement error where the evidence supports it.
- The unified table must retain dataset/split, SNR definition, sample counts, model/checkpoint version, parameter count, training exposure, Pfa unit, Pd, parameter RMSE, joint metric, uncertainty, teacher role, evidence links, and validation status.
- A missing checkpoint is not retrained and called historical. Cross-stage rows are not ranked unless evaluation data and operating rules are matched.
