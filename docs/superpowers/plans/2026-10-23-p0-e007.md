# P0-E007 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Implement and evaluate three bounded PyTorch frequency-estimation paradigms in E007, using staged CUDA screening, formal multi-seed training, distillation and an independent final test.

**Architecture:** Keep the existing E006 runner and artifacts untouched. Add E007-specific features, models and runner; fixed FFT physical front ends remain distinguishable from learned network contributions. Screen all candidates before training only selected candidates formally.

**Tech Stack:** Python 3.13, PyTorch 2.8.0+cu128, NumPy, PyYAML, Matplotlib, pytest; existing AISAR Conda environment and RTX 3050 Laptop GPU.

**Spec:** docs/superpowers/specs/2026-10-23-p0-e007-design.md and experiments/P0-E007/protocol.md

## Global Constraints

- PRF=1300 Hz, N=130, single complex tone plus circular complex AWGN; no clutter or multi-target data.
- CUDA is mandatory for model training; no CPU fallback.
- Train sequentially in FP32 with batch 64, Adam 0.001, up to 160 epochs and patience 40; all candidate models share this budget.
- Screen on data seed 17117 / validation seed 27117 and development seed 7070; final blind seed 999983 is unused until model selection is frozen.
- E1 uses truth, E2-H uses the local profile-ML point, E2-S uses the soft profile response, and E3-S uses truth plus fixed weight 0.5 on the soft response.
- Preserve existing uncommitted work and all E001–E006 artifacts; do not commit or push.
- Do not start P1-A unless the E007 G1 gate and existing project stage rules allow it.

## Review Focus

1. Frequencies just below/above ±PRF/2 must use circular errors and wrap correctly.
2. Near-zero spectral bins must not create NaN/Inf when normalized complex coherence is computed.
3. Positive modulation by one FFT grid step must roll the M1 spectrum and logits in the correct direction.
4. M2 coarse-peak mistakes must be counted and not hidden by the bounded ±0.5-bin residual target.
5. E2-only checkpoint selection must not use truth validation targets; E1/E3 selection must follow the preregistered truth objective.
