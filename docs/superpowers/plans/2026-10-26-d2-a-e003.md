# D2-A-E003 implementation plan

## Goal

Run the user-authorized, staged E003 experiment without editing the research charter or changing historical frozen results. The main comparison is a fresh, matched E1 truth-only S0/S2 pilot, conditional on correctness and information-preservation gates.

## Sequence

1. Freeze task alignment, mathematical design, protocol, config, seed blocks, and stage gates. Commit and push this preregistration before generating experiment data.
2. Add a stable scene-ID stratified sampler and tests proving selected IDs are invariant to row permutation; record selected IDs in diagnostics.
3. Add the fixed 28-channel coherence front end and S2 wrapper. Write tests first for feature shape, public-phase invariance, lag-frequency mapping/aliasing, cross-channel relative phase, range locality, finite precision, and parameter-count bounds.
4. Add bounded R2 controlled-factor diagnostics and stable physical-consistency summaries. Run R0/R1/R2; stop if any frozen prerequisite gate fails.
5. Add the E003-only data/training/evaluation runner, reusing the E002 truth loss and optimizer schedule without editing E002. Run CUDA preflight, materialize new split caches, then train S0 followed by S2 on `cuda:0`; use seed 101, 1,600 updates and effective batch 64.
6. Evaluate independent H0 calibration/verification, C3 verification, H1 development, traditional descriptive references, public phase, three distinct frequency interventions, and compute cost. Do not make or call any split a final blind set.
7. Write results, uncertainty, failed gates, stage review, ChatGPT review request and dynamic status updates. Remove only this run's manifest-listed reconstructible cache; retain checkpoints, metrics, figures, logs and audits.
8. Run the requested tests and consistency checks, review the exact staged diff, commit each completed work package to `main`, and push each commit to `origin/main`.

## Verification

Tests must first fail for the new behaviors, then pass after the implementation. Verify feature math against a complex128 reference, stable sample selection under a row permutation, disjoint scene IDs, S0/S2 shared initialization and paired train plan, CUDA-only execution, output decoding and the frozen statistical gates. Final reporting must distinguish scene-bootstrap uncertainty from the single training seed.
