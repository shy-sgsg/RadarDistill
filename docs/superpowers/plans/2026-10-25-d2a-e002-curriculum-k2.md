# D2-A-E002 课程学习与 K2 教师辅助 Pilot 执行计划

**Plan spec:** `experiments/D2-A-E002/protocol.md` v2.0 及 `config.yaml`
**Baseline:** `1e4300c9b81dbc500216d1b355bbcb618d35f253` (`main`, 与 `origin/main` 一致)
**Research charter:** `docs/RESEARCH_CHARTER.md` v1.1；本计划禁止修改总纲。

## 目标

在 D2-A 的三通道静止杂波仿真中，以同一 `TaskStudent`、初始化、数据样本集合和 1,600 次更新，对比 A 直接真值任务训练、B 课程真值训练、C 同课程加 K2 DPCA 软响应。先冻结协议，再做代码/数据/CUDA 正确性审查、K2 教师质量门和微型过拟合；通过后顺序运行三组 RTX 3050 CUDA pilot，评价检测、距离、周期 Doppler、联合任务、收敛与资源，并给出阶段判断。

## 执行步骤

1. 完成研究总纲映射、旧结果/假设保护和 TaskStudent/损失/训练—推理路径诊断；写入 E002 任务对齐和模型诊断报告。
2. 冻结 v2.0 实验协议与配置，更新动态路线、状态、假设登记、决策与 README；保留 R3、D1 及旧 E002 v1 记录。只提交明确路径并推送此协议冻结包。
3. 先添加测试并确认失败，再实现 D2-A-E002 可复现种子/数据缓存、K2 生成与质量审查、A/B/C 匹配课程批次、CUDA 训练、评估及报告入口。
4. 运行代码测试、D2-A 物理/基线回归、seed/split/标签/配对检查、极小 H0/H1 过拟合和梯度检查；实测 K2 数值、尺度不变和目标邻域响应。若严重误导，只停止 C 并保留 A/B 证据。
5. 训练前复核可用磁盘和 `cuda:0` 设备名；禁止 CPU 回退；按 16→8→4 microbatch 顺序处理 OOM 并维持有效 batch 64、总更新数及顺序。
6. 按 A、B、C 顺序各完成一个 seed、1,600 更新；保存初始/最佳/最终模型、每步日志、验证曲线、实际 CUDA/显存/时间。任何未完成臂明确记录，不写成完成结果。
7. 使用独立校准/验证和开发 split 评价冻结的 E0、B0–B3、T1 及 A/B/C 学生；分析教师对齐、训练—推理距离索引误差、物理一致性、分层结果与种子限制；不生成 final blind。
8. 更新指标、分析、阶段审查、progress、status、roadmap、假设和决策；审查 diff/文件大小，建立小提交并推送 `main`；最后给出 CONTINUE / REFINE / REDIRECT / STOP 和唯一下一项优先任务。

## 验证要求

- 实验协议/配置一致性与随机种子不重叠测试。
- K2 仅由 IQ 生成、有限/非负/归一化、复幅度缩放不变、H0/H1 对应性和 student-loss 梯度测试。
- 数据 H0/H1 共用背景与噪声、split 隔离、训练批次同 cohort/配对/预算测试。
- 小数据集真值监督过拟合与 A/B/C 公共初始化、B/C 课程顺序一致测试。
- 相关 D2-A 物理仿真、基线、评估和报告测试。
- 实际 CUDA 设备与显存记录；训练结果状态、checkpoint、CSV/JSON 和最终审查材料互相核对。

## 停止条件

- CUDA 不可用、真实设备名称不符、split/配对/标签检查失败、微型数据不能学习或梯度异常：先修复工程问题，不开始正式 pilot。
- K2 非有限、非归一化、违反整体尺度不变、读取 truth/metadata，或预注册严重误导规则触发：不训练 C；保留并分析 A/B。
- 所有学生臂在正确实现和完整预算下都没有任务学习证据：停止扩展蒸馏和盲测，先做有界表示/优化诊断。
- 单 seed pilot 只筛选后续问题，不声称跨种子效果或论文级收益；正式三 seed / blind 另行预注册。
