# D0/D1 任务级教师引导蒸馏设计

**日期：** 2026-10-24  
**状态：** 已获用户总体路线批准；实验数值门槛在 D0/D1 协议中冻结后执行。  
**范围：** 新建 D0 仿真/传统教师体系和 D1-E001 单目标任务级学生；保留 P0/P1 历史档案，不改写旧阶段结论。

## 1. 研究问题与阶段关系

新主线研究三通道距离压缩复数慢时间输入能否直接支持 H0/H1 检测、距离单元和连续 Doppler 估计；完整或部分传统处理链产生的知识是否能改善学生收敛、数据效率或最终任务指标。传统教师结果、仿真真值和学生输出分开保存。

P0-E007 的 GO、P1-A-E001 的 STOP/REDIRECT 均继续作为原阶段的真实历史记录。新路线 D0→D1 从任务级可行性开始，不要求先通过 P1-A 相位回归，也不把旧 P1-A 结果改写为成功。

## 2. D0 数据与物理假设

- 输入为距离压缩后的三通道复数数据 `X ∈ C[B, 3, 130, 32]`，轴顺序为样本、通道、慢时间脉冲、固定距离单元；网络使用 `[B, 6, 130, 32]` 的实/虚表示。
- `PRF=1300 Hz`、`N=130` 沿用 P0；频率定义为 `[-PRF/2, PRF/2)` 上连续 Doppler。
- H0 和 H1 均含复高斯背景噪声，并使用相同采样、幅度/噪声先验及固定归一化约定。训练 H0/H1 近似均衡。样本不按真值距离裁剪。
- H1 是单个点目标：目标距离为监视窗内部连续距离单元，Doppler 相位逐脉冲演化，初相随机，三通道复响应使用 APX15 四接收通道仿真场景前三个相位中心的远场导向相位。初期不加入杂波、多目标、通道失配或角度回归；方向参数仅为随机 nuisance 参数，这一子集不代表已经核实的实机阵列标定。
- 距离向目标响应使用明确的理想有限带宽匹配滤波点扩散模型；简化模型必须与小规模离散 LFM 波形匹配滤波器输出对照。对照只验证所声明的简化模型，不声称覆盖生产机载波形全部效应。
- 仿真真值包括 presence、连续 range cell、连续 Doppler、随机初相、目标幅度、噪声功率/SNR 和三通道导向参数。H0 的参数回归标签无效，但对应教师输出仍保留以分析教师虚警。

## 3. APX15 传统教师适配

本机 `GMTI_APX15_CoreX_Int16_20261014` 是用户提供的算法/仿真/评价来源，整体约 4.3 GiB，包含六份约 753 MB 的原始正式 BIN。其包级 CMake 明确面向 CoreX；本机没有 CoreX SDK。因此 D0 不运行整条 CoreX 正式回放，也不修改生产检测链。

D0 适配 APX15 中实际使用的慢时间 FFT 数据布局/居中约定（`include/transposeFFT.hpp` 的 `ColFFTTranspose`），建立一个独立可调用的传统频谱教师：对三通道分别做慢时间 Doppler FFT，以非相干功率和形成固定 130×32 原生距离—频率软响应；连续 Doppler 硬估计另使用 4 倍零填充及局部连续插值。该教师只复用 APX15 的慢时间频谱子链，不称为完整 APX15 GMTI 处理链。

教师输出字段固定为 `teacher_response`、`teacher_detection_score`、`teacher_range_cell`、`teacher_doppler_hz` 和 `teacher_confidence`。教师仅接收 IQ，不读取 presence/range/Doppler 真值或仿真噪声功率，不按真值裁剪响应图；H0 上的假警和 H1 上的错误估计照常保留。教师响应使用固定全图单位和归一化方式生成软目标；教师硬估计与软响应均不覆盖物理真值。

## 4. D1 学生结构

使用轻量二维深度可分离 TCN：输入为 6 个实数 IQ 平面；时间卷积 dilation 为 `[1, 2, 4, 8, 16, 32, 64]`，每层时间核宽 3，因此理论慢时间感受野 255，覆盖全部 130 脉冲。保留距离轴特征，不使用 Doppler FFT、CFAR 或参数搜索作为学生前向算子。

最终任务输出为目标存在 logit、32 个 range-cell logits、逐 range 的亚栅格偏移，以及逐 range 的 Doppler `cos/sin`。训练时 H1 的 range/Doppler 真值损失只作用于目标所在的真值邻近单元；H0 不计算参数回归损失。推理时 range 由预测 range logits 解码，Doppler 由相应 `cos/sin` 周期编码解码。训练期频谱辅助头可输出同一固定 RD 网格；导出的最终模型删除该头。

## 5. 训练组与公平预算

四组使用相同编码器/任务头、训练样本、验证样本、优化器和总更新步数：

| 组别 | 训练路径 |
|---|---|
| A | 全预算真值监督 |
| B | 预算的 1/4 教师全图响应预训练，3/4 真值任务微调 |
| C | 全预算从随机初始化开始的真值任务+教师响应联合监督 |
| D | 1/5 教师预训练、3/10 联合监督、3/10 线性退火教师权重、1/5 真值任务微调 |

辅助谱损失对 H0/H1 均使用完整教师输出；presence 和参数任务监督始终使用仿真真值。D 的教师权重按固定线性计划衰减至零。各组都以真值验证集选取任务最佳检查点。正式测试只在所有模型与校准阈值冻结后运行一次。

## 6. 数据划分、基线与阶段门

- 三个训练随机种子相互独立，训练集、验证集、教师阈值校准集及最终盲测集使用不重合的种子。
- 主比较包含 APX15 适配教师、N 点/过采样 FFT 峰值及插值、已知单目标模型下的连续 profile-ML（仅作为强性能参考），以及 A/B/C/D 学生。
- 检测报告 ROC/AUC、Pd、校准后的 `Pfa=1e-2` 和 `1e-3`；同时报告 H0 校准/盲测机会数与二项置信区间。有限样本不宣称达到 `Pfa=1e-6`。
- 参数报告 range-cell 和 Doppler 的 MAE/RMSE、边界分组、SNR 分组、连续 Doppler/初相/幅度分组；分别报告全部 H1 的无条件估计误差、正确检测后的条件误差及漏检/误检，不混为单一指标。
- G1：D0 物理/教师核对通过；盲测高 SNR 下学生显著优于无信息/常数输出，在随机 range、连续 Doppler 和相位边界上稳定；检测和参数同时优于相应无信息基线。
- G2：在总更新步数匹配下，B/C/D 只有在独立盲测、配对不确定性和三种子方向均符合预注册协议时，才可称存在蒸馏收益；收敛较快单独报告。
- G3：相对传统教师、FFT 插值和 profile-ML 的检测/参数差距按任务条件报告，不要求首轮全面超过教师或 ML；没有精度或速度优势时不推进更复杂场景。

具体训练样本数、校准/盲测数量、损失权重、置信区间算法和数值门槛写入 `experiments/D0-E001/`、`experiments/D1-E001/` 的冻结协议，先于正式盲测生成。一次性 pilot 只检查实现/训练可行性，使用独立开发 seed，不用于正式种子或盲测选择。

## 7. CUDA、产物与范围

PyTorch 训练必须显式要求 CUDA，不允许 CPU 回退。模型/批次顺序训练；默认 FP32、合理 batch size、CPU 数据分批搬运，不把完整训练集复制到 GPU。记录 GPU、驱动、CUDA、PyTorch、峰值显存、训练时间、随机种子和实际配置。OOM 时先减 batch size。

可由配置和种子重建的数据留在本机实验目录，代码、配置、教师/模型接口、汇总指标、预测、曲线和报告进入 Git。不要把 APX15 正式 BIN 或可再生训练数据加入提交。

本设计不包含 D2 杂波/多目标、D3 原始未压缩回波、D4 模型加速优化或 D5 系统级时延验收。
