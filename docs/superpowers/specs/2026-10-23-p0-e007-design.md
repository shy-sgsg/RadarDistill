# P0-E007 架构比较设计

**状态：** 用户于 2026-10-23 明确批准三范式比较，并授权设计后直接实现和运行。

## 目的

E007 在保留 E001–E006 结论的前提下，比较三种适用于单目标复数慢时间频率估计的学习路线：显式相干、循环等变频谱网络；FFT 粗估计后的神经子栅格修正；直接处理复数 IQ 的小型 Transformer。重点是估计精度、泛化、物理一致性和蒸馏可行性，不研究实时性。

E006 的 S1 相关 MLP 在 20 dB RMSE 为 2.947 Hz，略高于 N 点 FFT 峰值的 2.884 Hz；其频率平移诊断 RMSE 偏差为 51.66 Hz。S2 对数功率频谱 MLP 为 27.238 Hz，频移 RMSE 偏差为 207.394 Hz（seed 1101；三个种子的 RMSE 偏差为 180.502–213.641 Hz）。4N FFT 峰值为 0.733 Hz，连续 profile-ML 约 0.0327 Hz。E006 的 G1、G2、G3 均未通过。因此 E007 是有界的新 P0 诊断，不改写 E006 的 STOP/REDIRECT 历史判定，也不预设网络优于传统方法。

## 研究问题与假设

- H1：固定复频谱变换、相对谱相位特征和循环卷积能否修复普通频谱 MLP 的频移泛化问题？
- H2：相干谱特征是否优于相同网络仅使用谱功率？
- H3：学习局部 FFT 子栅格修正能否优于同一频谱局部窗口上的经典插值？
- H4：小型 Transformer 能否仅从复数慢时间序列学习达到 FFT 峰值附近的频率精度？
- H5：在 E1 已证明基本学习后，教师点目标、教师软频率响应及真值联合训练是否产生可复现收益？

## 方案比较

1. **三范式比较（采用）：** 在同一 P0 信号模型、训练预算和开发评估集上，依次筛选 M1、M2、M3；仅对满足预设筛选标准的路线做三种子正式比较。它同时检验物理等变性、传统前端加学习修正以及直接序列学习，工作量受阶段筛选控制。
2. **仅训练 Transformer：** 能回答非 CNN 序列模型是否可行，但不能区分频谱物理归纳偏置与 FFT 辅助学习的作用。
3. **结束 P0 学习实验：** 与 E006 STOP/REDIRECT 一致，但不能回答用户新批准的三范式架构问题。

## 模型设计

### M1：循环等变相干频谱网络（最高优先级）

- 固定、不可学习的 16N 点零填充复 FFT，L=2080；此处物理前端负责将频率调制表示为频谱循环平移。
- 三个输入通道：峰值归一化对数功率，以及相邻频点复互谱的归一化实部和虚部。复互谱消除公共初相，同时保留相邻频点间的相干相位；整体复幅度缩放不改变特征。
- 三层小型一维卷积和逐点输出，所有卷积使用 circular padding，不做位置展平或池化。输出 2080 点循环频率分布，使用圆周高斯标签和圆周均值解码。
- 这是一种“固定物理 FFT + 可学习循环等变读出”的混合模型，不是学习式 FFT，也不是纯端到端 IQ 模型。以 16N FFT 峰值作前端对照，并用同容量、仅谱功率输入的消融量化相干通道的作用。

### M2：FFT 子栅格修正网络

- 固定 4N 点 FFT 找粗峰，提取峰值周围 9 个循环频谱点的对数功率和相对中心频点的复相干量。
- 小型 MLP 输出限制在 ±0.5 个 4N 频率栅格内的连续修正量；不能修复选错粗峰的样本，故记录粗峰错选率和输出饱和率。
- 这是物理前端加学习修正的混合方法。与 N 点 FFT 峰、N 点 FFT 插值、4N FFT 峰、同一局部谱窗口上的 3 点对数抛物线插值及连续 profile-ML 比较；不作为纯端到端成功证据。

### M3：小型复数 IQ Transformer

- 输入为 130 个 I/Q token，固定正弦位置编码，2 层、宽度 32、4 头、前馈宽度 64 的 Transformer encoder，单个汇聚 token，输出 2080 点循环频率分布。
- 每脉冲按 RMS 归一化以消除幅度尺度，不消除公共初相；随机相位训练并测量相位旋转敏感性。
- 参数量保持在 RTX 3050 Laptop GPU 4 GiB 显存可承受范围；不使用预训练权重、FFT 输入特征或大型模型。

## 训练、筛选与蒸馏

- 三种模型先用相同 6000 个训练样本、1200 个验证样本、一个训练种子、FP32、batch 64、Adam 1e-3、最多 160 轮、patience 40 做 E1 真值监督筛选。M1 同时筛选仅功率输入消融。
- 开发选择只使用既有 E001–E005 development benchmark（数据种子 7070）和各自验证集；这些数据不作为 E007 最终盲测。
- 进入正式阶段的门槛：训练和验证数值有限且验证目标较首轮至少下降 20%；20 dB development RMSE ≤5 Hz，或 E1 在 0–20 dB 主 SNR 中至少两个相邻点优于 N 点 FFT 峰值。若均未满足，不机械扩展该模型的三种子训练。
- 正式阶段对入选路线使用相同三个新训练数据种子和对应独立验证种子；先完成全部入选模型的 E1，再做 E2/E3。仅筛选 E1 达到门槛的模型进入蒸馏。
- T1 硬教师标签是 FFT 初始化局部 profile-ML 的连续点估计；T2 软教师响应是归一化 profile likelihood。E1 只用物理真值；E2-H、E2-S 分别只用教师硬点和教师软响应；E3 用真值损失加权重固定为 0.5 的软响应损失。每一种标签单独保存，教师输出不覆盖物理真值。
- M1/M3 的 T2 使用 16N 频率网格上的 profile response；M2 的 T2 使用其 ±0.5 个 4N 栅格局部修正范围内的 65 点 profile response，输出其期望修正量。所有模型选择规则固定后，才训练并生成最终盲测结果。

## 评价与阶段决策

报告 8 个 SNR 下的圆周 RMSE、MAE、偏差、异常率、各训练种子结果、CRLB 比值、频率分段、Nyquist 边界、初相与幅度分组、相位旋转不变性、频移等变性、粗峰错误率和训练稳定性。主要传统基线为 N 点 FFT 峰/插值、相位差、局部/全局 profile-ML、4N FFT 峰、16N FFT 峰和 4N 局部插值。

正式 blind test 使用新种子 999983，每个 SNR 1024 例，只生成一次。主要 FFT 门要求 E1 相对 N 点 FFT 峰值在至少两个相邻的 0、5、10、15、20 dB 点获得配对 95% bootstrap 区间完全低于零。M1 另与 16N FFT 峰值比较，M2 另与相同 4N 局部输入的抛物线插值比较。E006 的 G1、G2、G3 定量门槛保持不变；G3 以 E3-soft 对 E1 进行检验。ML 的差距如实报告，不要求网络超过正确 AWGN 模型下的 ML。

若所有模型都未达到筛选标准，保留筛选负结果并停止后续训练，不生成 E007 最终盲测。阶段结论按现行 AGENTS.md 分别评估 G1/G2/G3；只有纯相干学习路线证明可靠学习后，才讨论 P1-A。

## 资源与实现边界

- 所有训练严格使用 CUDA；模型按种子和策略顺序训练，训练 batch 从主机内存传输，不把完整数据集常驻显存。
- 全部使用 FP32，避免小模型的混合精度误差；起始 batch 为 64。若 OOM，按协议将整个对应比较阶段的 batch 统一降至 32 后重跑，保持模型、样本数、轮数和评价条件不变。
- 保存数据、配置、训练历史、checkpoint、预测、指标和环境/显存记录。无新增依赖，不做实时性测试，不改变 P0 信号模型，不启动杂波、多目标或三通道实验。
