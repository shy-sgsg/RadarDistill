# D2-A-R5-C 教师知识质量审计设计

## 意图

R5-B 的 TFAS 未通过困难场景 G3，但这不回答现有 IQ-only 教师响应是否含有学生可用的频率知识。R5-C 先独立审计教师输出的任务相关信息与错误区域；本轮不训练学生、不运行蒸馏、不生成 blind。审计结果用于决定是否值得另立匹配学生教学实验。

## 目标与边界

- 保持 D2-A-E001 的三通道、PRF 1300 Hz、N=130、32 距离单元、静止杂波、配对 H0/H1 和既有可辨识物理假设。
- 比较同一冻结 B3 DPCA 前端产生的两种知识表达：原生 130×32 全 RD 归一化功率响应，以及固定 4 倍零填充的 520×32 Doppler 支持响应；再从后者按教师自身峰值距离门提取 520 点局部频率响应。
- 仅用新 scene seeds 做教师质量审计；教师运行在已检查的 RTX 3050 Laptop `cuda:0`。仿真按小批在 CPU 生成，教师运算按 batch 搬到 GPU，不缓存完整 IQ。
- 评价目标邻域软响应质量、峰值检测/连续 Doppler 定位、H0 伪目标响应，以及一个固定可观测尖锐度指标能否区分正确与错误教师输出。
- 保留 K0 物理真值仅用于离线评价。教师 API 不接受真值、目标位置、SNR/CNR 或场景标签。
- 响应归一化只表示相对功率支持，不称为后验概率或已校准似然。B3/K2/T1/T001 的历史固定阈值资格与结果不变。

## 非目标

- 不为 R5-B 失败的 TFAS 续训或搜索新学生架构。
- 不将低 Pfa 或软响应质量等同于合格阈值检测器。
- 不训练可靠性 gate，不在本轮选择/优化置信阈值，不改变仿真器。
- 不进行学生 truth-only / KD 对照，不开展教学时机、学生吸收机制或 final blind。

## 考虑过的路径

1. **只复述既有 K2 审计。** 成本最低，但 E002 数据已经参与知识与学生选择；不能回答教师输出在新场景上的复核结果，也没有连续 Doppler 响应对照。
2. **新场景上做同一 B3 前端的有界知识表达比较（采用）。** 保持教师物理运算固定，仅改变频率网格/输出表达；在 CUDA 上流式处理新场景。它可区分“B3 是否有信息”与“更细 Doppler 响应是否增加任务相关支持”，范围、成本和结论边界清楚。
3. **实现新的 ACE/AMF 或联合教师并同时搜索知识与教师参数。** 会把教师算法改变和知识形式改变混在一轮中，并触碰 T001 既有失败范围，无法解释 R5-C 的第一因果问题，因此不纳入本轮。

## 审计设计

- 主条件 C3：`separated`、`near_clutter_edge`、`partial_overlap` × SNR `{0,10}` dB、CNR 20 dB，每格 512 个独立配对 base scenes。
- 次要条件 C2：三个 scenario × SNR 10 dB、CNR 10 dB，每格 256 个 scenes；C1 的两个 scenario × SNR 15 dB、CNR 0 dB，每格 128 个 scenes；C0 separated × SNR 20 dB、CNR −5 dB，256 个 scenes。总计 4,352 个独立配对 base scenes；每一场景同时生成共享背景与噪声的 H0/H1。
- 数据 seed base 从 726,000,000 起，按条件分配互不重叠的 100,000 seed 区块；批大小 16。此范围须在 preflight 中核对与仓库已有 manifests 不重叠。最终 blind 保留区不使用。
- B3/K2 知识 K1：DPCA 后 130 点 FFT，输出有限、非负、全图和为 1 的 130×32 支持图。
- 连续知识 K3：同一 DPCA 残差做固定 4×零填充 FFT，输出 520×32 支持图；教师自身全图最大值所对应 range cell 的 520 点归一化 Doppler 响应作为局部知识。网格间距 2.5 Hz。它是过采样功率支持，不是 profile-ML 的已校准后验。
- 主要指标：按配对 base scene 计算的真值窗口质量 lift（H1−H0；距离半径 1 cell、周期 Doppler 误差半径 20 Hz）、全图峰值定位率、range/Doppler 回绕 RMSE。K1 与 K3 使用同一物理窗口与配对 H0/H1；对连续/原生网格分别保留实际频率轴。
- 可靠性诊断：固定可观测分数为 K3 归一化全图在教师自身峰值周围 ±1 cell、±20 Hz 的质量；报告它与 H1 联合定位正确性的分层关系/AUC，仅作审计描述，不拟合门限或 gate。
- 置信区间按 base_scene_id 配对 cluster bootstrap，2,000 次；主 C3 汇总和各预注册条件单独报告，不能把跨条件 scenes 当同质重复。
- 数值与物理检查：CUDA/CPU K1 输出最大绝对差≤1e−6；固定正/复尺度 `{0.5,2.0,0.6+1.2j}` 下归一化图差≤1e−6；确定性、shape、有限/非负/和为 1；analytic tone 频率峰误差≤一个 2.5 Hz 网格间距；信息隔离由函数签名和配置审计确认。

## 阶段门和解释规则

- G0：当前已推送代码、协议与配置提交一致；新 seed IDs 不与已知训练/验证/校准/开发 manifests 重叠；真实 CUDA 可用且没有 CPU fallback；存储预测低于项目最终 20 GiB 限制。
- G4：每种知识表达分别判断。基础资格要求数值/输入隔离全部通过、可辨识 A/B/C 配对质量 lift 95% CI 下界大于 0，且 C3 各子组的错误/低信息响应已如实标注。若一个 C3 子组的 lift CI 上界≤0 且 top-cell 定位率≤0.05，则该知识不得作为无条件全域监督；只有固定可观测尖锐度确实区分错误的证据，才可提出后续独立 reliability-gated pilot。
- K3 相对 K1 的收益以同 scene 配对差和 95% CI 报告；若没有明确收益，保留更简单 K1，不扩展 oversampling、窗口或温度搜索。
- 本轮不授予固定阈值 detector/teacher 资格，不自动授权 Phase 5 蒸馏。任何正结果只是 R5-C teacher-quality 候选；student-side 教学收益须另按 matched truth-only / full response / local response / matched truth-window protocol 验证。
- 停止：CUDA 设备不可用、seed 分离失败、数值/parity/invariance 失败、教师输入泄漏，或新 K1/K3 在困难条件均无可检验目标信息。停止后保存负结果并提出是否终止教师知识支线的判断。

## 资源与产物

- 按 batch=16 顺序计算；教师前端只驻留一个 batch，不缓存全集；CUDA FP64/complex128 用于与冻结 NumPy 定义做数值一致性检查，若设备/显存不支持则实验停止，不静默改回 CPU 或降精度。
- 预计不保存原始 IQ；只保留协议/config、代码、环境/预检、teacher response 摘要、逐场景指标、图表、分析和阶段审查。训练模型为零。
- 目标文件：`experiments/D2-A-R5/R5-C/`，新增最小 CUDA teacher module、runner 和对应单元测试；动态状态/路线/假设/进展/决定仅在完成审计后依据证据更新。
