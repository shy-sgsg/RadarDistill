# D2-A-R6-J4：物理驱动联合检测与参数估计设计

**状态：** 后续候选设计；不是冻结协议，不代表已实现或已运行。
**总纲：** `docs/RESEARCH_CHARTER.md` v1.3。
**依赖：** R6-G 当前pilot完成后；如进入架构筛选，还须遵守R6-H与P7的场景隔离、资源和阶段门。

## 1. 目标与边界

设计一种将可验证的相干物理处理、软目标候选搜索和学习式检测/连续参数估计结合起来的模型，回答固定物理前端能否给任务学生带来额外收益。最终判断依据是同场景下的Pd、Pfa、距离与周期Doppler误差及joint success，不是中间RD图的拟合损失。

本设计补足R6-D协议中尚未展开的物理驱动J4候选。R6-D的J1是共享任务主干；J2含可学习130→520投影、null候选与单轮参数反馈，属于学习式软候选交互，不能算作固定物理前端证据。R6-F的B3/FFT链提供传统物理处理参照，但不是学习式J4。R6-D的冻结协议和结果不作追溯修改。

本阶段候选不训练教师、不使用教师硬标签或软响应，不把测试真值送入推理输入，也不声称已达到低虚警资格、实测泛化或实时优势。PRF=1300 Hz、N=130、32距离单元、三通道静止杂波仿真保持不变。

## 2. 可选实现路径

| 路径 | 做法 | 取舍 |
|---|---|---|
| A：固定DPCA与频谱候选层（推荐） | 复用通过验证的几何分数时移/通道差分，再做520点零填充慢时间变换；学习检测、null候选、连续偏移和有界反馈。 | 物理算子与学习器边界清楚，能分别评价传统峰值、物理响应和网络读出；依赖当前几何/杂波假设，对未建模通道误差的适应能力有限。 |
| B：物理初始化的可学习复数滤波器 | 用DPCA/频率模板初始化复数核，再让其随任务损失更新。 | 可适应模型偏差，但“物理初始化”和“训练后学到的表示”贡献难分，且更容易过拟合开发集。 |
| C：展开式似然/GLRT网络 | 将目标假设、局部协方差估计、候选似然和任务头展开为可微迭代模块。 | 统计解释较强，但需要新增协方差估计与适配假设，首轮变量过多、显存和正确性验证成本较高。 |

首轮采用A。B或C只在A的前置正确性和任务结果暴露出明确缺口后另立协议；不并入首轮做网格搜索。

## 3. 候选结构

### 3.1 固定物理前端

输入为可观测三通道复IQ及冻结的雷达/平台几何配置。按现有 `dpca_time_shift_s` 与 `dpca_difference` 的几何定义，对冻结通道对(0,1)执行分数慢时间移位和差分：

\[
D[n,r]=X_0[n,r]-\mathcal S_{\delta}X_1[n,r].
\]

随后沿慢时间做520点零填充FFT并移频，得到复数候选响应 `Z[k,r]`。零填充只加密有限CPI频率响应的采样，不增加独立观测信息。实现不得另行拟合或从真值生成前端系数；若静止杂波/目标对该算子的适用性测试失败，停止候选，不用学习损失掩盖物理实现问题。

### 3.2 学习式候选与双向任务头

学习器从复数响应及其幅度/局部邻域形成`520×32`候选分数，并显式加入null类。条件候选后验用于估计连续距离偏移和PRF周期Doppler偏移；候选参数及其物理一致性残差再经一个有界、可微反馈分支修正检测分数。presence概率由null与非null候选的相对证据得到。H0只计算presence真值损失，不产生伪造的目标参数监督。

具体候选归一化、反馈特征、损失权重、输出不确定性和数值稳定处理须在独立协议中冻结；本设计不预设这些超参数，也不把教师结果作为选项搜索依据。

### 3.3 物理前端与学习器贡献的区分

至少保留三类可解释参照：

1. **固定物理峰值：** 同一DPCA+520点变换上的非学习峰值/局部插值读出，衡量物理前端本身。
2. **J4学习读出：** 固定前端不变，增加训练所得候选、null、连续参数与反馈头；相对固定峰值的差异估计学习器贡献。
3. **J1原始IQ联合学生：** 同一场景、任务损失、训练曝光和阈值程序下作为无固定DPCA前端的学习基线。

若实际参数量、输出网格或训练暴露不能匹配，必须报告差异，并把J4相对J1的差异解释为整套表示与学习结构的联合效果；不能单独归因于“物理先验”。如需进一步区分前端贡献，可增加一个使用同样候选头、但取消DPCA差分的`FFT-only`消融；仅在资源预算允许且在协议冻结前确定时使用。

## 4. 物理正确性与工程门

开始训练前的独立G1至少验证：

- 固定CUDA算子与complex128 NumPy参考在注册容限内一致；FFT频点顺序、`fftshift`、周期端点、距离轴和零填充长度均正确。
- 几何分数时移和通道差分对静止杂波的抑制符合已有物理测试；运动目标响应随慢时间频率变化，且目标峰频率在网格平移/回绕后跟随注入频移。
- 公共复相位旋转只改变复数中间图的整体相位，不改变检测分数、null/候选决策和参数估计（数值容限另在协议冻结）。
- 对幅度缩放分别检查原始峰值和归一化检测读出；不得默认固定阈值天然尺度不变。
- 所有候选/反馈/任务损失有限；反馈路径和连续参数路径有有限非零梯度；H0参数损失为精确零；小样本truth-only过拟合门通过。
- OOM只允许降低microbatch并保持冻结effective batch与更新数；禁止CPU回退。模型顺序驻留GPU。

频移作用于DPCA差分后的幅度不一定严格不变，因为差分算子本身具有频率响应。因此频移测试应检查候选位置的周期平移、连续参数误差和预期的前端幅度响应；不能把“所有分数完全不变”设成错误的物理要求。

## 5. 后续预注册的评价原则

只有R6-G完成、R6-H与既定路线的依赖关系明确、scene ID总审计可执行后，才决定是否把J4纳入P7候选。若入选，必须另行冻结protocol/config/code SHA、独立训练/验证/H0 calibration/H0 verification/H1 development、CUDA资源、训练seed与更新预算。训练预算根据已有曲线预注册并让所有比较臂匹配；不追溯修改R6-D，也不依据开发集临时续训。

主要比较应使用C2+C3的paired joint success，并保护Pd、range及PRF-wrapped Doppler误差。固定阈值只由各方法的独立H0 calibration确定，verification不可用于模型或阈值选择。C3 pooled与六个条件格的Pfa及精确区间分别报告；未通过冻结C3门时，不宣称为合格低虚警检测器。所有失败臂、场景ID、训练曲线、参数/显存/时间成本均保留；final blind仍需另行授权。

## 6. 停止条件与决策影响

- 固定算子不符合已验证的几何/数值响应，或频率候选不能按预期移动：停止J4实现，修正已定位的实现错误；若物理假设不适用，则记录反证并不训练。
- G1通过但J4不能通过小样本学习门：停止正式数据生成，排查张量布局、周期频率映射及梯度路径，不追加蒸馏损失。
- J4相对J1改善joint但明显损害Doppler、Pd或C3虚警：保留为局部收益，不晋级正式确认。
- J4只提高固定物理峰值的任务表现，而学习读出无增益：结论归于物理前端，不宣称网络学习到额外知识。
- 若J4对固定峰值和J1都无可复现增益，保留负结果并停止该参数化；不据此否定全部物理驱动网络。

这份设计只补齐J4的可检验候选，不改变当前R6-G训练，不启动新的数据生成或GPU作业，也不构成最终审查请求。
