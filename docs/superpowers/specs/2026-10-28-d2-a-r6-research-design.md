## 3. 路线选择

### 方案 A：先扩大模型，再处理虚警

先训练0.3M/1M模型，期待容量自然改善 C3。R5-A 已显示容量能改善单seed开发集联合任务，但 Medium 仍有 C3 Pfa=0.18896；这条路线不能区分容量和阈值/背景尺度问题，故不作为优先顺序。

### 方案 B：先统一同场景评价并定位虚警来源，再依证据扩展模型

先冻结相同 IQ 场景上的教师、Medium学生与精估计器比较；通过独立 H0 校准/验证和分层 ROC 判断问题来自条件内可分性还是全局分数迁移。随后只选择有证据支持的一个低虚警改进，再进行容量/数据/训练预算对照。推荐此顺序；它直接回应已知 C3 差距，减少无解释的网格搜索。

### 方案 C：一次性运行大规模架构×损失×蒸馏网格

覆盖面看似完整，但会消耗单卡资源、混淆因素，并因大量选择造成开发集过拟合；不采用。

**执行选择：** 按用户给定的 P0–P7 顺序，采用方案 B。R5-C T0–T3先完成；R6-A统一基线和R6-B低虚警是R6首个实证阶段。R6可在R5-D完整机制研究之前启动。R6数据、种子、统计分析和指标与R5-C完全分离。

## 5. R6-A 统一基线设计

所有检测器和估计器接收同一份三通道复 IQ 与同一套冻结场景。R6-A 不重新训练现有 Medium checkpoint；它是同场景比较，不形成新的训练seed结论。

**检测组：** 冻结 B3；D2-A-R3 T1/T2（标为尚未获固定阈值资格的开发候选）；已验证实现的 B0/B1/B2 作为弱基线/诊断；现有 Medium CNN checkpoint。所有方法在共享 H0 calibration set上各自确定阈值，随后在同一独立 H0 verification 和 H1 development CPI 上评价。报告 ROC/AUC、目标工作点Pd、全局/条件Pfa及每CPI候选误警数。阈值来自全局冻结混合，不输入真实 SNR/CNR/目标参数；条件 ROC 只作分布诊断。

**参数组：** FFT 峰、FFT插值、固定4×零填充峰、lag-one相位差、局部连续 Doppler profile-ML、Medium CNN输出。Range 报告整数峰与局部插值/匹配估计。ML按其似然假设标成条件估计器：正确目标候选/正确range gate的 oracle 结果与实际候选结果分开；残余杂波使 AWGN profile likelihood 假设不成立时，不称其为全场景最优或无条件 CRLB。

**同场景端到端组：** B3检测+传统精估、Medium检测+自身参数头、Medium检测+局部 profile-ML、传统检测+学生参数估计。任何使用 oracle 正确候选的图表必须明确标注为条件上界；系统比较还需计入漏检和错误候选传播。

建议冻结的 R6-A 开发样本为12个条件格：H0 calibration 12,000（每格1,000）、独立 H0 verification 12,000（每格1,000）、H1 development 6,144（每格512）。这足以比较0.05和0.01工作点及条件ROC，但不是1e-3/1e-4/1e-6的资格验证。样本由独立高位seed block生成；场景 ID 在方法间共享、在 calibration/verification/development 间互斥。R6-A数据仅用于路线选择。

## 6. R6-B 低虚警研究及统计样本量

统计单位为一个完整 CPI 的最高目标候选分数；对同一 detector 和全局工作点，只在H0 calibration上选阈值，所有方法共用相同H0 verification CPI。C3六格单独报告；每CPI事件和RD CUT事件分开。真值 SNR/CNR仅用于离线分层，不能作为部署门控输入。

当 H0 verification 未观察到任何误警时，单侧95% Clopper–Pearson 上界约为 `−ln(0.05)/n`。精确零误警样本下界约为：

| 目标Pfa上限 | 零误警所需独立H0 CPI数（单个预注册总体） |
|---:|---:|
| 0.05 | 59 |
| 0.01 | 299 |
| 0.001 | 2,995 |
| 0.0001 | 29,956 |
| 0.000001 | 2,995,731 |

这只是验证上界的最小零事件样本量，并不表示校准分位数或条件分层已精确。为稳定估计0.001工作点，R6-B首轮计划H0 calibration和独立verification各120,000（12格每格10,000）；此时全局目标尾部各约有120个样本，C3每格约10个，仍须报告精确区间。0.05、0.01、0.001共用该样本分数并用冻结的顺序统计阈值；0.0001仅在资源复核通过后，以独立百万级校准/验证的增补批次作探索，不以低样本量宣称资格。1e-6不属于首轮，达到零误警单侧95%上界所需样本量约300万 CPI，且条件分层需要更多。

诊断顺序：

1. 用同一阈值绘制所有C0–C3条件下的ROC和Pfa；若条件AUC高、条件分数可排序但固定混合阈值跨条件偏移，问题偏向尺度/校准迁移。
2. 若困难C3条件的条件ROC本身很差，优先改善可观测特征、H0覆盖和目标证据，不靠调阈值掩盖可分性不足。
3. 每次只比较一个受控候选：训练期困难H0负样本挖掘、可观测背景功率归一化、检测分数校准、异质背景训练、参数辅助检测、统计验证模块。验证H0永不用于挖掘或调门。
4. Pfa候选必须保护Pd、参数误差和joint success；单独降低Pfa不算综合改进。

## 7. R6-C 容量、训练和数据规模

容量候选先用同一基线 CNN 主体按拓扑缩放至约0.07M、0.3M、1M推理参数；报告推理参数与训练期辅助参数，不把二者混为一个“模型规模”。R5-A Medium训练模型含130-bin频谱头共82,887参数，冻结推理导出移除该辅助头后为70,277参数，故当前基线约0.07M推理参数。首轮用同一训练/验证场景、初始化规则、任务损失、batch、优化器和12,800 updates做单seed筛选；有研究价值的少数候选再使用至少三个训练seed。R6-B低虚警门槛仍单独报告。

训练预算依次为12,800、25,600、51,200 updates；102,400仅在51,200时验证任务仍有实质改善且未见明确过拟合，并有独立门控后再考虑。固定batch64时，若每update使用32个H0/H1配对base scenes，以上预算对应8、16、32、64遍51,200场景训练集；记录准确的场景暴露、更新数、学习率、验证轨迹、参数量、耗时和显存。

数据规模另立单因素对照：训练数据51,200与102,400对，嵌套生成但验证/评估新建；首先固定optimizer updates以比较独立场景覆盖率与重放比例，再用相同scene exposure补充计算匹配对照。不得把更多固定场景重复训练称作更多训练数据，也不得据短预算负结果否定模型家族。

GPU筛选采用单模型驻留、FP32优先，确有支持时再冻结AMP；有效batch保持64，OOM只减microbatch并梯度累积。批次流式搬入GPU，训练IQ/teacher全图不全量驻留显存。0.3M和1M正式GPU运行先测参数、forward/backward、峰值分配和16-pair过拟合；超出4 GiB时记录并停止或按预算采用 microbatch 4/2，不改变科学任务。

## 8. R6-D 联合模型与R6-E架构

任务口径：D检测优先（固定Pfa下Pd为主）；P参数估计优先（距离/Doppler误差为主，分oracle候选和实际候选）；J真正联合（同一IQ模型联合输出H0/H1及参数，并以最终joint success评价）。分别比较D-only、P-only、J及“参数辅助D/检测辅助P”，主干、数据和优化预算匹配；报告任务梯度冲突与各任务退化，不把辅助损失下降当任务改善。

首个联合模型J1为共享主干多任务学生；J2为**双向软候选交互**：检测支路给出包含null类的软RD候选后验，参数支路对软候选区域估连续参数并返回归一化物理一致性证据，经过有界/校准映射回检测支路。没有硬argmax反馈或真值候选输入；H0由null类表达，H0不计算目标参数回归损失。J2需对反馈截断、归一化和循环Doppler边界给出数学说明。

正确性/梯度测试至少包括：shape与概率和为1；H0/null与H1单目标边界；PRF端点回绕；range gate错位；所有分支有限前后向；检测损失对参数反馈分支有梯度、参数损失对检测软候选有梯度；detach消融确实切断对应梯度；零响应/全均匀分布时无NaN；IQ公共相位与频移干预满足定义的有限容差。先完成CPU小tensor与CUDA batch测试，再运行16-pair/200-update小样本拟合，不先做大规模训练。

之后才考虑J3可微软候选展开、J4可微物理处理。R6-E以受物理机制支撑的少数代表项比较：多尺度残差/TCN或时距分离CNN；具有轴向和周期结构编码的因子化Transformer（与既有TFAS结构差异明确）；参数匹配复数卷积对照；双向慢时间/距离扫描SSM；CNN+SSM/attention融合。Mamba/SSM关于选择性长序列建模的通用论文不能证明它适合此短CPI雷达任务；复值网络的通用组件工作也不能证明本信号任务受益，必须做配对/等变测试。

## 9. R6-F 混合系统与R6-G知识迁移

在相同IQ/scene IDs和最终threshold下比较：A传统检测+传统精估；B神经检测+神经精估；C神经检测+传统profile-ML；D传统检测+神经精估；E真正联合神经网；F神经检测+传统精估+独立统计验证。先报告oracle候选估计上界，再报告实际候选完整链；重新校准每条完整链的H0虚警，不能沿用子模块Pfa。成本包含全部前后处理、CPU/GPU传输、候选数、内存和批处理边界。

R5-C T0–T3是独立的教学内容pilot。R6-G只在其结果和R6-A/B/C/D显示明确知识缺口后，选择少数组合：学生架构/容量 × 教师知识形式，匹配truth-only和truth-assisted控制。先证明K1/K3/K2-local在学生上是否有增量，再另行设计可靠性或时机单因素实验；不做所有模型×教师×损失组合。

## 10. 停止条件与交付

- G0：提交/配置/种子/场景隔离/资源和代码版本一致。
- 基线有效性：同场景输入、阈值和估计链可复现；算法适用假设已写明。
- R6-B：若条件ROC较好而global Pfa差，转向可观测尺度/合规阈值路线；若条件ROC也差，转向特征/背景覆盖；若改进只降Pfa但严重损害Pd或joint，停止该候选。
- R6-C/D/E：若实现/梯度/小样本门失败，先修复或按预设门停止具体候选；短预算负结果不能否定全家族。只有在充足训练曲线和独立数据保护下才能停止候选。
- R6-F：任何链未在自身H0上校准，或靠oracle候选才能显示收益，则不能作为完整系统优势结论。
- 所有结果保留失败项、配置、场景清单、seed、统计区间、训练记录和代码SHA。训练IQ和重建缓存阶段后清理，审计记录保留；项目最终总占用仍须小于20 GiB。

## 11. 先导文献与适用边界

- Diskin et al., *CFARnet: deep learning for target detection with constant false alarm rate*：提出CFAR约束学习框架并分析与GLRT的渐近联系；其统计假设和任务不同于本项目复杂三通道静止杂波，作为R6-B思路来源而不是现成结论。[arXiv:2208.02474](https://arxiv.org/abs/2208.02474)
- Feintuch et al., *Neural Network-Based Multi-Target Detection within Correlated Heavy-Tailed Clutter*：神经检测与CA-CFAR、OS-CFAR、ANMF比较，含记录回波和模拟实验；目标数、杂波分布与当前合成D2-A不等价。[arXiv:2210.12042](https://arxiv.org/abs/2210.12042)
