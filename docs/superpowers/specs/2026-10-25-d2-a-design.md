# D2-A 静止地杂波：设计说明

**状态：** 按用户明确批准的 D2-A 任务实施
**实现基线：** `main` / `d8af9e019400dc0c80e957a0d04dcd4211e41e23`
**适用目录：** `src/radardistill/simulation/`, `src/radardistill/baselines.py`, `src/radardistill/evaluation/`, `experiments/D2-A-E001/`, `tests/`, `docs/`

## 1. 问题和可检验假设

D0/D1 在 3 通道、130 脉冲、32 距离单元的距离压缩复 IQ 上验证了目标估计和蒸馏，但背景仅为复 AWGN。D2-A 只新增静止地面点散射杂波，以验证：

- **H-D2A-1（相干几何）：** 三个接收通道必须由同一地面散射集合和双程传播路径生成；通道相位及静止杂波多普勒应由平台/通道几何推出。
- **H-D2A-2（配对）：** 同一 base scene 下 H0 与 H1 应共享背景散射体、复散射系数、热噪声与所有非目标 nuisance draw；逐样本 H1−H0 只能等于目标贡献。
- **H-D2A-3（可辨识性）：** 目标越靠近杂波的角度/多普勒/距离支撑，有限 CPI 的检测越依赖先验；精确同支撑且未知散射幅相时，目标源标签一般不能从单次总场中唯一分解。
- **H-D2A-4（传统边界）：** B0/B1/B2/B3 的独立 H0 校准和同场景 H0/H1 对比可给出学习任务的实际难度；基线结果仅描述本仿真假设，不宣称生产 APX15 性能。

## 2. 参数与输入边界

- 采用 D0 的 `PRF=1300 Hz`, `N=130`, `C=3`, `R=32` 和 range-compressed IQ 接口。
- D2 有杂波主场景采用生产 XML 中 `fc=15.8 GHz`, `BW=50 MHz`, `fs=60 MHz`、2.28° 波束；D0 无杂波对照原样保持 16 GHz 参数。D2 研究距离网格采用 `c/(2 BW)=2.9979 m`，与 D0 兼容；生产名义 5 m 分辨率另行记录。
- 使用本地 +x 北、+y 东、+z 上坐标，平台匀速 +x。接收相位中心取生产场景四通道坐标的前三个；发射相位中心采用平台参考原点共址的**未验证仿真假设**。
- 每个散射体固定于地面，具有静态位置和复散射系数。每脉冲在连续时间重新计算 Tx/Rx 到散射体距离、有效距离单元、波束增益和传播相位。
- 总路径 `L=R_tx+R_rx`，回波相位 `exp(-j 2π L/λ)`。不得在模型中强制静止杂波慢时间频率为零。
- 距离压缩响应使用 D0 带宽 sinc PSF，作为距离压缩 IQ 的研究近似。仿真不声称重建实际 ADC、匹配滤波加窗、旁瓣/地物相关或标定链。

## 3. R0 生成模型和接口

新增 `src/radardistill/simulation/d2a.py`，定义输入配置、`D2ASceneBatch` 和生成函数。单个样本包含：

- `iq_h0`, `iq_h1`；两者形状 `[3,130,32]`、复数 float32。
- 独立的 `clutter_iq`, `noise_iq`, `target_signal_iq` 分量；H0=clutter+noise，H1=clutter+noise+target。
- 分开的物理真值、counterfactual target 条件、`base_scene_id`、`background_id`、`target_id` 和 `realization_id`；H0 目标真值对外遮蔽。
- 可重放 seed 和配置。随机流按背景、噪声、目标 nuisance 分离，目标参数变化不得改变已有背景/噪声 realization。

每个 base scene 生成共用地面散射体。其角度覆盖指定单束主瓣、初始距离覆盖 32 个 range bin；散射系数为显式参数化的独立圆对称复高斯仿真系数，之后按配置的 CNR 标定整体尺度。热噪声为独立复 AWGN。H0/H1 通过同一份组件数组构造，不能用不同 shape、不同 normalization、target-conditioned background 或 teacher output 生成正负样本。

`compute_scene_power_metrics()` 对每个完整 `[channel,pulse,range]` CPI 分别求 `Ps=mean(|target|²)`, `Pc=mean(|clutter|²)`, `Pn=mean(|noise|²)`，返回 `SNR=Ps/Pn`, `CNR=Pc/Pn`, `SCNR=Ps/(Pc+Pn)` 及 dB 形式。H0 与 H1 使用相同 component arrays；这些是 component powers，不以总场交叉项冒充目标功率。D0 输入的 `snr_db` 仍指连续距离 PSF 峰值的 `A²/E|w|²`；报告同时保存该输入标签和本函数的实际 CPI-mean 功率比，禁止把两种归一化混称。

`generate_d0_compatible_no_clutter()` 仅作 D0 回归适配器，调用冻结的 D0 生成实现，不改写 D0 代码或参数。

## 4. R1 传统检测和评估

共享同一 RD 处理、同一开发场景、同一训练/校准样本数：

- **B0：** 通道 0 的 2D 慢时间 Doppler FFT 最大功率统计量。
- **B1：** 三通道非相干功率相加后取 RD 最大值。
- **B2：** 使用三通道几何 steering manifold，在预设波束角网格上相干合成，再取 RD/角搜索最大值。角度范围来自配置，不能读取样本 truth angle。
- **B3：** 候选沿航向 DPCA：使用第一、二通道 0.17 m 基线和共址 Tx 假设，推导等效 phase-center 时间偏移，做慢时间分数移位后相减；只有静止散射体抑制和运动目标保真测试通过时报告为有效基线。否则记录为实现失败/不适用，不得用理想 oracle 替代。
- **STAP：** 不实现满秩三通道 130 脉冲全维协方差基线。其 390 维 snapshot 小于可用 32 个 range training cells，协方差秩亏；缺少独立 IID 支持样本。该限制在报告中明确说明。

每个 detector 的标量 score 仅用独立 H0 calibration base scenes 校准固定 `Pfa_CPI` 阈值；test H0 不用于定阈值。结果报告 `Pfa_CUT`（若有局部 CUT）、`Pfa_CPI`、每 CPI 假警数、`Pd`、ROC/AUC、range/Doppler 误差（检测漏失也计入 joint success）、目标保真、杂波抑制、SCNR 变化和运行复杂度。误差区间按 base-scene 聚类 bootstrap，不将同一场景的配对 H0/H1 当成独立样本。

## 5. R0 可辨识性诊断

冻结四个 scenario families：

- **A 分离：** 目标 Doppler 显著离开静止杂波角域支撑，且 range/angle 可分。
- **B 近边缘：** 目标 Doppler 接近 beam-limited clutter edge，观测支持只有有限分离。
- **C 部分重叠：** 目标 RD 主瓣和 clutter 支撑重叠，但角度/距离至少一维仍可区分。
- **D 精确/近精确重叠：** target 和一个 clutter scatterer 共享 range/角度/slow-time manifold，复散射幅相未知。逐样本 source attribution 不可唯一识别；D 用于标明边界，不能作为神经网络必胜目标。

实际 scenario 数值、距离和径向速度在 `experiments/D2-A-E001/protocol.md` 中冻结，范围不超 PRF 无模糊多普勒区间。

## 6. R2 后续学生/蒸馏协议

本轮只冻结协议，不训练学生、不生成 final blind。三输出层级：K1 raw RD response，K2 clutter-suppressed target saliency，K3 final detection and estimates。

- A：仿真物理真值监督。
- B：真值 + 教师 K1 软复数/功率频谱响应。
- C：真值 + 教师 K2 杂波抑制目标显著性。
- D：K1/K2 分阶段监督 → 联合 K3 → 退火 teacher loss → 真值 finetune。
- teacher hard labels、teacher soft responses、physical truth 独立保存与单独计量。若 A 未在开发集证明基础任务可学，不进入 B/C/D。
- 训练/验证/阈值校准/开发评估按 base scene 分组；模型与门槛冻结后才生成新的独立 final blind。

## 7. 方案比较与选择

| 方案 | 评估 | 决策 |
|---|---|---|
| 三通道各自独立合成杂波 | 破坏共享地物的空间相干关系，无法测试三通道方法 | 排除 |
| 静止杂波直接置零 Doppler | 违反运动平台对地静止散射体的传播几何 | 排除 |
| 从原始快时间 ADC 重新实现完整波形/匹配滤波 | 把新波形、滤波与 clutter 因素混在一起，且真实窗/复响应未确认 | 本阶段不做；限定在距离压缩 IQ 并记录近似 |
| 共用散射点 + Tx/Rx 每脉冲几何 + D0 range PSF | 能保留相干和静止杂波平台多普勒，新增假设可追溯 | 采用 |

## 8. 风险、验证和阶段门

- 最重要的科学风险是未验证 Tx phase center、方向图及生产相位校准；它们将作为仿真假设，不转写成硬件事实。
- 精确距离相位需要 float64 几何；输出 IQ 用 complex64。测试应覆盖平台方向、相位符号、range migration 和相干性。
- D1 teacher 由 APX15 生产/模拟链导出，但本轮不把 teacher response 写进物理观测或 H0/H1 生成。
- T1–T12 任一核心物理/配对测试失败则不得验收 R0。R1 要求独立 H0 calibration 和按 base scene 的测试；D2-R2 学生训练只有 R0/R1 前门验收后再授权。
- 如果所有 B0–B3 在重叠区域都无法分离，不提高模型复杂度掩盖信息缺失；按 A–D 分别报告能力边界和下一阶段 GO / CONDITIONAL GO / STOP / REDIRECT。
