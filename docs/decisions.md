# 技术决策记录

## 2026-10-22：P0 采用 NumPy CPU 小型 Conv1D

- **背景：** 初检环境 Python 3.13.5、NumPy 2.1.3、SciPy 1.15.3、pytest 可用；PyTorch/TensorFlow/JAX 不存在，NVIDIA 驱动不可用。
- **决定：** 先用 NumPy 实现简单 Conv1D + ReLU + 全局均值池化 + sin/cos 圆周输出及 Adam 训练，以满足 P0 真实训练需求且不安装依赖。
- **理由：** P0 的研究问题是能否学习频率物理信息，而非框架性能；当前实现可复现且网络规模小。
- **边界：** 当前性能/时延不代表 PyTorch/GPU；后续只有在可用硬件或实验需求出现时再迁移，迁移需保持数据种子和实验对照。

## 2026-10-22：教师软标签用局部 profile likelihood

- **背景：** P0 需要把教师估计与物理真值分开，并让联合训练使用软知识。
- **决定：** 以连续 profile-ML 峰值为教师模式，在其 ±2 个 FFT bin 范围内计算 profile-likelihood 的圆周均值，作为 E2/E3 软目标；真值、教师频率和教师软目标独立存储。
- **理由：** 这是可重复的局部频率不确定性表示，且保持教师模式；不会把教师估计冒充物理真值。
- **边界：** 局部软分布不是全局后验，可能忽略多峰歧义；该限制在结果解释中明确，必要时后续改为全局频率似然。

## 2026-10-22：P0 未通过性能继续门，暂不启动 P1

- **证据：** P0-E001 的三种子 E1 在 -5 至 20 dB 均未超过 FFT 峰值；20 dB E1 RMSE 为 15.00 Hz，FFT 峰值为 2.96 Hz、插值为 1.23 Hz、相位差为 0.206 Hz、连续 ML 为 0.0332 Hz。P0-E002 延长训练后 E1 改善至 8.55 Hz，但为单种子且仍落后基线。P0-E003/004 的位置保留 Dense 头测试误差更大，训练/验证差距明显。
- **决定：** 保留 P0 负结果；P1 暂停在阶段门之前，不把单音估计结果外推为三通道 GMTI 能力。
- **下一实验：** 最多先做一个针对归纳偏置的预注册 P0 诊断：小容量位置敏感读出或显式相位增量输入。保留固定独立测试集和全部传统基线，并要求在部分正常 SNR 稳定优于 FFT 峰值。
- **停止规则：** 若该诊断未达到预定门槛，先分析误差/可辨识性并重新评估纯 CNN 路线，不扩大成无目标超参数搜索。

## 2026-10-23：分离 P0 学习、传统竞争与蒸馏阶段门

- **背景：** E001–E005 的测试集参与了多轮架构诊断；原单一继续门会在“学到频率”与“超过 FFT”之间混为一谈。E2 的旧验证选择也使用了物理真值，无法代表全程教师选择。
- **决定：** 将 E001–E005 测试集标为开发基准；E006 使用冻结的新最终 seed。P0 分 G1 学习可行性、G2 传统算法竞争力、G3 蒸馏价值独立验收。E2-A 使用教师验证，E2-B 使用真值验证并明示，E3 使用真值+教师目标。
- **验收约束：** G1 失败则 STOP/REDIRECT。G1 通过且实现正确时，即使 G2 未通过，也可 CONDITIONAL GO 进入最低复杂度 P1-A；这不构成传统算法替代能力的证据。G2/G3 阈值不得事后调整。E006 的具体标准以冻结协议为准。
- **硬件与复现：** 用户要求并授权在可见 GPU 上进行 E006 训练。AISAR 中已检测到 RTX 3050 Laptop 和 CUDA；E006 runner 在没有 CUDA 时中止，禁止 CPU 回退。GPU训练只作为执行环境记录，不作为边缘部署速度证据。

## 2026-10-23：P0 profile-ML 名称和低 SNR 参考

- **背景：** 原 estimator 使用 FFT 峰初始化的局部 profile-likelihood 搜索，错误峰会限制局部搜索。
- **决定：** 保留旧实现并明确命名为 local profile-ML；兼容 `estimate_mle` 别名。增加全局高分辨率网格参考和同四个复相关输入的非学习相干评分。
- **证据：** 测试 seed 61000 的第 5 个 -15 dB 样本中，真值约 335.966 Hz，FFT 峰和局部 ML 约 -360/-357.839 Hz，而 1024 网格全局参考约 335.571 Hz。该例说明局部搜索可能被错误 FFT 峰困住，不代表有限网格等于连续全局最优。

## 2026-10-23：E006 首轮评估作废并轮换最终测试种子

- **证据：** 首轮训练完整完成，但检查 `result.csv` 发现 3,278,901 行/474,335,833 字节。根因是传统估计器的一维整批预测被当作标量种子列表；基线误差矩阵、汇总指标、配对 bootstrap 和 baseline 预测存档均受影响。
- **决定：** 不采用 seed 909090 结果，也不根据它调整模型；保留训练数据、checkpoint 和错误运行记录，错误 CSV 无损归档。修复统一 prediction-replicate 规范化并增加自动回归测试。
- **盲测规则：** 由于 seed 909090 已生成并检查，修正版 final seed 改为 919191。训练配置、模型、预算、门槛及指标公式保持不变。修正版仍需全程用 CUDA 训练。

## 2026-10-23：P0-E006 阶段决策 STOP / REDIRECT

- **证据：** 修正版 E006 的 G1 无噪声门为 0/3 种子通过（S1 MAE 2.44–3.01 Hz，P95 5.75–6.40 Hz；S2 更差）；S1 仅在一个主 SNR 点显著胜过 FFT，且没有胜过匹配多延迟解析参考；E3/T2 的显著收益出现在不相邻 SNR，E3/T3 全部变差。
- **决定：** 按冻结门槛，G1 未通过，因此停止当前单音学生网络扩模，不启动 P1-A 训练，不将 P0 性能外推到三通道/检测。P0 阶段总结完成；只保留 P1-A 理论方案草案，待后续单独审议。
- **边界：** S1 优于旧 CNN、远优于零频预测，支持“学习到部分频率信息”的有限判断，但不支持可靠高精度学习、传统算法替代或蒸馏增益。

## 2026-10-24：P0-E007 更新当前阶段判断并停止无收益路线

- **背景：** E006 按其冻结盲测判定 STOP/REDIRECT，G1 未通过。用户随后批准了新的、单独预注册的三范式 P0 诊断 E007；E007 不重用 E006 最终测试，也不改写其历史结论。
- **证据：** E007 使用固定 16N FFT + 学习式循环频谱读出的 M1、4N FFT 子栅格混合模型 M2、直接 IQ 小型 Transformer M3。M1 三种子 E1 在 20 dB RMSE 为 0.03722、0.04369、0.03607 Hz；G1 全部三种子通过。M1 在五个主 SNR 点均显著优于 N 点 FFT 峰值及匹配 16N FFT 峰值，G2 通过。M1-power 消融略优但配对区间跨零，说明本实验没有显示相邻谱相干输入的频率精度收益。M2 未通过预注册验证下降门，且落后相同局部谱输入的抛物线估计和 profile-ML；M3 单种子训练/验证差距很大并接近常值预测，故都不扩展三种子正式训练。E3-S 蒸馏未产生稳定收益，G3 失败。
- **决定：** 按既定独立阶段门更新当前 P0 为 **GO**，允许启动 P1-A 方案登记与设计；P1-A 训练仍未开始。E006 的 STOP/REDIRECT 作为历史审查原样保留。
- **边界：** GO 不表示 M1 超越 ML、蒸馏有效、相干输入增益已证实或三通道能力成立。M1 在 20 dB 略差于连续 profile-ML 和高分辨局部插值；所有结论来自 AWGN 单音仿真。
- **后续约束：** 不再为 M2/M3 追加未经预注册的筛选预算，也不扩大 P0 架构搜索。P1-A 若启动，须建立三通道可辨识模型和强解析相位基线，冻结独立数据、统计门槛与频率/相位周期指标后再训练。

## 2026-10-24：冻结 P1-A-E001 理想三通道相对相位实验

- **触发条件：** 用户依据 P0-E007 的 GO 决策批准继续进入最小 P1-A 实验，并要求直接执行。
- **决定：** 冻结 `experiments/P1-A-E001/protocol.md` 与 `config.yaml`。研究模型为三通道共享单音加独立同方差复 AWGN；只估计相对相位 `Δφ21`、`Δφ31`。学习器先显式计算两组能量归一化复互相关，再用 `4→64→64→4` 小 MLP 回归 sin/cos。仅做 E1 物理真值监督，不开展教师蒸馏。
- **比较对象：** 零相位先验、相干互相关、逐样本圆均值和同方差秩一 profile-ML。报告条件 CRLB、周期误差、SNR/相位/初相/幅度分组和配对 bootstrap。
- **数据与执行：** 训练/验证分别使用三个独立种子；每个 SNR 1024 条的全新盲测集仅在训练模型冻结后生成。训练固定为 RTX 3050 `cuda:0`、FP32、batch 64、Adam、最多 160 epochs、patience 40，按种子顺序运行。训练数据留在 CPU 内存，按 batch 传至 GPU。
- **边界：** 不进入 P1-B，不加入通道误差、杂波、时延或多目标；E001 结果只支持理想三通道相位可学习性判断，不支持角度、速度或 GMTI 检测结论。

## 2026-10-24：P1-A-E001 G1 未通过，停止当前相位读出路线

- **证据：** 三个 RTX 3050 CUDA 训练种子均通过 20 dB 零相位基线改善与公共相位旋转/复尺度/频移不变性检查，但 0/3 同时满足 G1；无噪声两相位 MAE 为 0.0177–0.0206 rad，预注册门槛为 `<0.01 rad`。20 dB 学生 RMSE 为 0.0232–0.0260 rad，条件 CRLB 约 0.0099 rad；B1、B2、B3 均约 0.0097–0.0100 rad。学生−B1/B3 的三种子配对 95% bootstrap 区间在 20 dB 全为正。
- **训练诊断：** 三个种子的训练/验证向量 MSE 均在约 0.10 平台化，未见明显过拟合鸿沟；无噪声 RMSE 约 0.022–0.026 rad。该结果支持当前小 MLP 读出精度不足/欠拟合，但不能单独定位因果。
- **决定：** 按预注册门槛判为 **STOP / REDIRECT**。不进入 P1-B、不开展教师蒸馏，不在盲测之后追加训练或调整阈值。若以后要重启相位学习，应先提出单独的可证伪问题、冻结方案并另用独立盲测。
- **边界：** 学生确实使用了相对相位信息并显著优于零相位先验；本结果只否定当前读出模型在理想单音 AWGN 条件下达到既定精度门的能力，不否定所有学习架构，也不外推到真实回波或 GMTI 检测。P0-E006、P0-E007 的历史结论均保持不变。
