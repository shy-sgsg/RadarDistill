## 2026-10-22：P0 采用 NumPy CPU 小型 Conv1D

- **背景：** 初检环境 Python 3.13.5、NumPy 2.1.3、SciPy 1.15.3、pytest 可用；PyTorch/TensorFlow/JAX 不存在，NVIDIA 驱动不可用。
- **决定：** 先用 NumPy 实现简单 Conv1D + ReLU + 全局均值池化 + sin/cos 圆周输出及 Adam 训练，以满足 P0 真实训练需求且不安装依赖。
- **理由：** P0 的研究问题是能否学习频率物理信息，而非框架性能；当前实现可复现且网络规模小。
- **边界：** 当前性能/时延不代表 PyTorch/GPU；后续只有在可用硬件或实验需求出现时再迁移，迁移需保持数据种子和实验对照。

## 2026-10-22：教师软标签用局部 profile likelihood

- **背景：** P0 需要把教师估计与物理真值分开，并让联合训练使用软知识。
- **决定：** 以连续 profile-ML 峰值为教师模式，在其 ±2 个 FFT bin 范围内计算 profile-likelihood 的圆周均值，作为 E2/E3 软目标；真值、教师频率和教师软目标独立存储。
- **理由：** 这是可重复的局部频率不确定性表示，且保持教师模式；不会把教师估计冒充物理真值。
- **边界：** 局部软分布不是全局后验，可能忽略多峰歧义；该限制在结果解释中明确，必要时后续改为全局频率似然。

## 2026-10-23：P0 profile-ML 名称和低 SNR 参考

- **背景：** 原 estimator 使用 FFT 峰初始化的局部 profile-likelihood 搜索，错误峰会限制局部搜索。
- **决定：** 保留旧实现并明确命名为 local profile-ML；兼容 `estimate_mle` 别名。增加全局高分辨率网格参考和同四个复相关输入的非学习相干评分。
- **证据：** 测试 seed 61000 的第 5 个 -15 dB 样本中，真值约 335.966 Hz，FFT 峰和局部 ML 约 -360/-357.839 Hz，而 1024 网格全局参考约 335.571 Hz。该例说明局部搜索可能被错误 FFT 峰困住，不代表有限网格等于连续全局最优。

## 2026-10-24：冻结 P1-A-E001 理想三通道相对相位实验

- **触发条件：** 用户依据 P0-E007 的 GO 决策批准继续进入最小 P1-A 实验，并要求直接执行。
- **决定：** 冻结 `experiments/P1-A-E001/protocol.md` 与 `config.yaml`。研究模型为三通道共享单音加独立同方差复 AWGN；只估计相对相位 `Δφ21`、`Δφ31`。学习器先显式计算两组能量归一化复互相关，再用 `4→64→64→4` 小 MLP 回归 sin/cos。仅做 E1 物理真值监督，不开展教师蒸馏。
- **比较对象：** 零相位先验、相干互相关、逐样本圆均值和同方差秩一 profile-ML。报告条件 CRLB、周期误差、SNR/相位/初相/幅度分组和配对 bootstrap。
- **数据与执行：** 训练/验证分别使用三个独立种子；每个 SNR 1024 条的全新盲测集仅在训练模型冻结后生成。训练固定为 RTX 3050 `cuda:0`、FP32、batch 64、Adam、最多 160 epochs、patience 40，按种子顺序运行。训练数据留在 CPU 内存，按 batch 传至 GPU。
- **边界：** 不进入 P1-B，不加入通道误差、杂波、时延或多目标；E001 结果只支持理想三通道相位可学习性判断，不支持角度、速度或 GMTI 检测结论。

## 2026-10-24：P1-A-E001 G1 未通过，停止当前相位读出路线

- **证据：** 三个 RTX 3050 CUDA 训练种子均通过 20 dB 零相位基线改善与公共相位旋转/复尺度/频移不变性检查，但 0/3 同时满足 G1；无噪声两相位 MAE 为 0.0177–0.0206 rad，预注册门槛为 `<0.01 rad`。20 dB 学生 RMSE 为 0.0232–0.0260 rad，条件 CRLB 约 0.0099 rad；B1、B2、B3 均约 0.0097–0.0100 rad。学生−B1/B3 的三种子配对 95% bootstrap 区间在 20 dB 全为正。
- **训练诊断：** 三个种子的训练/验证向量 MSE 均在约 0.10 平台化，未见明显过拟合鸿沟；无噪声 RMSE 约 0.022–0.026 rad。该结果支持当前小 MLP 读出精度不足/欠拟合，但不能单独定位因果。
- **决定：** 按预注册门槛判为 **STOP / REDIRECT**。不进入 P1-B、不开展教师蒸馏，不在盲测之后追加训练或调整阈值。若以后要重启相位学习，应先提出单独的可证伪问题、冻结方案并另用独立盲测。
- **边界：** 学生确实使用了相对相位信息并显著优于零相位先验；本结果只否定当前读出模型在理想单音 AWGN 条件下达到既定精度门的能力，不否定所有学习架构，也不外推到真实回波或 GMTI 检测。P0-E006、P0-E007 的历史结论均保持不变。

## 2026-10-24：D1 初步推理成本与下一阶段优先级

- **证据：** 已距离压缩 IQ 输入边界上，D 学生 CUDA batch 1/32/128 平均时延为 1.53/15.77/59.75 ms，P95 为 1.91/18.01/62.11 ms；batch 128 峰值分配显存约 359 MB。APX15 FFT 子链 CPU batch 1 平均 0.83 ms。两者测量设备不同，且未覆盖全原始回波处理链，不能用于速度优劣或部署结论。

## 2026-10-24：首次训练前补明 D1-E002 评价分数与流式 seed

- **触发：** 对 E002 执行器的预训练审阅发现，协议虽要求各方法校准检测阈值，却未定义 FFT/lag-one 频率基线的检测分数，也未写出流式盲测分块的派生 seed。
