# 创新空间与已有工作边界

## 当前能确认的已有工作

1. **raw ADC 学习和教师蒸馏已见于汽车 FMCW 雷达。** ADCNet 用离线 DSP 伪标签预训练 raw ADC 学生；T-FFTRadNet 研究从 raw ADC 做检测。这些工作不能直接证明机载三通道 GMTI 的速度/相位估计能力。
2. **神经网络频率估计已有先例。** 多正弦频率学习和单音神经回归均已有公开研究；因此 P0 的“使用小 CNN”不应被宣称为新方法。
3. **GMTI/STAP 学习已出现。** 自监督 MTI 和深度展开 ANM-STAP 分别覆盖模拟器一致性和空时杂波处理，但其公开摘要尚未证明同一三通道宽域体制、原始慢时间参数输出和严格 1e-6 Pfa。
4. **传统三通道 SAR-GMTI 基线成熟。** DPCA/ATI、3 Doppler transform、协方差特征值和干涉相位已有星载/机载或实测工作。项目必须把现行体制和几何放入比较，不能仅与简单 FFT 或弱检测器比较。
5. **CFARNet 面向不同的 OFDM rainbow-beam 雷达。** 它是学习式峰检测的相关线索，但不能直接作为 GMTI 证据，也不替代低虚警率校准。

## 可能的研究空间（待验证，不是新颖性结论）

- 将物理真值、传统教师估计与教师局部似然/中间知识严格分开，并对复数慢时间、相位周期和三通道几何做独立测试。
- 研究“真值监督 vs 纯教师蒸馏 vs 联合训练”在频率、通道相位、估计不确定性和模型失配条件下的差别，而不是仅报告网络拟合教师的误差。
- 在真实三通道 GMTI 观测假设下，联合评估相位、速度和检测误差传播，并用已核验的传统多通道基线约束学习结论。
- 探索物理前端保留与学习模块替换的边界，比较分阶段学习、联合蒸馏和端到端方案的弱目标/非均匀杂波性能。
- 对模型失配、训练数据有限、硬件误差等优势条件作针对性假设，并报告适用域；不以架构新颖性替代性能与理论证据。

## 当前明确不主张的内容

- P0 不是最终论文创新；连续单音频率神经估计已有先例。
- 尚未完成更广的论文、专利、学位论文和真实系统资料检索，不能声称“首次”“尚无人研究”或创新点已成立。
- 汽车 FMCW raw ADC、星载 SAR-GMTI、机载宽域 SCANSAR-GMTI、STAP 和 OFDM rainbow beam 不能合并成一个任务集合。
- 仿真模型上的 RMSE 不证明真实回波可迁移；小样本背景不能证明 Pfa=1e-6。

## 进一步核查任务

P0 验收后、进入 P1/P2 前：从目标机载体制的论文/公开数据集/硬件说明中确认 PRF、通道位置、脉冲/扫描结构、相位校准和可辨识区域；逐项复核 3 Doppler transform、DPCA、ATI、协方差/GLRT 及现行 CSI 实现；补充国内外学位论文/会议全文和公开数据集说明；最后才能收敛具有可验证边界的创新假设。
