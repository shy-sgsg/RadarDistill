## 结论摘要

既有项目已经形成可复现的单目标复正弦 + 复 AWGN 频率估计链，保存了传统基线、学生模型、种子数据和负结果。审计发现并修复了 E2 验证标签协议表述、局部 ML 命名、N=130 分组硬编码和 NumPy 手写梯度缺少数值核验等问题。E001–E005 的历史结果未重算、未删除，也未被当作新的最终盲测。

## 发现、证据与修复

| 问题 | 证据与影响 | 修复和验证 |
|---|---|---|
| E2 训练与验证标签协议混淆 | 原流程 E2 用教师软目标训练，却以真值验证早停，因此不能称为全程教师选择的无真值蒸馏。 | `experiment.py` 显式支持 `teacher`、`truth` 和历史 `truth_legacy` 选择；E006 将 E2-A（教师选模）与 E2-B（真值选模）分开记录，并保留 E3 的真值验证。单测检查两种标签目标不互换。 |
| profile-ML 被过度概括 | `estimate_mle` 从 N 点 FFT 峰初始化相邻 bin 范围内的连续搜索；在错峰时会局部收敛到错误峰。 | 保留算法并命名 `estimate_mle_local`，旧名称保留兼容；新增全局均匀网格搜索和多延迟相干传统基线。离栅格、近 Nyquist、变 N/PRF 和低 SNR 错峰测试通过。 |
| 固定脉冲数用于分组 | 旧测试子集的 FFT-bin 宽度固定按 130 点计算，不适用于其他脉冲数。 | 现在从实际 `iq.shape[-1]` 计算 bin 宽度；测试覆盖不同长度、PRF、边界、空输入及错误形状。 |
| NumPy CNN 梯度未经有限差分核验 | 手工卷积、全连接和蒸馏反向传播容易产生不易发现的实现误差。 | 提供 `loss_and_gradients` / `loss_value` 检查接口；卷积权重/偏置、隐藏权重/偏置、输出权重/偏置的解析梯度均与中心有限差分比较，测试目标含教师蒸馏损失。 |
| 物理变换性质未系统核对 | 频率、相位具有周期性，公共初相、整体复缩放、频率平移和共轭会产生明确变换关系。 | 测试仿真器和传统 estimator 的相位/尺度/频移/共轭关系；E006 对网络和固定旧 CNN 记录变换后的实测偏差，不假设网络天然严格等变。 |
| 预测向量形状混淆种子维 | E006 首轮中经典方法返回的 `(N,)` 被 Python 逐值迭代，错误地当成 N 个训练种子；这污染基线汇总、配对比较、CSV 和预测 archive。 | 新增统一 `_prediction_replicates`：一维数组视为一个完整重复，二维数组按种子拆分；每个预测必须与测试样本一一对应。回归测试验证 shape、样本数、RMSE 和行数。首轮无效结果已留档，seed 909090 不重用；修正复跑用新盲测 seed 919191。 |
| 旧测试被重复用于开发 | E001–E005 多轮模型/特征决策都参考相同的 seed 7070 测试集。 | 统一将其标为 `development_benchmark`；E006 固定独立 final seed 909090，模型和停止规则在盲测生成前冻结。 |

### 局部搜索错峰的确定性例

固定数据 seed 61000、PRF=1300 Hz、N=130、SNR=-15 dB 的第 5 个样本，物理真值为约 335.966 Hz。FFT 峰为 -360 Hz，局部 profile-ML 为 -357.839 Hz；1024 点全局频率网格参考为 335.571 Hz。相应周期误差约为 FFT +604.034 Hz、局部 ML +606.195 Hz、网格参考 -0.395 Hz。该例证明局部搜索可能被错误初始化峰困住；有限网格只近似连续全局极值，不将此样本外推成整体基线排序结论。

## 既有数据重复审计

## 未消除的限制

1. 局部 profile-ML 仍可能错峰；全局网格的分辨率有限，正式报告应并列而不能把任一有限搜索称作解析的连续全局解。
2. T2/T3 教师信息仍以教师局部模式为中心、覆盖 ±2 个原生 FFT bin；若教师局部模式错峰，其局部概率响应也可能集中在错误频段。
3. 全部 P0 证据来自仿真单音 AWGN，不涵盖杂波、多目标、三通道误差或实测回波。
4. GPU 执行只用于实验训练；未测量端到端部署延时、能耗或边缘硬件效率。
5. 旧 E1–E5 的 E2 选择协议与开发集用途按历史记录解释，不对旧结果作事后校正。

E006 的实际结果及其 STOP/REDIRECT 阶段判断见 `docs/stage_reviews/P0_final_review.md`；P1-A 只保留未注册的理论草案。
