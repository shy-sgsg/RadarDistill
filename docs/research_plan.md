# 分阶段研究计划

P0/P1 是已经开展的历史先导实验，其档案及决定保留。2026-10-24 用户批准的新主线是 D0 → D1 → D2 → D3 → D4 → D5；它以最终任务为中心，不要求先通过单独相位读出实验。阶段通过门槛后才增加场景难度；每个实验都保留传统基线、物理真值/教师输出区分、统计结果和负结果。

**当前状态（2026-10-24）：** E001–E005 已标为开发基准。P0-E006 的 STOP/REDIRECT 是保留的历史结论；P0-E007 在 RTX 3050 CUDA 完成新的预注册评估，G1、G2 通过、G3 未通过，P0 决策为 GO。随后完成 P1-A-E001 三通道相对相位实验，但 G1 为 0/3 种子通过，原 P1-A 相位路线决定 STOP/REDIRECT；不进入 P1-B 或相位蒸馏。新主线 D0/D1 由用户单独批准，不改变上述历史结论。详见 `experiments/P0-E007/analysis.md`、`docs/stage_reviews/P0_final_review.md`、`docs/stage_reviews/P0-E007_review.md` 和 `docs/stage_reviews/P1-A-E001_review.md`。

## 当前任务级路线：D0 → D5

该路线优先验证直接最终任务学习和教师知识价值。教师可以提供频谱响应、目标候选和检测统计量，但教师错误不得覆盖物理真值，学生最终推理也不必保留教师结构。P0/P1 的历史阶段门继续用于解释其自身结果，不约束新路线启动。

### D0：可信物理仿真与传统教师（已通过）

建立三通道距离压缩复数慢时间仿真、H0/H1 标签、目标距离/Doppler 真值、APX15 慢时间 FFT 子链教师和统一评价接口。12 项冻结正确性门全部通过，-10 dB 教师检测 AUC 为 0.98856；阶段审查允许开始 D1。该结论仅涵盖简化仿真与 CPU FFT 子链，不声称完整 CoreX 生产链已集成。证据见 `experiments/D0-E001/` 与 `docs/stage_reviews/D0_review.md`。

### D1：最小任务级检测和估计

输入 `[3,130,32]` 三通道复 IQ，直接输出目标存在、连续距离单元和连续 Doppler。数值协议冻结于 `experiments/D1-E001/config.yaml` 与 `protocol.md`；轻量 TCN、四类损失、CUDA pilot、三种子 formal 训练、独立校准和最终盲测均已完成。阶段审查为 **GO → D2**：G1 PASS、G2 PASS、G3 FAIL。C 联合监督和 D 渐进蒸馏通过预注册最终指标规则，但没有任何蒸馏组通过收敛加速规则；学生低 SNR 检测与高 SNR Doppler 精度仍落后于传统教师或 profile-ML。GO 只允许按 D2 方案逐项增加复杂度，不代表传统替代或实测性能。详见 `docs/stage_reviews/D1-E001_review.md` 与 `experiments/D1-E001/analysis.md`。

### D2：三通道参数与复杂场景

只有 D1 阶段审查支持后才增加角度/速度可辨识分析、多目标、静止/强杂波、低速弱目标及通道误差；逐项增加困难，不把不可辨识参数交给网络猜测。

### D3：原始回波渐进迁移

将学生输入从距离压缩回波前移至原始三通道回波，比较物理前端加学生与原始回波学生；教师与已验收学生提供辅助知识，逐步撤除辅助分支。

### D4：结构与计算优化

仅当 D1/D2 模型已可靠完成任务后，研究流式结构、稀疏特征、剪枝、量化、算子融合和 CUDA 优化；每项变化与未优化学生做同任务比较。

### D5：完整 GMTI 场景和系统验证

在相同硬件、输入边界和完整前后处理范围下比较传统处理链、物理前端加学生及原始回波学生；报告 Pd/Pfa、参数误差、P95/P99 时延、吞吐、内存和功耗。达到样本量要求前不得声称 Pfa=1e-6。

**当前执行阶段（2026-10-24）：** D0-E001 与 D1-E001 已完成冻结阶段审查；D1 原阶段门为 GO → D2（G1/G2 PASS，G3 FAIL），历史结论不变。用户另行批准在增加 D2 场景复杂度前开展有界 D1-R1 Doppler 诊断和 D1-E002 受控结构实验。当前优先任务只有 D1-R1；E002 结构、训练预算、非劣门和独立盲测协议须在 R1 证据后冻结。两项实验不改变 D1-E001 盲测结论。D1 的 Pfa=1e-2/1e-3 结果不能外推为 Pfa=1e-6，仿真结果不能称为真实 GMTI 验证。动态状态见 docs/CURRENT_STATUS.md 和 docs/RESEARCH_ROADMAP.md。

### D1-R1：任务级学生连续 Doppler 误差诊断（已批准，待执行）

仅用 D1 训练缓存、验证缓存、正式训练历史和可复核 checkpoint；最终盲测结果不得用于诊断或模型选择。拆分检测、距离分类/偏移和 Doppler 误差；对照预测距离门和只用于诊断的真值距离门；按 SNR、真值频率、相位、幅度、距离、Nyquist 邻域和种子分组。用训练样本拟合池化前/后的低成本线性 probe，并在验证样本上评价；计算共享主干上的任务梯度范数和方向。若所需训练 checkpoint 或数据不存在，明确标为不可复算。输出见 experiments/D1-R1/ 和 docs/stage_reviews/D1_R1_doppler_diagnosis.md。

### D1-E002：受控连续 Doppler 结构实验（已批准总体路线，具体协议待冻结）

继续三通道距离压缩复 IQ 输入及 H0/H1、距离、连续 Doppler 任务。S0 为冻结原 TCN；S1 按 R1 证据保留时间结构；S2 为低成本相干物理特征；S3 固定 FFT 混合方法只作诊断并与匹配非学习估计器比较。先用单 seed pilot 筛选，再对选中候选使用至少三个独立训练种子、匹配数据/预算和新的独立盲测。固定检测保护指标、Doppler 主指标、距离保护门、资源成本及停止条件后，才可生成盲测。不得将 S3 归因为纯学习成功。

## 历史先导实验：P0/P1

以下 P0/P1 计划和结果仅记录旧的模块级路线及其证据。它们不因新增 D0/D1 主线而删改。

## P0：单目标高精度多普勒频率估计（已完成阶段审查）

1. **科学问题：** 小型网络能否从长度 130 的复数慢时间观测中学习连续 Doppler？教师蒸馏是否优于真值监督？
2. **假设：** 随机相位/幅度和连续频率下，网络应优于常数预测；正确模型下 ML 应是强参考，蒸馏增益不预设。
3. **理论依据：** 单音复高斯似然、周期频率表示、无偏频率估计 CRLB。
4. **数据：** PRF=1300 Hz，N=130，训练 SNR {-15,-5,0,10,20} dB，测试 {-15,-10,-5,0,5,10,15,20} dB；独立训练/验证/测试种子，连续无模糊频率、随机初相和幅度。
5. **传统算法：** FFT 峰值、三点 FFT 插值、相位差、连续最大似然。
6. **学习模型：** 小型 1D Conv + 圆周 sin/cos 输出；E1 真值监督、E2 纯教师软目标、E3 真值+教师软目标。
7. **步骤：** 仿真一致性 → 基线 → CRLB → 教师标签 → 训练三组策略 → 独立测试 → 分组和种子分析。
8. **指标：** MAE/RMSE/偏差/异常率、SNR/频率/初相/幅度/栅格偏移分组、CRLB、配对 bootstrap 区间。
9. **验收：** 三个独立门分别报告。G1：至少一类学生在至少 2/3 个训练种子的连续无噪声检查中 MAE<1 Hz、P95<5 Hz，且 20 dB E1 RMSE 至少比零频预测低 50%。G2：E1 在至少两个相邻主 SNR 点同时以配对区间胜过 FFT 峰值和同输入物理前端解析基线。G3：E3 在至少两个相邻主 SNR 点胜过匹配 E1，配对 95% 区间整体低于零，且每个通过点至少 2/3 训练种子方向一致。G1 失败则 STOP/REDIRECT；G1 通过而 G2 失败时可 CONDITIONAL GO 进入最低复杂度 P1-A，但不可声称传统算法竞争力。详细冻结门槛见 `experiments/P0-E006/protocol.md`。
10. **失败原因：** 标签/信号错误、周期边界、训练分布捷径、网络欠拟合、教师偏差或低 SNR 信息不足。
11. **备选：** 先复核数学与数据；只针对有证据的因素改输入归一化、训练采样或圆周表示；若 ML 接近 CRLB，转向失配条件而不人为削弱 ML。
12. **产出：** P0 配置、仿真数据、教师和学生权重、逐样本预测、汇总表及阶段分析报告；根据证据做 P1 决策。

### P0-E006 冻结实验

在 E001–E005 的开发基准之外，使用 3 个训练种子、3 个独立验证集和 final seed 919191（每个 SNR 1024 例）。首轮 seed 909090 因评估器把基线批量向量误读为多个种子而作废，已留档且不用于选模。修正版比较冻结 E005 CNN（S0）、复相关特征 MLP（S1）、固定 4N 频谱特征混合模型（S2），并设置同复相关和同频谱前端的非学习估计器。E2-A 以教师目标早停，E2-B 以真值验证早停，E3 使用真值加教师知识。训练上限 160 轮，全部 33 个训练实例使用 CUDA。结果和阶段决策见 `experiments/P0-E006/analysis.md`、`metrics.json` 和 `docs/stage_reviews/P0_final_review.md`。

### P0-E007 三范式架构筛选与正式评估

E007 的设计、模型和筛选/停止规则见 `experiments/P0-E007/protocol.md` 与 `docs/superpowers/specs/2026-10-23-p0-e007-design.md`。在相同 P0 复单音 AWGN 条件下，使用固定 16N 复 FFT 加可学习循环读出的 M1、固定 4N FFT 加学习子栅格修正的 M2、直接输入 IQ 的小型 Transformer M3；M1 的功率输入消融用于检查相干通道贡献。三种架构各先完成一个种子筛选，仅 M1 进入正式三种子 E1 和 E2-H/E2-S/E3-S 蒸馏比较，M1-power 只作三种子 E1 消融。

E007 最终独立盲测每 SNR 1024 例，采用全新 seed 999983 起按 SNR 偏移生成。M1 在 20 dB RMSE 为 0.03899 Hz（CRLB 标准差 0.03419 Hz）；比 N 点 FFT 峰值、N 点插值、相位差和 16N FFT 峰值更准，但略差于 4N/16N 局部抛物线和连续 profile-ML。M1 与功率消融间的差异未显著，M3 单种子筛选失败，不能据此判定所有直接序列模型不可行；M2 未胜过匹配局部抛物线或连续 profile-ML，因此不做三种子扩展。G1 PASS、G2 PASS、G3 FAIL，P0-E007 阶段决策 GO；该结果允许进入 P1-A 协议设计，不表示知识蒸馏有效或传统算法已可被全面替代。

## P1：三通道相对相位估计（P1-A-E001 已完成，STOP / REDIRECT）

P0-E006 曾因 G1 未通过而停止；P0-E007 的独立阶段门通过 G1 与 G2 后，按批准方案启动最小 P1-A。P1-A-E001 以归一化复互相关为物理前端，训练三个真值监督 MLP，并与零相位先验、复互相关、逐样本圆均值、秩一 profile-ML 和条件 CRLB 对照。训练数据、测试种子、预算及 G1 门槛均在盲测前冻结。最终 0/3 种子通过 G1：三种子均满足常值基线改善及不变性条件，但无噪声 MAE 为 0.0177–0.0206 rad，超过 `<0.01 rad` 门槛；20 dB 学生 RMSE 为 0.0232–0.0260 rad，显著差于约 0.0097–0.0100 rad 的解析基线，并为条件 CRLB 的约 2.3–2.6 倍。故暂停当前相位读出路线，不进入 P1-B 或蒸馏。完整结果见 `experiments/P1-A-E001/analysis.md` 和 `docs/stage_reviews/P1-A-E001_review.md`。本结论仅适用于该模型和理想仿真假设，不否定所有神经相位估计方法。

1. **问题：** 网络能否从相干三通道观测学习两组独立通道相位差？
2. **假设：** 复互相关/相干积累可作为强基线，物理约束可改善低 SNR 或误差失配场景。
3. **理论：** 相位圆周统计、通道几何、可观测性及 Fisher 信息。
4. **数据：** 理想三通道起步，之后逐项加入独立噪声、通道幅度/相位偏置、时延和异常观测；训练/验证/测试独立。
5. **传统算法：** 复互相关、相干积累、加权相位、ML、稳健圆均值。
6. **模型：** P1-A-E001 已先试归一化复互相关前端加小型真值监督 MLP；只有通过当前可学习性门后，才能提出后续蒸馏或其他模型方案。
7. **步骤：** 最小两相位 E001 已执行。只有阶段门通过后，才另行预注册并逐项增加噪声或误差因素；当前不进入 P1-B。
8. **指标：** 已报告周期相位 RMSE/偏差、CRLB、相位及公共初相分组、幅度差分组、不变性和配对区间。
9. **验收：** E001 冻结门为至少 2/3 种子同时达到无噪声 MAE<0.01 rad、P95<0.05 rad、20 dB 明显优于常值基线且公共相位/复尺度/频移不变。E001 为 0/3 种子通过，当前 STOP/REDIRECT；不通过增加模型或蒸馏绕过。
10. **风险：** 通道相位与几何/时延混淆，或仿真误差未代表硬件。
11. **备选：** 固定几何、显式校准参数，分开估计静态通道偏置和目标相位。
12. **产出：** 三通道信号模型、误差敏感性报告、相位估计器及阶段验收记录。

## P2：三通道目标参数联合估计

> 下方 P2–P6 内容是原模块级路线草案，当前由 D2–D5 主线取代；保留其理论材料供后续设计复用，但尚未获阶段门授权启动。

1. **问题：** 多普勒、相对相位、角度及可观测径向速度是否可联合辨识？
2. **假设：** 先验明晰且可辨识时，联合学习可减少分步估计误差传播；不可辨识区域不能靠网络解决。
3. **理论：** 三通道几何映射、参数混叠、FIM/CRLB和模糊条件。
4. **数据：** 单目标逐步增加角度/速度耦合、SNR、相位误差和训练外几何。
5. **传统算法：** 联合 ML 搜索、多基线估计、分步估计及可用的解析解。
6. **模型：** 多参数圆周/实值输出网络，分头监督和联合/物理约束对照。
7. **步骤：** 理论可辨识性 → 单参数 → 双参数 → 联合参数 → 未见几何测试。
8. **指标：** 各参数 RMSE、偏差、异常率、联合置信度和 CRLB。
9. **验收：** 可辨识区间测试满足物理一致性；不可辨识区间明确拒判/不确定。
10. **风险：** 单一训练范围造成参数先验捷径。
11. **备选：** 参数归一化、覆盖模糊边界、增加显式几何输入或保持部分物理前端。
12. **产出：** 参数 FIM、混叠图、联合估计器与适用域结论。

## P3：杂波背景下的动目标检测

1. **问题：** 学习法能否在杂波和误差下检测弱/低速目标并估参？
2. **假设：** 只有数据/物理误差与现有模型不匹配时，学习或混合方法才可能优于适配良好的传统检测器。
3. **理论：** CFAR、GLRT、杂波协方差、可检测性及虚警统计。
4. **数据：** 逐项加入 AWGN、静止杂波、强杂波、低 CNR、非均匀杂波、通道误差、低速弱目标、多目标。
5. **传统算法：** 现行 CSI、CA/GO-CFAR、适用 GLRT、多通道检测器。
6. **模型：** 目标存在性、参数和置信度输出；监督/教师/物理一致性对照。
7. **步骤：** 一次增加一个主困难；按独立杂波和系统误差生成外部分布测试。
8. **指标：** Pd、Pfa、SCNR、MDV、速度/角度 RMSE、目标漏检、异常率。
9. **验收：** Pfa=1e-6 有足够背景样本或有理论尾部模型，明确单元/系统级；弱目标保护不得以增加虚警换取。
10. **风险：** 少量仿真无法验证极低 Pfa，训练杂波分布过窄。
11. **备选：** 解析 CFAR 校准、尾部建模、扩大独立背景机会或限制结论。
12. **产出：** 逐难度数据、基线检测性能、Pfa/Pd 曲线和误差报告。

## P4：多模块联合蒸馏

1. **问题：** 独立学生级联与联合多任务学生相比，误差和蒸馏收益如何？
2. **假设：** 联合优化可能降低级联误差，也可能引入任务冲突；需实验区分。
3. **理论：** 误差传播、多任务优化、特征/输出蒸馏和物理一致性。
4. **数据：** 只用 P0–P3 已验收模块和场景，覆盖正常及模型失配条件。
5. **传统算法：** 完整传统分阶段链与每模块强基线。
6. **模型：** 独立学生级联、多任务学生、物理约束学生。
7. **步骤：** 逐模块蒸馏 → 级联 → 联合 → 消融中间知识/损失权重。
8. **指标：** 检测和各参数误差、任务冲突、级联稳定性、计算量。
9. **验收：** 同一测试集上的配对统计支持联合收益才继续；仅复杂度增加不构成通过。
10. **风险：** 多任务梯度冲突、教师中间表征不一致。
11. **备选：** 保留多个轻量专用模块或物理处理节点。
12. **产出：** 级联/联合对照、消融结果和选择依据。

## P5：原始回波整链端到端蒸馏

1. **问题：** 三通道原始回波能否端到端检测并估计距离/速度/角度？
2. **假设：** 端到端不必然优于物理前端加学习模块；替代边界需逐项验证。
3. **理论：** 完整成像/脉冲压缩/多普勒/通道观测模型及信息保真。
4. **数据：** 三通道复回波仿真、独立系统/场景误差，后续才加入实测数据。
5. **传统算法：** 完整高精度处理链作为教师与评估基线。
6. **模型：** 原始端到端、物理引导端到端、流式/多任务学生。
7. **步骤：** 单模块积木 → 部分链路 → 完整链路 → 教师软标签/中间特征/物理自监督消融。
8. **指标：** Pd/Pfa、目标参数误差、信息损失、跨场景泛化和资源开销。
9. **验收：** 对关键弱目标和失配条件不劣于基线且有明确统计证据；速度优势须实测。
10. **风险：** 仿真器失配、训练数据需求和端到端信息捷径。
11. **备选：** 保留可信物理前端，只学习噪声/杂波或参数估计环节。
12. **产出：** 可复现完整链比较及保留/替代物理模块的证据。

## P6：边缘部署与优化

1. **问题：** 已验收模型能否在指定硬件满足精度和实际时延要求？
2. **假设：** 蒸馏/剪枝/量化等可减少资源，但可能损害弱目标检测或参数精度。
3. **理论：** 量化误差、吞吐/存储/能耗和实时调度约束。
4. **数据：** P3–P5 验收测试集与真实目标硬件输入流。
5. **传统算法：** 经过优化的经典处理链。
6. **模型：** 物理引导学生、端到端学生、多模块学生及压缩变体。
7. **步骤：** 基准测量 → 单一压缩措施 → 组合优化 → 目标硬件实测。
8. **指标：** Pd/Pfa、参数 RMSE、均值/P95/P99 延时、吞吐、内存、功耗。
9. **验收：** 目标硬件真实测量且精度满足预设门限；FLOPs 不替代实测。
10. **风险：** 算子/驱动不支持、批处理掩盖尾延时。
11. **备选：** 物理前端加小模型、混合精度或保留未压缩安全路径。
12. **产出：** 部署镜像/脚本、硬件实测记录和精度-资源权衡。
