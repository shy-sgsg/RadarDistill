# 分阶段研究计划

阶段顺序固定为 P0 → P1 → P2 → P3 → P4 → P5 → P6。阶段通过门槛后才增加难度；每个实验都要保留传统基线、真实标签/教师输出区分、统计结果和负结果。

**当前状态（2026-10-22）：** P0 已运行，但继续门未通过；P1 未启动。主实验和三项诊断的证据、局限及下一步见 `docs/progress.md`。在一个有针对性的 P0 诊断满足本计划第 9 项验收条件前，不增加三通道或杂波难度。

## P0：单目标高精度多普勒频率估计（当前）

1. **科学问题：** 小型网络能否从长度 130 的复数慢时间观测中学习连续 Doppler？教师蒸馏是否优于真值监督？
2. **假设：** 随机相位/幅度和连续频率下，网络应优于常数预测；正确模型下 ML 应是强参考，蒸馏增益不预设。
3. **理论依据：** 单音复高斯似然、周期频率表示、无偏频率估计 CRLB。
4. **数据：** PRF=1300 Hz，N=130，训练 SNR {-15,-5,0,10,20} dB，测试 {-15,-10,-5,0,5,10,15,20} dB；独立训练/验证/测试种子，连续无模糊频率、随机初相和幅度。
5. **传统算法：** FFT 峰值、三点 FFT 插值、相位差、连续最大似然。
6. **学习模型：** 小型 1D Conv + 圆周 sin/cos 输出；E1 真值监督、E2 纯教师软目标、E3 真值+教师软目标。
7. **步骤：** 仿真一致性 → 基线 → CRLB → 教师标签 → 训练三组策略 → 独立测试 → 分组和种子分析。
8. **指标：** MAE/RMSE/偏差/异常率、SNR/频率/初相/幅度/栅格偏移分组、CRLB、配对 bootstrap 区间。
9. **验收：** 代码正确；网络独立测试优于常数/随机并对分组变化稳健；至少部分合理 SNR 超越 FFT 峰值，报告与插值/ML差距；E3 只有统计支持时才声称蒸馏有益。
10. **失败原因：** 标签/信号错误、周期边界、训练分布捷径、网络欠拟合、教师偏差或低 SNR 信息不足。
11. **备选：** 先复核数学与数据；只针对有证据的因素改输入归一化、训练采样或圆周表示；若 ML 接近 CRLB，转向失配条件而不人为削弱 ML。
12. **产出：** P0 配置、仿真数据、教师和学生权重、逐样本预测、汇总表及阶段分析报告；根据证据做 P1 决策。

## P1：三通道相对相位估计

1. **问题：** 网络能否从相干三通道观测学习两组独立通道相位差？
2. **假设：** 复互相关/相干积累可作为强基线，物理约束可改善低 SNR 或误差失配场景。
3. **理论：** 相位圆周统计、通道几何、可观测性及 Fisher 信息。
4. **数据：** 理想三通道起步，之后逐项加入独立噪声、通道幅度/相位偏置、时延和异常观测；训练/验证/测试独立。
5. **传统算法：** 复互相关、相干积累、加权相位、ML、稳健圆均值。
6. **模型：** 小型三通道 CNN，监督、教师蒸馏、物理一致性对照。
7. **步骤：** 先两相位估计，再加噪声与误差因素；最后按独立误差测试。
8. **指标：** 周期相位 RMSE/偏差、失配敏感度、相位闭合一致性和不确定度。
9. **验收：** 独立测试优于先验/常值基线，跨初相与幅度有效且相位闭合；相位不可辨识时须识别而非猜测。
10. **风险：** 通道相位与几何/时延混淆，或仿真误差未代表硬件。
11. **备选：** 固定几何、显式校准参数，分开估计静态通道偏置和目标相位。
12. **产出：** 三通道信号模型、误差敏感性报告、相位估计器及阶段验收记录。

## P2：三通道目标参数联合估计

1. **问题：** 多普勒、相对相位、角度及可观测径向速度是否可联合辨识？
2. **假设：** 先验明晰且可辨识时，联合学习可减少分步估计误差传播；不可辨识区域不能靠网络解决。
3. **理论：** 三通道几何映射、参数混叠、FIM/CRLB和模糊条件。
4. **数据：** 单目标逐步增加角度/速度耦合、SNR、相位误差和训练外几何。
5. **传统算法：** 联合 ML 搜索、多基线估计、分步估计及可用的解析解。
6. **模型：** 多参数圆周/实值输出网络，分头监督和联合/物理约束对照。
7. **步骤：** 理论可辨识性 → 单参数 → 双参数 → 联合参数 → 未见几何测试。
8. **指标：** 各参数 RMSE、偏差、异常率、联合置信度和 CRLB。
9. **验收：** 可辨识区间测试满足物理一致性；不可辨识区间明确拒判/不确定。
10. **风险：** 单一训练范围造成参数先验捷径。
11. **备选：** 参数归一化、覆盖模糊边界、增加显式几何输入或保持部分物理前端。
12. **产出：** 参数 FIM、混叠图、联合估计器与适用域结论。

## P3：杂波背景下的动目标检测

1. **问题：** 学习法能否在杂波和误差下检测弱/低速目标并估参？
2. **假设：** 只有数据/物理误差与现有模型不匹配时，学习或混合方法才可能优于适配良好的传统检测器。
3. **理论：** CFAR、GLRT、杂波协方差、可检测性及虚警统计。
4. **数据：** 逐项加入 AWGN、静止杂波、强杂波、低 CNR、非均匀杂波、通道误差、低速弱目标、多目标。
5. **传统算法：** 现行 CSI、CA/GO-CFAR、适用 GLRT、多通道检测器。
6. **模型：** 目标存在性、参数和置信度输出；监督/教师/物理一致性对照。
7. **步骤：** 一次增加一个主困难；按独立杂波和系统误差生成外部分布测试。
8. **指标：** Pd、Pfa、SCNR、MDV、速度/角度 RMSE、目标漏检、异常率。
9. **验收：** Pfa=1e-6 有足够背景样本或有理论尾部模型，明确单元/系统级；弱目标保护不得以增加虚警换取。
10. **风险：** 少量仿真无法验证极低 Pfa，训练杂波分布过窄。
11. **备选：** 解析 CFAR 校准、尾部建模、扩大独立背景机会或限制结论。
12. **产出：** 逐难度数据、基线检测性能、Pfa/Pd 曲线和误差报告。

## P4：多模块联合蒸馏

1. **问题：** 独立学生级联与联合多任务学生相比，误差和蒸馏收益如何？
2. **假设：** 联合优化可能降低级联误差，也可能引入任务冲突；需实验区分。
3. **理论：** 误差传播、多任务优化、特征/输出蒸馏和物理一致性。
4. **数据：** 只用 P0–P3 已验收模块和场景，覆盖正常及模型失配条件。
5. **传统算法：** 完整传统分阶段链与每模块强基线。
6. **模型：** 独立学生级联、多任务学生、物理约束学生。
7. **步骤：** 逐模块蒸馏 → 级联 → 联合 → 消融中间知识/损失权重。
8. **指标：** 检测和各参数误差、任务冲突、级联稳定性、计算量。
9. **验收：** 同一测试集上的配对统计支持联合收益才继续；仅复杂度增加不构成通过。
10. **风险：** 多任务梯度冲突、教师中间表征不一致。
11. **备选：** 保留多个轻量专用模块或物理处理节点。
12. **产出：** 级联/联合对照、消融结果和选择依据。

## P5：原始回波整链端到端蒸馏

1. **问题：** 三通道原始回波能否端到端检测并估计距离/速度/角度？
2. **假设：** 端到端不必然优于物理前端加学习模块；替代边界需逐项验证。
3. **理论：** 完整成像/脉冲压缩/多普勒/通道观测模型及信息保真。
4. **数据：** 三通道复回波仿真、独立系统/场景误差，后续才加入实测数据。
5. **传统算法：** 完整高精度处理链作为教师与评估基线。
6. **模型：** 原始端到端、物理引导端到端、流式/多任务学生。
7. **步骤：** 单模块积木 → 部分链路 → 完整链路 → 教师软标签/中间特征/物理自监督消融。
8. **指标：** Pd/Pfa、目标参数误差、信息损失、跨场景泛化和资源开销。
9. **验收：** 对关键弱目标和失配条件不劣于基线且有明确统计证据；速度优势须实测。
10. **风险：** 仿真器失配、训练数据需求和端到端信息捷径。
11. **备选：** 保留可信物理前端，只学习噪声/杂波或参数估计环节。
12. **产出：** 可复现完整链比较及保留/替代物理模块的证据。

## P6：边缘部署与优化

1. **问题：** 已验收模型能否在指定硬件满足精度和实际时延要求？
2. **假设：** 蒸馏/剪枝/量化等可减少资源，但可能损害弱目标检测或参数精度。
3. **理论：** 量化误差、吞吐/存储/能耗和实时调度约束。
4. **数据：** P3–P5 验收测试集与真实目标硬件输入流。
5. **传统算法：** 经过优化的经典处理链。
6. **模型：** 物理引导学生、端到端学生、多模块学生及压缩变体。
7. **步骤：** 基准测量 → 单一压缩措施 → 组合优化 → 目标硬件实测。
8. **指标：** Pd/Pfa、参数 RMSE、均值/P95/P99 延时、吞吐、内存、功耗。
9. **验收：** 目标硬件真实测量且精度满足预设门限；FLOPs 不替代实测。
10. **风险：** 算子/驱动不支持、批处理掩盖尾延时。
11. **备选：** 物理前端加小模型、混合精度或保留未压缩安全路径。
12. **产出：** 部署镜像/脚本、硬件实测记录和精度-资源权衡。
