## 1. 研究背景

机载多通道 GMTI 需要从运动平台接收的复数回波中检测运动目标，并估计 Doppler、距离、速度或与通道几何相关的参数。传统处理链会依次进行距离压缩、杂波抑制、慢时间频谱处理、检测和参数精估。它依赖明确的信号模型，性能可分析，但多个模块间存在误差传播；低信噪比、低速弱目标、非均匀杂波、通道误差和有限硬件资源会共同影响最终任务。

学习式方法可能把多个中间量映射到最终任务，也可能利用传统链难以显式表达的统计规律。但复数相干信息、参数周期性、可辨识条件和数据分布偏差要求模型受到物理检验。仅换用 CNN、Transformer、蒸馏或 IQ 输入，不构成研究贡献。必须用可信数据、强传统基线、隔离测试和完整成本测量，判断学习或混合处理是否有实际价值。

## 2. 研究主题、对象与边界

正式主题为：

**《物理模型与渐进式知识蒸馏驱动的高效雷达动目标检测及参数估计方法研究》**

项目名：RadarDistill。

研究对象是机载多通道 GMTI 的复数雷达信号、目标检测和连续参数估计。研究从简化可辨识仿真开始，逐步扩展到复杂场景、原始回波与系统验证。物理真值用于监督和纠错；传统处理链用于提供可比较的基线和候选教师知识。现阶段的仿真证据不得外推成实测或生产系统结论。

研究长期关注精度与完整处理成本。学生不必复制教师的内部计算，也不要求精度和速度同时超过传统算法；但任何单项优势都必须满足预先冻结的其他任务质量下限。允许保留有明确价值且计算代价合理的物理算子。

## 3. 总体目标

1. 以检测目标和估计目标参数为最终任务，而不把复刻某个中间谱图当作终点。
2. 用可信物理仿真真值进行监督和教师错误纠正；真值、教师估计与学生输出分别保存。
3. 建设、验证并按明确任务瓶颈迭代高质量教师：既可针对杂波抑制、检测、参数精估计等单模块改进，也可研究联合检测与参数估计的任务级教师；检验教师知识能否经渐进蒸馏实际转移给学生。教师任务性能和教学有效性必须分别评价。
4. 逐步检验从距离压缩 IQ 到更原始复数回波的迁移，并明确每个推理模型实际保留的传统算子。
5. 最终在真实任务质量约束下，判断纯学习式学生、物理前端加学生、完整传统链的精度、可靠性与计算成本。
6. 不预设学习方法胜出；结果可以支持继续、修正、转向混合处理或停止某一路线。

## 4. 核心科学问题

- **Q1：** 传统算法知识能否改善任务级学生学习，包括最终检测/估计、样本效率或收敛？
- **Q2：** 哪些教师中间知识真正有助于最终检测和参数估计，完整响应、局部响应与最终任务监督如何取舍？
- **Q3：** 学生能否以不同于传统算法的内部表征完成最终任务，而不必显式恢复所有传统中间变量？
- **Q4：** 如何利用物理先验避免直接端到端训练的优化困难，同时避免把教师偏差强加给学生？
- **Q5：** 如何从距离压缩输入逐步迁移到更原始的复数回波，并区分物理前端和学习器的贡献？
- **Q6：** 如何提高低 SNR 弱目标检测和连续参数估计精度，特别是当前的 Doppler 瓶颈？
- **Q7：** 在哪些任务规模、输入边界和硬件条件下，学生可能降低完整处理链成本或时延？
- **Q8：** 哪些传统物理计算应当保留，哪些值得由学习式方法替代？
- **Q9：** 当教师在困难场景失效时，模块级改进与整体任务级改进分别能带来哪些可靠任务收益；如何筛选教师知识、度量教师错误与不确定性，并验证教师的提升是否转化为学生最终任务收益？

## 5. 研究内容

1. **数据与教师：** 建立可复现的复数信号仿真、可辨识性检查和经验证的传统算法子链；记录场景、噪声、杂波、通道误差和标签假设。针对已证实的教师薄弱环节开展有界先进方法调研、复现与改进（含模块级与任务级联合教师），以相同输入与可辨识条件下的检测、估计、校准、可靠性和复杂度评价教师能力，并检查其监督信息的可蒸馏性。
2. **渐进式知识蒸馏：** 对比真值监督、教师硬标签、软频谱响应、联合监督和渐进退火；测量知识是否改善最终任务、收敛或泛化。
3. **联合检测与估计：** 研究 H0/H1 检测、距离、Doppler 及后续可辨识参数的联合学习和任务冲突。
4. **复杂场景：** 在每轮只增加有限因素的条件下研究静止杂波、弱目标、多目标、系统误差和模型失配，并与有代表性的传统方法比较。
5. **原始回波迁移：** 比较距离压缩物理前端加学生与从更原始回波学习的学生，逐渐撤去不再需要的辅助模块。
6. **结构和计算优化：** 只在模型可靠后评估算子、流式处理、量化和部署成本；不将模型前向时间当作整链时延。
7. **系统验证：** 在同硬件、同输入边界、同任务质量约束下评价完整处理链、可靠性、内存、时延和功耗。

## 6. 总体研究思路

物理仿真真值与传统教师 → 教师知识有效性检验 → 最终任务联合监督 → 逐步减弱教师辅助约束 → 任务级学生 → 物理算子与学习模块协同 → 复杂场景和系统级评价。

教师只参与训练或基线比较，是否进入最终推理由实验决定。仿真真值不得被教师错误覆盖。每种混合方法均须报告保留算子及与匹配非学习物理前端的比较。

**教师能力提升与教学能力联合迭代原则：** 当困难条件暴露教师检测、杂波抑制、参数估计或统计校准的缺口时，可并行采用两条有界路线：（a）针对已定位瓶颈选择适用的先进模块算法，单因素验证其增益；（b）研究直接面向最终检测与连续参数估计的联合任务教师，比较其相对于模块组合是否减少信息损失。每次必须先核查方法的雷达体制、通道几何、样本支持、可观测输入和可辨识性，不得因方法被称为 SOTA 就假定可直接移植。教师离线计算可以较重，但必须单独记账；教师是否真正变强与其知识是否有益于学生，必须在匹配数据、学生结构和训练预算的受控对照中分别验证。允许可靠性分层、教师集合、软响应、联合估计与真值纠错；不得用错误教师硬标签覆盖物理真值，也不得要求学生复制全部中间处理。以“相对强基线的任务收益＋实际学生增益”为继续条件，设置明确预算与停止规则；不将所有教师达到所谓通用 SOTA 作为学生研究的必需前置门。

## 8. 可证伪核心假设

假设及状态以唯一编号维护在 research/ASSUMPTION_REGISTER.md。当前重点包括：

- H-KD-001：教师辅助在特定任务与预算下能改善学生最终任务指标；其范围和稳定性仍需复核。
- H-KD-002：任务导向的局部教师知识比完整频谱重建更有效。
- H-ARCH-001：当前时间平均池化弱化了精细 Doppler 信息。
- H-EFF-001：在满足检测和估计质量约束后，学生可能降低完整处理成本。
- H-TEACH-001：在受测可辨识困难条件下，经过适用的模块级或任务级改进，教师可提升检测／联合参数估计和输出可靠性；改善后的教师知识可能进一步提升匹配学生的最终任务指标，但两种收益须分别验证，较强教师不必然产生较强学生。

这些都是待检验或范围有限的假设，不是本总纲宣称已成立的结论。

## 9. 成功标准

每个阶段使用单独冻结的协议和阶段门；不同成功维度不可互相替代。

- **学习可行性：** 在独立数据上稳定优于预设常值/简单先验，跨训练种子复现，并满足物理一致性检查。
- **教师能力与教学有效性：** 在相同物理输入、同等可观测信息、独立 H0 校准和可辨识条件下，分层比较原教师、模块增强教师、任务级联合教师的 Pd/Pfa、联合任务成功率、连续参数误差、物理可靠性、校准及计算成本；再使用固定学生、数据和训练预算，独立验证升级教师是否带来蒸馏增益。特别报告教师错误区域、负蒸馏和学生容量约束；不将文献声称的 SOTA 直接视为本任务 SOTA。
- **蒸馏收益：** 与同架构、同数据、同预算的真值监督对照比较；报告教师硬标签、软响应和物理真值各自作用及统计不确定性。
- **检测性能：** 报告 Pd/Pfa 及其样本量和置信区间，区分单元级与系统级虚警；样本量不支持时不声称达到 1e-6。
- **参数精度：** 对周期参数使用回绕误差，报告 SNR、频率/参数区间、边界、幅度、相位和训练种子分组，并比较强传统基线及适用的 CRLB。
- **推理速度/成本：** 在同硬件、相同输入边界下测量完整前后处理、数据搬运、内存与吞吐；报告实际保留的传统算子。
- **系统可靠性：** 检查分布偏移、通道/场景误差、失效识别和资源约束；仿真通过不等于真实回波可靠。
- **论文贡献：** 贡献必须由可证伪问题、可复核的新证据和清晰适用范围支撑。使用常见网络、蒸馏或 IQ 数据本身不构成创新。

## 10. 创新性边界

**已有证据：** 当前 P0/D0/D1 报告中明确记录的仿真正确性、单目标频率可学习性、任务级检测/估计和部分蒸馏指标结果，只能按各自模型、协议和数据范围表述。

**已验证贡献边界：** D0 证明简化物理仿真与 APX15 慢时间 FFT 子链通过冻结检查；D1 证明受测任务级学生可在简化仿真学习最终任务，且部分蒸馏策略满足冻结最终联合指标规则。它们不证明实测 GMTI、普遍蒸馏优势、完整链速度优势或传统链可替代。

**待验证创新假设：** 物理先验与渐进蒸馏如何改善低 SNR 任务质量、Doppler 表征和有限样本泛化；哪些中间知识可被学生吸收；何时混合前端优于纯学习；完整工作负载的精度—计算边界。

## 11. 当前已知结论与失败经验

- P0-E006 的独立阶段结论为 STOP/REDIRECT；P0-E007 后续以新协议取得 G1/G2 通过、G3 未通过。E007 的 M1 未胜过 profile-ML/强局部插值，蒸馏没有稳定收益；M2/M3 按预设规则停止扩展。
- P1-A-E001 三个种子均未达到冻结无噪声精度门；20 dB MLP 精度明显差于接近条件 CRLB 的互相关/profile-ML。该结论限定于该模型和理想单音 AWGN 条件。
- D0-E001 通过 12/12 正确性检查；低 SNR 下教师不总可靠，教师不能替代物理真值。
- D1-E001 的学生从三通道距离压缩复 IQ 学会了检测、距离和周期 Doppler 任务。G1/G2 通过、G3 未通过；C/D 的部分最终指标有收益，但没有收敛加速证据。E002 中 S2 优于 S0 的高 SNR Doppler RMSE，但未满足低 SNR 检测保护门。
- D1 低 SNR 检测仍弱；20 dB 学生 Doppler RMSE 约为 25–35 Hz，远高于 APX15、4 倍 FFT 插值和 profile-ML。
- 已有成本数据测的是距离压缩输入边界，且学生 GPU 与 APX15 FFT 子链 CPU 设备不同。没有公平完整链速度证据。
- 多次参与架构选择的开发测试不能重新称为最终盲测；旧冻结结论不得事后更改。

完整数字和限定条件见对应配置、实验结果与阶段审查，不在总纲中复制逐样本历史。
